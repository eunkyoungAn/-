# 질문 구조 연습

초급자용 프롬프트 연습 페이지. 짧게 쓴 지시문을 역할 · 자료 · 할 일 · 형식 · 조건 다섯 가지로 점검하고, 빠진 부분을 채워 다듬은 지시문을 만든다.

- 주소: `https://eunkyoungan.github.io/-/prompt-practice/` (실제 배포는 `gh-pages` 브랜치. main에 합친 뒤 `prompt-practice/index.html`을 `gh-pages`에 그대로 올려야 반영된다)
- `index.html` 하나로 동작한다. 스타일과 스크립트가 파일 안에 들어 있어, 파일만 보내도 받는 사람이 두 번 눌러 브라우저에서 쓸 수 있다.
- 구성과 스타일은 면접 리허설(`interview/`)을 따랐다.
- 업무 에이전트 실습실 무료플랜 파트 `#fpgpt`(질문 구조 연습)의 "질문 구조 연습 열기" 단추로 연결된다.

## 동작

- AI를 부르지 않는다. 정해진 규칙(낱말 판별)으로 다섯 가지가 있는지 살핀다. 틀리게 표시할 수 있다는 안내를 화면에 적어 두었다.
- 연습 주제: 레시피 만들기, 마케팅 자료조사, 직접 쓰기. 직접 쓰기는 지시문의 낱말로 주제를 짐작해 보기를 맞춘다.
- 다듬는 방식: 질문 받으며(빠진 것을 하나씩 묻는다), 바로 다듬기(빈칸 `[ ]`이 있는 틀을 낸다).
- 원래 지시문의 문장은 고치지 않고 빠진 요소만 덧붙인다.

## 고치기

- 예시 지시문과 질문별 보기: `index.html`의 `THEMES`(`samples`, `picks`).
- 주제 추가: `THEMES`에 항목을 더하고 `THEME_ORDER`에 이름을 넣는다. 주제가 4개 이상이면 `.seg.three` 단추 줄 모양도 고친다.
- 판별 규칙: `ELEMENTS`의 `has`, `detail` 정규식.

## 보안

- CSP 메타에서 `connect-src 'none'`. 화면에서 바깥으로 보내는 요청이 없다. 한 파일 배포를 위해 스크립트·스타일은 `'unsafe-inline'`을 허용했다.
- 입력한 내용은 저장하지 않으며 화면을 닫으면 사라진다. "글 파일로 저장"은 그 기기에 txt로 내려받는다.
