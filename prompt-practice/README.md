# 질문 구조 연습

초급자용 프롬프트 연습 페이지. 짧게 쓴 지시문을 역할 · 자료 · 할 일 · 형식 · 조건 다섯 가지로 살피는 연습을 세 가지 방식으로 한다.

- 주소: `https://eunkyoungan.github.io/-/prompt-practice/` (실제 배포는 `gh-pages` 브랜치. main에 합친 뒤 `prompt-practice/index.html`을 `gh-pages`에 그대로 올려야 반영된다)
- `index.html` 하나로 동작한다. 스타일과 스크립트가 파일 안에 들어 있어, 파일만 보내도 받는 사람이 두 번 눌러 브라우저에서 쓸 수 있다.
- 구성과 스타일은 면접 리허설(`interview/`)을 따랐다.
- 업무 에이전트 실습실 무료플랜 파트 `#fpgpt`(질문 구조 연습)의 "질문 구조 연습 열기" 단추로 연결된다.

## 세 가지 연습

| 연습 | 하는 일 | 채점 |
|---|---|---|
| 객관식 3문항 | 상황(지문)을 읽고 네 지시문 가운데 가장 알맞은 것 고르기. 문항당 90초, 시간이 끝나면 해설이 열린다 | 정답/오답 + 정답 이유 · 오답 함정 · 실무에서는 |
| 주관식 3문항 | 동료의 부탁과 조건을 보고 AI에게 보낼 지시문을 직접 입력 | 다섯 요소별 배점 합계 100점, 빠진 항목과 보완 팁, 모범 예시 |
| 내 지시문 다듬기 | 내가 쓰려던 지시문을 점검하고 빠진 곳 채우기 | 다섯 가지 있음/보완/없음 표시 → 완성 지시문 |

주제는 **레시피 만들기**와 **마케팅 자료조사** 두 가지이며, 객관식·주관식 문항이 주제에 따라 바뀐다.

## 동작

- AI를 부르지 않는다. 정해진 규칙(낱말 판별)으로 점검하고 채점한다. 뜻이 같아도 다르게 적으면 못 알아볼 수 있다는 안내를 화면에 적어 두었다.
- 주관식 채점은 항목마다 정규식 하나 또는 여러 개를 둔다. 여러 개면 맞힌 개수만큼 부분 점수를 준다.
- 원래 지시문의 문장은 고치지 않고 빠진 요소만 덧붙인다.

## 고치기

- 객관식 문항: `index.html`의 `QUIZ`(주제별 배열). `passage`, `q`, `opts` 4개, `ans`(0부터), `why`, `trap`, `work`.
- 주관식 문항: `DRILL`(주제별 배열). `from`, `ask`, `conds`, `checks`(`k` 항목명, `pt` 배점, `re` 정규식, `tip` 보완 안내), `sample` 모범 예시. 배점 합계는 100으로 맞춘다.
- 다듬기 예시와 보기: `THEMES`(`samples`, `picks`).
- 주제 추가: `THEMES`, `QUIZ`, `DRILL`에 같은 이름의 항목을 더하고 `THEME_ORDER`에 넣는다. 주제가 3개 이상이면 `.seg` 단추 줄 모양도 고친다.
- 제한 시간: `LIMIT`(초).
- 판별 규칙: `ELEMENTS`의 `has`, `detail` 정규식.

## 보안

- CSP 메타에서 `connect-src 'none'`. 화면에서 바깥으로 보내는 요청이 없다. 한 파일 배포를 위해 스크립트·스타일은 `'unsafe-inline'`을 허용했다.
- 입력한 내용은 저장하지 않으며 화면을 닫으면 사라진다. "글 파일로 저장"은 그 기기에 txt로 내려받는다.
- 문항에 나오는 인물과 상황은 모두 교육용 가상 설정이다.
