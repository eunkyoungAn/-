원고: AI 시대 '인재를 돕는 인재'의 경력전략 (고용서비스업 종사자의 프로티언 경력태도와 직무열의)
기준: 「산업교육연구」 논문 작성 및 편집 규정 · 투고 및 발간 규정 · 한국산업교육학회 윤리규정

## 적용한 규정
- 순서: 표지(1면) → 국문 요약·핵심 되는 말(2면) → 본문 Ⅰ~Ⅴ → 참고문헌(새 장) → 영문초록
- 글꼴: 제목 HY그래픽 16pt 굵게 가운데 / 성명 휴먼명조 10pt 오른쪽 / 소속 바탕체(각주) / 요약 제목 HY그래픽 14pt / 본문 신명조 10pt 양쪽정렬·들여쓰기 10pt / 장 HY그래픽 14pt 굵게 / 절 12pt·항 11pt 굵게 / 표 내용 돋움 9pt·줄간격 130%
- 번호체계 Ⅰ → 1 → 1) → (1), 쪽번호 없음
- 표: 제목은 위, 위·아래 굵은 실선, 좌우 선 없음, 머리행 아래 이중선 / 그림: 제목은 아래
- 인용: 2인 "손지윤, 임희주", 3인 이상 "최미미 외" 형식으로 통일(가운뎃점 제거)
- 참고문헌: 국문 가나다 → 영문 알파벳, 학위논문은 "석사(박사)학위논문, 대학교." 순서
- 분량: A4 13매(20매 이내 → 초과 게재료 없음)

## 고친 부분
- 오타 "미쳐다" → "미쳤다", 표 Ⅲ-1 끝의 깨진 글자 → "계 38"
- "[그림 1]" → "그림 [Ⅲ-1]"로 번호 통일, 그림 안의 캡션 중복 제거
- 표 Ⅲ-1 "문항 번호" → "문항 수"
- 영문초록(Abstract) 새로 작성 — 원고에 없었음(규정상 필수). 저자 검토 필요
- 석사학위논문 수정·보완 표기를 표지 주석으로 이동

## 저자가 채워야 할 곳 (파일에 노란색 표시)
1. 저자 성명·소속·연락주소·전화·e-mail (표지와 각주), 영문 성명
2. 표 Ⅲ-1 α 값: 본문 기준으로 수직 .666, 수평 .728로 넣음 — 원 표와 맞는지 확인
3. 표 Ⅳ-4 아래 R, R², F 값 (원고에 없음)
4. 본문에 인용됐지만 참고문헌에 없는 문헌: 김용성(2025), 김혜연(2021), 오선정·이재갑(2025), 최미미(2018)
5. 새로 넣은 영문 문헌 2건(Demerouti et al., 2001; Law et al., 1998) 서지 확인
6. 원고 매수는 LibreOffice 기준 13매 — 한글/워드에서 열어 다시 확인

## 윤리규정 점검
- 학위논문을 수정한 논문임을 밝힘(중복게재 방지, 제3조) — 투고 전 학위논문과의 관계를 편집위원회에 알릴 것
- 모든 인용에 출처 표기(제1·4조) — 위 4번 누락 문헌 보완 필요
