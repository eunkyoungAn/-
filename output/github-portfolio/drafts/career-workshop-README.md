# 내일의 나 · 커리어 워크숍

> 취업 교육 수업에서 교육생이 휴대폰으로 자기이해 활동을 하고, 원하는 응답만 익명으로 강사 화면에 공유하는 모바일 워크숍 웹사이트

🔗 **Demo**: https://eunkyoungan.github.io/career-workshop/ [배포 주소 확인 필요] · 운영 매뉴얼: [GUIDE.md](GUIDE.md)

## 1. Problem
- 종이 활동지는 수업 중 공유·피드백이 늦고, 발표는 일부 교육생에게만 기회가 갑니다.
- 기존 설문 도구는 실명·계정을 요구하거나 응답이 외부 서버에 쌓여 개인정보 부담이 있습니다.
- 성향검사(DISC) 결과가 "유형 판정"으로 오해되어 경험 기반 강점 발견을 가립니다.

## 2. Solution
| 활동 | 내용 | 결과물 |
|---|---|---|
| 커리어 자산 | 흥미·가치·경험·역량·현실조건 (항목별 예시 2개) | 자산 목록 |
| 강점 발견 | DISC는 선택 참고, 실제 경험 5문항 | 강점 문장 |
| 코칭 휠 | 8개 영역 1~10점 + 이유 (현재/목표/실행 후) | 휠 그래프 |
| 취업 계획서 | 한 줄 소개, 희망 직무·시기, 할 일 3가지 | PNG 이미지 |

강사는 수업방 생성 → 참여 QR 배포 → 발표 화면에서 익명 응답을 보여 주고, 원치 않는 응답은 발표에서 숨깁니다.

## 3. Technology
- 순수 HTML/CSS/JS, 빌드 없음, **GitHub Pages** 배포
- 실시간 공유: **WebRTC**(PeerJS 1.5.5) — 별도 운영 서버 없음
- 보안: PBKDF2-SHA256(600,000회) + AES-GCM, ECDSA 서명으로 강사·참여자 검증
- QR: qrcode-generator 2.0.4
- AI API·이메일: 사용하지 않음

## 4. Process
1. [기관·과정명] 자기이해·취업 준비 수업의 기존 활동지를 웹으로 옮김
2. 경험을 먼저 떠올리도록 활동 순서 조정(커리어 자산 → 강점)
3. 개인정보 최소화를 원칙으로 닉네임·브라우저 저장 구조 설계
4. 수업 운영 중 발견한 문제(절전, 재연결, 방 삭제)를 반영해 개선

## 5. Validation
- 자동 테스트: `npm test` (`tests/`)
- 개인정보: 실명·이메일·연락처 미수집, 응답은 교육생·강사 브라우저에만 저장, GitHub에 응답 미업로드
- 공유 전 강사 쪽 저장 확인 후 성공 표시
- 측정하지 않은 점수는 만들어 넣지 않음(코칭 휠)

## 6. Limitations & Improvements
- 4자리 강사번호는 간편 잠금 수준 → 고강도 인증이 필요하면 별도 서버 필요
- 강사 탭을 닫으면 공유 수신 불가, 클라우드 백업 없음
- 기관 네트워크에서 WebRTC 차단 시 공유 불가(개인 작성은 가능)
- 개선 계획: [예: 활동 템플릿 추가, 수업 후 익명 통계 내보내기]
