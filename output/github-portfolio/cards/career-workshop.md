# Card: 내일의 나 · 커리어 워크숍

## 1. Details
- **설명**: 교육생이 휴대폰으로 자기이해·취업 준비 활동을 하고, 원하는 응답만 익명으로 강사 화면에 공유하는 모바일 워크숍 사이트
- **만든 사람**: 커리어캐쳐(CareerCatcher)
- **형태 / 배포**: HTML/CSS/JS, 빌드 없이 GitHub Pages(`main` 루트)
- **사용 AI·외부 API**: 없음(AI·이메일 미사용). PeerJS 공개 연결 중개 서버 사용
- **저장소**: eunkyoungAn/career-workshop

## 2. Uses
### 의도한 사용
- 취업 교육 과정(예: 여성발전센터 M365 시스템 운영 관리자 과정)의 자기이해 수업
- 활동 4종: 커리어 자산 → 강점 발견 → 코칭 휠 → 취업 계획서(PNG 저장)
### 응용 사용
- 대학·기관 취업특강의 실시간 참여형 활동
### 쓰면 안 되는 경우
- DISC 결과로 능력이나 유형을 판정하는 용도
- 실명·연락처를 모으는 공식 설문
- 고강도 인증이 필요한 환경(4자리 번호는 간편 잠금 수준)

## 3. Bias, Risks, and Limitations
- 강사 탭을 닫으면 공유 응답을 받을 수 없고, 클라우드 백업이 없다.
- 기관 네트워크가 WebRTC를 막으면 공유가 안 된다(개인 작성·이미지 저장은 가능).
- 브라우저 데이터를 지우거나 기기를 바꾸면 초안을 복원할 수 없다.
- 강사번호는 10,000가지 조합뿐이라 오프라인 추측 공격에 약하다.
### 권고
- 공유 PC에서는 수업 뒤 수업방과 응답을 삭제한다.
- 닉네임·응답에 실명을 적지 않도록 안내한다.

## 4. How to Get Started
1. 강사 공간에서 4자리 강사번호 입력 → 새 수업방 생성
2. 참여 링크·QR 배포 → 교육생이 닉네임으로 참여
3. 발표 화면 열기 → 익명 응답을 프로젝터로 보여 주기(원치 않는 응답은 숨기기)
- 개발: Node.js 22+, `npm test`, `npm start` → `http://127.0.0.1:4173`

## 5. Data
- **입력**: 닉네임, 활동 응답(흥미·가치·경험·역량·코칭 휠 점수·계획)
- **저장 위치**: 교육생 브라우저(개인 초안), 강사 브라우저(공유 응답). GitHub에는 소스만 있고 응답은 올리지 않는다.
- **개인정보**: 실명·이메일·연락처를 받지 않는다.

## 6. Evaluation
- 기능 테스트: `tests/` (`npm test`)
- 내용 원칙: 측정하지 않은 점수는 만들어 넣지 않는다. DISC는 참고용으로만 쓴다.
- 전송 확인: 강사 쪽 저장 확인을 받은 뒤에 성공을 표시한다.
- 현장 적용 결과: [확인 필요]

## 7. Technical Specifications
- WebRTC 데이터 채널(PeerJS 1.5.5), qrcode-generator 2.0.4
- PBKDF2-SHA256(600,000회) + AES-GCM 로컬 암호화, ECDSA 서명으로 강사·참여자 검증
