# Card: 공공데이터 지역별 매출 분석

## 1. Details
- **설명**: 공공데이터로 지역별 매출을 비교 분석한 실습 프로젝트. 그래프를 그리는 데서 그치지 않고 데이터를 해석하는 경험을 목표로 했다.
- **저장소**: eunkyoungAn/public-data-analysis (현재 README만 있음)

## 2. Uses
### 의도한 사용
- 데이터 분석 학습 과정의 결과물 사례
### 쓰면 안 되는 경우
- 분석 결과를 지역 매출 현황의 공식 통계로 인용하는 경우

## 3. Bias, Risks, and Limitations
- 데이터 양이 적어 일반화하기 어렵다. 표본이 적은 지역은 해석에 주의해야 한다.
- 코드·데이터 파일이 저장소에 없어 다시 실행해 볼 수 없다.
