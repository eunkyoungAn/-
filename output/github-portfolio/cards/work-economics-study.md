# Card: 일의 세계 경제학 · 오픈북 학습실

## 1. Details
- **설명**: 『일의 세계 경제학』 제2판의 제3·10·11장과 보론 발췌본을 다시 서술한 시험 대비 학습실
- **구성**: 핵심 주제 24개, 모범답안 48개, 미니시험 12문항, 쪽수·표·그림 색인, 학습노트 PDF 59쪽, 원문 대조 검토표
- **형태 / 배포**: 정적 웹(`index.html`, `app.js`) + Markdown + PDF
- **저장소**: eunkyoungAn/work-economics-study

## 2. Uses
### 의도한 사용
- 오픈북 시험 대비: 개요 → 핵심 읽기 → 책 덮고 답안 작성 → 원문 대조 → 다음 날 재시험
### 응용 사용
- 기업 인사·채용 실무 학습(2026-10-20 기업 실무 보충: IBM, HBS·Burning Glass 연구)
### 쓰면 안 되는 경우
- 모범답안을 실제 기출문제나 공식 정답으로 쓰는 경우
- 원문을 대신하는 자료로 배포하는 경우

## 3. Bias, Risks, and Limitations
- 발췌 범위 밖의 내용은 다루지 않는다.
- 원문과 어긋나 보이는 곳은 "확인 필요"로만 표시하고 임의로 고치지 않는다.
- 필기는 브라우저에만 저장되어 기기 간 자동으로 동기화되지 않는다.
### 권고
- 원문 기반 답안과 실무 확장 내용을 구분해서 읽는다.

## 4. How to Get Started
- 웹 화면을 열어 주제별로 학습한다. 원문 PDF는 "원문 PDF 연결"로 내 기기에서만 연결된다(업로드 없음).
- 필기는 JSON으로 백업·복원한다(복원 전에 자동 백업).

## 5. Data
- **원천 자료**: 제공된 원문 발췌 PDF(공개 저장소에는 포함하지 않음)
- **공개 범위**: 학습용 재서술 자료만. 원문 PDF·스캔 이미지·개인 필기는 제외
- **저장 위치**: 필기·답안·복습 상태는 브라우저에 저장

## 6. Evaluation
- 원문 대조 검토표(`answer-review.md`)로 답안과 원문 쪽수를 확인
- 원문 수치·설명을 우선한다.

## 7. Technical Specifications
- 웹·Markdown·PDF가 같은 보충 데이터(`data.js`)를 함께 쓴다. PDF 1~56쪽은 기존 쪽수를 유지하고, 57~59쪽은 실무 보충이다.
