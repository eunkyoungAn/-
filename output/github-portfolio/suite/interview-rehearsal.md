# Card: 커리어캐쳐 면접 리허설 (AI 면접 연습 플랫폼)

## 1. Details
- **설명**: 참여자가 휴대폰으로 면접 질문을 듣고 말로 답하면 피드백을 받고, 한 가지를 고쳐 같은 질문에 다시 답해 전후를 비교하는 음성·영상 면접 연습 도구 (MVP)
- **흐름**: 질문 선택 → 음성 질문 → 준비 30초 → 60/90초 답변(실시간 글자 변환) → 글 확인·수정 → 피드백 → 재답변 → 전후 비교
- **피드백 구성**: 다음에 고칠 한 가지, 잘한 점, 고칠 점, 바꿔 말하기 예시, 5개 항목 점수, 말하기 지표(길이·속도·군말)
- **영상 모드(선택)**: 시선·억양·템포 분석(Google MediaPipe, 기기 내 처리)
- **형태 / 배포**: GitHub Pages(빌드·설치 없음). AI 피드백용 중계 서버는 Cloudflare Workers
- **소스**: eunkyoungAn/- 저장소 `interview/` (`worker/` 포함)

## 2. Uses
### 의도한 사용
- 강의 현장에서 구직자가 QR·링크로 접속해 면접 답변을 연습하고 개선점을 확인한다.
- 강사는 질문 번호(`q`)와 답변 시간(`t`)을 링크로 지정해 수업에 맞게 배포한다.
### 응용 사용
- 면접 특강 실습, 1:1 컨설팅 사전·사후 과제, 질문 목록·평가 기준 교체를 통한 직무별 확장
### 쓰면 안 되는 경우
- **점수를 합격 가능성 예측으로 해석하는 경우** (점수는 연습용 참고 지표이며 첫 화면에서도 고지)
- 간이 피드백을 내용 평가로 신뢰하는 경우 (낱말 규칙 계산이라 내용 판단은 거침)
- 시선·억양 분석을 평가·선발 목적으로 사용하는 경우 (실제 얼굴로 검증 전)
- 개인정보가 담긴 실제 사례(실명·기밀)를 답변에 입력하는 경우

## 3. Bias, Risks, and Limitations
- **음성 인식 의존**: 브라우저 내장 기능(Chrome·Safari)을 쓰며 기기별 품질이 다르다. 미지원 시 글로 답한다. 군말이 누락되어 실제보다 적게 집계될 수 있다.
- **점수 기준 미검증**: 간이 피드백의 기준값은 기획안 루브릭 기반의 초기값이며 강사 채점과의 일치도는 아직 검증하지 않았다.
- **영상 분석 미검증**: 시선 분석은 실제 얼굴로 검증하지 않았다. 안경·조명·카메라 각도·기기 차이에 따라 오차가 생길 수 있다.
- **AI 판단의 한계**: AI 피드백은 루브릭 기반 참고 의견이며 면접관의 실제 평가와 다를 수 있다.
- **환경 제약**: 카카오톡 인앱 브라우저에서는 마이크가 막힐 수 있다. 일부 기기는 녹화 중 음성 인식이 동시에 되지 않는다.
### 권고
- 강사가 파일럿에서 직접 매긴 점수와 비교한 뒤 기준값을 조정한다.
- 아이폰·갤럭시·카카오톡 인앱 브라우저에서 사전 점검 후 수업에 쓴다.

## 4. How to Get Started
- **참여자**: 링크 또는 QR 접속 → Chrome(안드로이드)·Safari(아이폰)에서 열기 → 질문 선택 → 답변 → 피드백 확인 → 필요하면 이미지·PDF·글로 저장
- **강사**: 첫 화면 `강사용 설정`에 AI 서버 주소·수업 코드를 입력하고 배포 링크 복사(AI 피드백 사용 시). 예: `?q=1,4,7,14&t=60`
- **AI 서버 배포(1회)**: `interview/worker`에서 Cloudflare Workers 배포, API 키와 수업 코드는 비밀값으로 등록. 상세는 `interview/README.md`
- 안내 문구·QR·안내 이미지: `interview/SHARE.md`

## 5. Data
- **입력**: 음성 또는 글 답변, (영상 모드) 카메라 영상
- **녹음 파일**: 만들지 않는다. 말한 소리는 브라우저 음성 인식이 글자로 변환한다(Chrome은 Google, 아이폰 Safari는 Apple 음성 인식을 거침). 이 앱의 서버로는 소리가 전달되지 않는다.
- **영상·분석 결과**: 서버로 보내지 않는다. 얼굴 인식 모델·라이브러리도 사이트 내(`vendor/mediapipe/`)에서 불러온다.
- **AI 피드백 사용 시**: 질문과 답변 글만 중계 서버를 거쳐 AI에 전달한다. 서버는 답변을 저장하거나 기록하지 않는다. 허용된 사이트 주소와 수업 코드가 맞는 요청만 처리한다.
- **사용자 추가 질문**: 해당 휴대폰 브라우저에만 저장(최대 20개, 150자)
- **회원·로그인**: 없음. 화면을 닫으면 답변이 사라진다.
- 한계: 음성 인식과 AI 호출은 해당 서비스 제공사의 정책을 따른다.

## 6. Evaluation
