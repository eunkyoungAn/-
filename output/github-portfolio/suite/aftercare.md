# Card: 내일동행 · 고용서비스 사후관리

## 1. Details
- **설명**: 구직자별 고용서비스 제공 내역과 사후관리 이력을 **담당자의 PC·브라우저 안에 암호화하여 보관**하는 웹앱
- **사용자**: 취업지원 담당자(상담·사후관리 실무자)
- **주요 기능**: 담당자·구직자 등록, 관리 기간 지정, 서비스·결과·다음 연락일·증빙 기록, 엑셀/CSV 일괄 등록, PDF·CSV·PNG·증빙 ZIP 출력, 암호화 백업·복원
- **형태 / 배포**: 외부 라이브러리·분석 추적·폰트 요청이 없는 정적 파일, GitHub Pages
- **소스**: eunkyoungAn/- 저장소 `aftercare/`

## 2. Uses
### 의도한 사용
- 담당자가 본인이 맡은 구직자의 서비스 이력과 사후관리 일정을 한 곳에서 관리한다.
- 관리 기간 종료 시 대상·기간·서비스별 증빙을 출력한다.
### 응용 사용
- 소규모 사업 단위의 개인 업무 기록 도구, 사후관리 절차 교육용 실습 도구
### 쓰면 안 되는 경우 (사용을 권고하지 않는 경우)
- **담당자 개인이 직접 관리하기 어려운 경우**: 암호 관리, 백업, 기기 관리를 본인이 책임질 수 없는 환경
- **지속 운영이 보장되지 않는 경우**: 담당 교체·사업 종료 뒤에도 기록을 인수인계하거나 보관할 체계가 없는 경우
- **지속적인 피드백과 개선이 불가능한 경우**: 운영 중 발견되는 문제를 반영하고 업데이트를 관리할 주체가 없는 경우
- 기관 공동 열람, 다수 담당자 동시 편집, 기기 간 자동 동기화가 필요한 업무

## 3. Bias, Risks, and Limitations
- **복구 불가**: 암호를 분실하거나 백업 없이 브라우저 자료를 삭제하면 복구할 수 없다.
- **개인 단위 저장**: 기관 공동 저장·로그인·자동 동기화가 없다. 주소나 브라우저 프로필이 바뀌면 별도 저장소로 취급된다.
- **보호 범위의 한계**: 화면을 열어 둔 상태와 내려받은 출력물(PDF·CSV·PNG)은 암호화 저장소의 보호 범위 밖이다. 같은 브라우저 저장소는 한 탭에서만 열리고, 10분간 사용하지 않으면 잠긴다.
- **개인정보 마스킹 범위**: 이름 가리기는 기본 인적사항에만 적용된다. 자유 입력 내용과 원본 증빙의 개인정보는 사용자가 직접 확인해야 한다.
- **증빙 효력**: 진행 요약 PNG는 입력 자료를 요약한 이미지이며 실제 진행을 증명하는 원본 자료가 아니다.
- **용량 제한**: 파일 1개 3MB, 기록당 10개, 저장소 전체 증빙 약 30MB
### 권고
- 사용 전 암호 관리·백업 주기·인수인계 방식을 정한다.
- 이 저장소는 공개이므로 **실제 구직자 자료와 암호화 백업 파일을 저장소에 올리지 않는다.**
- 소속 기관의 개인정보·정보보안 지침이 우선한다. [확인 필요: 기관 지침과의 적합성 검토]

## 4. How to Get Started
1. 12자 이상의 암호로 저장소를 만든다.
2. 담당자를 등록한다(담당자 명부이며 로그인 계정이 아님).
3. 구직자에게 담당자와 관리 시작일·종료일을 지정한다(엑셀·CSV 일괄 등록 가능).
4. 서비스·결과·다음 연락일·증빙을 등록한다.
5. 출력·증빙에서 PDF·CSV·PNG·증빙 ZIP으로 저장한다.
6. 보안·백업에서 암호화 백업을 받고 저장소를 잠근다.

## 5. Data
- **저장 위치**: 담당자 브라우저의 IndexedDB. 기록과 첨부파일을 하나의 암호화 묶음으로 저장한다.
- **암호화**: AES-256-GCM, 키 파생은 PBKDF2-SHA256 600,000회. 암호와 키는 서버로 전송하지 않는다.
- **외부 전송**: 없음(CSP로 외부 연결 차단). 엑셀·CSV 파일은 브라우저 안에서만 읽고 전송·보관하지 않는다.
- **운영자 보유 정보**: 없음(운영자는 사용자 자료에 접근하지 않는다). 보유기간·삭제 책임은 사용하는 담당자·기관에 있다.

## 6. Evaluation
- **현재 상태**: 기능과 보안 설계는 문서화되어 있으나, **정량 검증 결과와 현장 적용 결과는 아직 기록하지 않았다.**
