## 사용 흐름
경험이 이미 정리되어 있으면 2번부터 시작하고, 경험 찾기가 어렵다면 1번에서 시작합니다.

```
(경험 찾기가 어렵다면) 1. 기업·경험 찾기 → 2. 자기소개서 작성 → 3. 포트폴리오 작성
```

## 처음 쓰기 전에
1. 무료 Gemini API 키를 준비합니다 (aistudio.google.com/apikey, 약 1분).
2. **1번 서비스는 첫 실행에 4~5분이 걸릴 수 있습니다.** DART 전체 기업코드를 불러오기 때문이며, 이후 같은 기업은 6시간 캐시됩니다.
3. 생성 결과는 AI 초안입니다. 반드시 본인이 읽고 고쳐서 사용하세요.

## 개인정보 보호 설계
세 서비스 모두 **사용자 본인의 API 키**로 작동하고, **키를 저장하지 않도록** 만들었습니다. 운영자가 사용자의 AI 계정·비용·사용 내역에 접근하지 않습니다.
