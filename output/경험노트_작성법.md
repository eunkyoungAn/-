# 미리 준비하는 경험노트 작성법
> 취업 준비생을 위한 자기소개서·면접 대비 실전 가이드

## 1. 경험노트가 왜 필요한가
- 자소서 문항은 회사마다 달라 보여도 대부분 **성취, 협업·갈등, 실패·극복, 도전, 직무역량, 가치관** 같은 질문 유형으로 묶인다. 소재를 미리 정리해 두면 문항마다 처음부터 쓰지 않고 골라서 조합하면 된다.
- 면접 꼬리질문("그때 수치는?", "본인 역할은?", "다시 한다면?")은 기억이 흐릿하면 답하기 어렵다. 노트에 적어 둔 구체적 사실이 답변의 근거가 된다.
- 경험은 시간이 지나면 디테일부터 잊힌다. 그래서 **경험한 직후에 기록하는 것**이 가장 정확하다.

## 2. 4단계 작성 프로세스

### 1단계: 경험 전수 조사 (브레인스토밍)
판단은 미루고 일단 전부 적는다. 시기별·영역별로 훑으면 빠뜨리는 것이 적다.
| 영역 | 예시 |
|---|---|
| 학업 | 팀 프로젝트, 졸업작품, 수업 과제, 연구실 |
| 대외활동 | 동아리, 서포터즈, 공모전, 봉사 |
| 일 경험 | 인턴, 아르바이트, 현장실습 |
| 개인 | 자격증, 독학, 여행, 운동·취미, 사이드 프로젝트 |
| 위기 | 실패, 갈등, 포기했다가 다시 한 일 |

- 적은 소재가 20개 이상이면 충분하다. "사소해 보이는 것"도 포함한다(아르바이트 클레임 대응도 좋은 소재가 된다).

### 2단계: 구조화 (STAR+L)
경험 하나당 아래 틀로 정리한다.
- **S (Situation)**: 언제, 어디서, 어떤 상황이었나
- **T (Task)**: 해결해야 할 과제나 목표는 무엇이었나
- **A (Action)**: **내가** 한 행동(팀이 아닌 본인 중심, 2~3가지)
- **R (Result)**: 결과. 수치가 있으면 수치로 적는다(전/후 비교)
- **L (Learning)**: 배운 점, 그리고 직무에서 어떻게 쓸 수 있나

### 3단계: 역량 태깅
경험마다 드러나는 역량을 2~3개 태그로 붙인다(예: #문제해결 #협업 #꼼꼼함 #데이터분석 #고객지향). 지원 직무의 채용공고·인재상에 나온 키워드와 맞춰 보면, 비어 있는 역량이 무엇인지 보인다.

### 4단계: 문항 매핑과 주기적 업데이트
- 자주 나오는 질문 유형별로 대표 경험 1개 + 예비 경험 1개를 정해 둔다.
- 한 경험은 여러 각도로 쓸 수 있다(같은 프로젝트를 '갈등 해결'로도, '성과'로도).
- 새 경험이 생기면 바로 추가하고, 지원 시즌 전에 한 번씩 정리한다.

## 3. 경험노트 템플릿 (복사해서 사용)
```
### [경험명]
- 기간/소속:            - 내 역할:
- 역량 태그: #   #   #
- S 상황:
- T 과제/목표:
- A 내 행동: 1)        2)        3)
- R 결과(수치):
- L 배운 점 / 직무 연결:
- 증빙(사진, 결과물, 링크):
- 예상 꼬리질문과 답:
  - Q: 가장 어려웠던 점은?  A:
  - Q: 다시 한다면?        A:
- 활용 문항: [ ]성취 [ ]협업·갈등 [ ]실패 [ ]도전 [ ]직무역량
```

## 4. 작성 예시
### 카페 아르바이트 재고 관리 개선
- 기간/소속: 2025.03~2025.12 / ○○카페 / 내 역할: 마감 담당
- 역량 태그: #문제해결 #데이터관리 #주도성
- S: 원두·우유 재고를 감으로 발주해서 품절과 폐기가 반복됨
- T: 폐기 비용 줄이기, 품절 없애기
- A: 1) 4주간 요일별 판매량을 엑셀로 기록 2) 요일별 발주 기준표 작성 3) 점장에게 제안해 전 직원 공유
- R: 월 폐기액 약 30% 감소, 해당 기간 품절 0회 (수치는 예시)
- L: 작은 기록이 의사결정 근거가 된다는 것을 배움 → 데이터 기반 업무 개선으로 연결
- 활용: 문제해결, 직무역량(데이터), 주도성 문항

## 5. 잘 쓰는 원칙
1. **"우리" 대신 "나"**: 팀 성과 안에서 본인의 행동을 분리해서 적는다.
2. **숫자와 고유명사**: "많이 개선"보다 "3주 만에 20% 단축"처럼 쓴다. 정확한 수치가 없으면 추정치임을 밝힌다.
3. **과정 > 결과**: 결과가 작아도 판단 근거와 행동이 구체적이면 충분하다.
4. **실패도 자산**: 실패 경험은 원인 분석과 이후 달라진 행동까지 적어 둔다.
5. **사실만 기록**: 부풀린 내용은 면접 꼬리질문에서 드러난다.

## 6. 자주 하는 실수
- 활동 목록(이력서)처럼 나열만 하고 행동·결과가 없음
- 경험 하나를 모든 문항에 돌려 씀 → 면접에서 단조롭게 보임
- 지원 직무와 연결(L)을 빼먹음
- 지원 시즌 직전에 몰아서 작성해 디테일이 사라짐

## 7. 실행 체크리스트
- [ ] 경험 소재 20개 이상 나열했다
- [ ] 핵심 경험 8~10개를 STAR+L로 정리했다
- [ ] 각 경험에 역량 태그와 수치를 넣었다
- [ ] 질문 유형별 대표/예비 경험을 정했다
- [ ] 경험마다 꼬리질문 2개 이상에 답을 준비했다
- [ ] 월 1회 업데이트 일정을 잡았다

## 8. 활용 팁
- 도구: 노션·구글 시트(태그 필터)·한글/워드 어느 것이든 좋다. 검색과 필터가 되는 도구가 편하다.
- 면접 전: 경험별 1분 답변 버전을 소리 내어 연습한다.
- 자소서 작성 시: 문항 키워드 → 태그 검색 → STAR 뼈대에 회사·직무 맞춤 문장을 입힌다.
