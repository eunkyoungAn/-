ROOM 1 · 목표 정하기

탈출 목표를 입력하세요

준비물(내 Gemini 키)과 필수 정보 3개만 입력하면 직무 맞춤 질문이 시작됩니다.

준비물 · 나의 Gemini API 키 *

이 게임의 질문과 자기소개서는 구글 Gemini AI가 만듭니다. 각자 본인 키로 작동하므로 무료로 쓸 수 있습니다. 입력한 내용은 이 앱의 서버(Google Apps Script)를 거쳐 Gemini로 전달되고, 이름·이메일·답변과 결과는 결과 메일 발송과 이어하기를 위해 운영자의 Google 시트에 저장됩니다.

키 발급받는 방법 (1분, 무료)
  1. aistudio.google.com/apikey 접속 후 구글 계정으로 로그인합니다.
  2. API 키 만들기(Create API key) 버튼을 누릅니다.
  3. 발급된 키가 나오면 복사 버튼을 눌러 키 전체를 복사합니다.
  4. 위 칸에 붙여넣고 키 확인을 누르세요.

키는 이 브라우저에만 저장되어 다음 접속 때 다시 입력하지 않아도 됩니다. 요청을 처리할 때만 서버를 거치며, 운영자의 시트에는 저장되지 않습니다. 공용 PC에서는 사용 후 아래 키 지우기를 눌러주세요.

상장사·공시 대상 기업은 DART 공시(직원 수·평균 연봉·매출 등)를 함께 분석합니다. 이 경우 첫 질문까지 1~2분 걸릴 수 있어요.
