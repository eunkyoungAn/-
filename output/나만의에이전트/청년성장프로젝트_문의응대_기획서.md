# 나만의 에이전트 기획서 (실습 8) — 청년 성장프로젝트 문의 응대·자료 갱신

작성일: 2026-11-15 / 상태: 초안(대표 확인 전)

| 번호 | 칸 | 내가 적을 내용 |
|---|---|---|
| 1 | 자동화할 업무 | 청년 대상 성장프로젝트 맞춤형 프로그램 운영 중 **고객 문의 답변**과 **내부자료(명단·출석부·FAQ) 업데이트** |
| 2 | 누가 쓰나 | 나 혼자 |
| 3 | 입력 자료 | 문의 원문(전화·문자 메모, 이메일, 신청폼·설문 댓글), 참여자 명단·출석부(구글 시트), 자주 묻는 질문 정리본 |
| 4 | 지금 하는 순서 | 문의 확인 → 기억·명단을 보고 바로 답변 → 시간 날 때 시트·FAQ에 몰아서 반영 (이 단계에서 누락이 생김) |
| 5 | AI에게 맡길 일 | 문의 읽기 → 유형 분류(일정·신청·출석·준비물·기타) → 명단·FAQ와 대조 → 답변 초안 → 시트·FAQ 변경안 표 작성 |
| 6 | 담당자가 판단할 일 | 수료·출석 인정(결석 사유 인정, 보충, 수료 기준 예외) |
| 7 | 어디에 저장하나 | 구글 드라이브·시트 |
| 8 | 사람 확인 지점 | 시트·FAQ 반영 직전 (변경안 표를 보고 승인한 뒤에만 반영) |

## 노드 흐름

```
[문의 입력] 전화·문자 메모 / 이메일 / 신청폼 댓글
      ↓
[1 읽기·분류] 문의 유형, 대상자, 요청 내용 정리
      ↓
[2 대조] 참여자 명단·출석부, FAQ에서 근거 찾기
      ↓
   ┌─ 수료·출석 인정 관련? ─ 예 → [담당자 판단 요청] 근거만 정리해 넘김
   └─ 아니오
      ↓
[3 답변 초안] 근거(시트 행, FAQ 항목) 표시, 확인 안 된 내용은 "확인 필요"
      ↓
[4 변경안 표] 시트·FAQ에 바꿀 내용: 위치 / 기존 값 / 새 값 / 근거 문의
      ↓
[사람 확인] 변경안 승인  ← 양식 8번
      ↓
[5 반영·기록] 승인된 항목만 시트·FAQ에 반영, 처리 기록 남김
```

## 구분 표시

- [자료 근거] 1~4, 6~8번 칸은 대표 인터뷰 답변(2026-11-15)을 그대로 옮김
- [추론·제안] 5번 칸의 분류 유형과 노드 흐름은 답변을 바탕으로 한 제안. 확정 전 확인 필요
- [추론·제안] 답변은 전화·문자·메일로 바깥에 나가므로, 발송도 대표가 직접 하는 것을 전제로 함(AI는 초안까지만)
