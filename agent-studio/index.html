우리 기관 · 반복 업무 6종

    자료는 이 브라우저 안에서만 처리합니다. 서버나 저장소로 올리지 않습니다.

    입력

    * 표시는 반드시 채웁니다.

    자료

    xlsx, xls, csv, txt, md 파일을 여러 개 올릴 수 있습니다.
    이름·연락처 같은 개인정보 열은 AI에 보내기 전에 자동으로 지웁니다.

    파일 고르기

    파일 창이 열리지 않거나 파일이 흐리게 보여 고를 수 없으면, 엑셀에서 표를 복사해 아래 "본문 붙여넣기" 칸에 붙여넣어 주세요. 같은 방식으로 개인정보 열을 지웁니다.

      붙여넣은 표도 개인정보 열을 지우고, 전화번호·이메일·주민번호는 가린 뒤 보냅니다.
      공식 자료 검색

      공공기관 누리집에서만 찾도록 검색 주소를 만들어 드립니다. 새 창에서 원문을 열어 확인한 뒤, 자료명·발행기관·발행일·주소와 필요한 부분을 아래에 붙여넣어 근거로 추가합니다. 발행기관이나 발행일이 비어 있는 자료는 수치 근거로 쓰지 않습니다.

      이 주소에서는 AI 실행을 쓸 수 없습니다. claude.ai에 로그인한 브라우저(사파리, 크롬, 삼성 인터넷)에서 아래 주소로 열면 파일 올리기와 실행이 모두 됩니다.

      https://claude.ai/artifact/M5QqF3H1j9iySycbZSzqjQ

      여기서 올린 자료를 옮기려면 "정리된 자료 복사"를 누른 뒤, 위 주소 화면의 "본문 붙여넣기" 칸에 붙여넣습니다. 개인정보 열은 이미 지워진 상태로 복사됩니다.

      결과

      실행하면 결과가 여기에 표시됩니다. 마지막 확인은 담당자가 합니다.
      Word는 바로 저장됩니다. 한글은 zip 하나로 묶여 저장되니 압축을 풀어 1번 파일을 엽니다. 처음 누를 때 보고서 양식으로 정리하느라 1~2분 걸릴 수 있습니다.
        실행 탭에 적은 내용과 자료가 바로 반영됩니다. 개인정보 열은 지운 뒤의 자료입니다.
