# 여행지 분석

## 언제 쓰나
- 사용자가 여행지 이름을 말하며 분석이나 비교를 요청할 때

## 순서
1. 여행지, 일정, 인원을 확인한다. 말하지 않았으면 1박 2일, 2인, 서울 출발로 정하고 그렇게 정했다고 밝힌다.
2. 아래 결과 형식의 표를 만든다.
3. 가격, 운영 시간, 축제 날짜처럼 바뀌는 정보는 단정하지 않고 '확인' 칸에 [확인 필요]라고 적는다.
4. 표 아래에 직접 확인할 곳 두 군데(지자체 관광 누리집 등)를 적는다.
5. 여행지가 두 곳 이상이면 같은 항목으로 나란히 비교하고, 마지막에 한 줄 추천을 붙인다.
