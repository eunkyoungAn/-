메일은 한 번에 보내고, 카드뉴스는 시트 한 줄로

반복하는 업무 두 가지를 AI로 자동화합니다. 실습 1에서는 Gemini가 만든 Apps Script 코드로 이름을 넣은 메일을 한 번에 보내고, 실습 2에서는 시트에 기획 한 줄을 쓰면 Gemini·ChatGPT·Canva가 카드뉴스를 만듭니다. 코딩을 몰라도 됩니다. AI가 만들고, 여러분이 확인하고 결정합니다.

      두 실습 모두 구글 시트에서 시작해 결과를 시트에 남깁니다. 실습 1에서 익힌 Apps Script가 실습 2의 자동 생성 버튼으로 이어집니다.
      0 / 7검수까지 마친 단계
      실습 1의 4단계와 실습 2의 3단계 가운데 검수 항목을 모두 확인한 단계를 셉니다. 메모와 검수 표시는 이 기기에만 저장됩니다.
      시작 전 1계정 로그인

      크롬에서 Google 계정으로 로그인합니다. 실습 2에서는 ChatGPT와 Canva도 씁니다. 요금제에 따라 연결 기능이 다를 수 있습니다.

      시작 전 2보낼 메일과 시트

      3회차 실습 1의 회의 안내 메일을 열어 둡니다. 실습 2에서 쓸 카드뉴스 운영 시트 사본을 미리 만들어도 됩니다.

      시작 전 3예시 정보만 사용

      메일은 내 주소와 동의를 받은 주소만, 카드뉴스는 예시 주제로 연습합니다. API 키는 비밀번호처럼 나만 봅니다.

      TIMELINE

      시간표 (약 3시간 30분)

      첫 8분은 "나는 어떤 AI 사용자?" 점검입니다. 개념 64분, 실습 126분(60%), 휴식 20분. 실습은 실습 1(메일 자동화 34분)과 실습 2(카드뉴스 92분)입니다.

      MATERIALS

      요청문과 참고 코드

      두 실습에서 쓰는 요청문, 프로젝트 지침, 참고 코드를 모았습니다. 각 단계 화면에도 같은 내용이 있습니다.

      SAFETY

      실제 업무에 쓸 때

      AI가 작성하고, 사람이 확인합니다.

      메일은 받는 사람에게 보내도 되는지(수신 동의) 먼저 확인하고, 개인 Gmail 계정은 Apps Script로 하루 100명까지 보낼 수 있으므로 인원이 많으면 나눠 보냅니다. 카드뉴스의 가격·제품 사양·건강 효과는 공식 자료로 직접 확인합니다. 주민등록번호, 계좌번호, 고객 명단, 회사 내부자료는 요청문에 넣지 않습니다. 다른 사람이 보낸 시트나 코드에서 "확인되지 않은 앱" 승인 화면이 뜨면 출처를 모를 때는 허용하지 않습니다.
