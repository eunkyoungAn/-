  1. 아래에서 쓸 스킬의 zip 파일을 받습니다. 압축을 풀지 않습니다.
  2. claude.ai → 설정 → 기능 → 스킬에서 받은 zip 파일을 그대로 올립니다.
  3. 새 채팅에서 자료를 첨부하고 평소처럼 요청합니다. 예: "첨부한 공고문을 RFP 분석해 줘. 우리 기관 정보도 첨부함."

        RESULT FILES
        
결과를 파일로 받기

        
스튜디오에서 실행이 끝나면 결과 아래에 형식을 고르는 칸이 나옵니다. 형식을 바꿔 여러 번 받을 수 있습니다. 보고서 작성은 한 장 보고서 / 3장 이내 보고서 / 분석 결과 전체 가운데 무엇을 받을지도 고릅니다.

        

          
형식받는 파일참고

          
            
한글 (hwpx)…_hwpx.zip압축을 풀면 hwpx 파일이 나옵니다. 한글 2014 이상에서 열립니다.

            
워드 (docx)….docx표가 워드 표로 들어갑니다.

            
PDF….pdf보기 · 인쇄용입니다. 글자를 고칠 수 없습니다.

            
한글 옛 형식 (hwp)…_hwpx.ziphwpx로 저장됩니다. 한글에서 열어 [파일 → 다른 이름으로 저장 → 한글 문서(*.hwp)]를 고릅니다.

            
글 파일 (md)….md메모장에서 열립니다.

          

      


      

        TROUBLESHOOTING
        
오류가 나는 대표 사유

        
화면에 나온 문구로 찾습니다. 붉은 상자가 나오면 그 안의 안내를 먼저 따릅니다. 끝내 실행되지 않으면 각 실습 맨 아래의 "Claude 채팅에서 하기" 지시문을 복사해 같은 결과를 얻을 수 있습니다.

        
강사 스튜디오 링크는 누구나 열 수 있지만, "에이전트 실행"은 만든 사람 계정에서만 됩니다.
Claude의 공유 규칙입니다. 링크로 공유한 사이트를 만든 사람이 아닌 계정으로 열거나 로그인하지 않고 열면, 화면은 보이지만 Claude를 부르는 부분(실행)과 캘린더 연결은 동작하지 않습니다. 로그인해도 같습니다. 직접 실행하려면 "내 스튜디오 만들기"로 내 계정의 스튜디오를 만들거나, 각 실습 맨 아래의 "Claude 채팅에서 하기"를 씁니다. 이 실습실의 복사 단추가 듣지 않으면 글 상자가 선택된 상태가 되므로 Ctrl+C로 복사합니다.
