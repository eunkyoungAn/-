        RESULT FILES
        
결과를 파일로 받기

        
스튜디오에서 실행이 끝나면 결과 아래에 형식을 고르는 칸이 나옵니다. 형식을 바꿔 여러 번 받을 수 있습니다. 보고서 작성은 한 장 보고서 / 3장 이내 보고서 / 분석 결과 전체 가운데 무엇을 받을지도 고릅니다.

        

          
형식받는 파일참고

          
            
한글 (hwpx)…_hwpx.zip압축을 풀면 hwpx 파일이 나옵니다. 한글 2014 이상에서 열립니다.

            
워드 (docx)….docx표가 워드 표로 들어갑니다.

            
PDF….pdf보기 · 인쇄용입니다. 글자를 고칠 수 없습니다.

            
한글 옛 형식 (hwp)…_hwpx.ziphwpx로 저장됩니다. 한글에서 열어 [파일 → 다른 이름으로 저장 → 한글 문서(*.hwp)]를 고릅니다.

            
글 파일 (md)….md메모장에서 열립니다.

          

      


      

        TROUBLESHOOTING
        
안 될 때

        
스튜디오 화면에 붉은 상자가 나오면 그 안의 안내를 먼저 따릅니다. 끝내 실행되지 않으면 각 실습 맨 아래의 "Claude 채팅에서 하기" 지시문을 복사해 같은 결과를 얻을 수 있습니다.

        

          
화면에 나온 것왜 그런가할 일

          
            
붉은 상자 "이 화면에서는 에이전트를 실행할 수 없음"로그인하지 않은 화면에서 스튜디오 링크를 열었습니다.크롬이나 엣지에서 claude.ai에 로그인한 뒤, 같은 브라우저에서 링크를 다시 엽니다.

            
붉은 상자 "실행하지 않았음 — 아래 항목이 비어 있음"별표(*) 칸이나 자료가 비어 있습니다.적힌 항목을 채웁니다. 자료는 파일 목록에 "읽음"이 보여야 합니다.

            
파일 이름 아래 붉은 글씨 "읽지 못함"읽을 수 없는 형식이거나, 기관 네트워크가 읽기 도구를 막았습니다.붉은 안내대로 합니다. 급하면 내용을 복사해 "본문 붙여넣기" 칸에 넣습니다.

            
"Claude에게 요청함 (○초 지남)"에서 멈춰 있다허용을 묻는 창이 떠 있거나, 응답을 기다리는 중입니다.화면에 뜬 창에서 허용을 누릅니다. 3분이 넘으면 중지하고 다시 실행합니다.

            
"요청이 많아 잠시 제한됨"짧은 시간에 여러 번 실행했습니다.1~2분 뒤 다시 실행합니다.

            
파일 받기를 눌렀는데 저장 창이 안 뜬다저장 창이 이미 떠 있습니다.한 번 더 누릅니다. 그래도 안 되면 "결과 복사"로 한글에 붙여 넣습니다.

            
이 실습실에서 복사 단추가 듣지 않는다브라우저가 복사를 막았습니다.글 상자가 선택된 상태가 되므로 Ctrl+C로 복사합니다.
