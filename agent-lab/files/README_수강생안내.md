# 업무 에이전트 설계와 실습 — 수강생 실습 자료

> 모든 자료는 교육·실습용 가상 자료임. 실제 기관·인물·수치가 아니다.

노트북(크롬 또는 엣지)에서 claude.ai에 로그인한 상태로 진행한다.

## 전체 순서

| 순서 | 할 일 | 볼 파일 |
|---|---|---|
| 1 | 이 압축 파일을 푼다 | — |
| 2 | 강사가 안내한 사이트 링크를 연다 | 아래 주소 |
| 3 | 사이트에서 실습 1부터 차례로 한다 | 각 실습 폴더의 `프롬프트.md` |
| 4 | 결과를 한글(hwpx) · 워드 · PDF 가운데 골라 파일로 받는다 | 사이트의 "결과를 파일로 받기" |
| 5 | 마지막에 내 업무용 MD 파일을 받는다 | `실습8_나만의에이전트/` |

## 2번 — 사이트 열기

업무 에이전트 스튜디오: https://claude.ai/artifact/KZ8jbQyiu3qHRkMRhjxe93

링크를 열면 에이전트 7종과 노드 순서가 이미 들어 있다. 따로 만들 것이 없고, Claude 채팅에서 어떤 모델을 골랐는지와 상관없이 같은 화면이 열린다.

### (선택) 내 사이트를 따로 갖고 싶을 때

교육 뒤 기관명·문서 규칙을 넣은 내 사이트를 갖고 싶으면 `나만의스튜디오_만들기/시작하기.md`를 따라 한다. 실습에는 필요하지 않다.

## 3번 — 사이트에서 실습하기

1. 왼쪽에서 에이전트를 고른다.
2. 실습 폴더의 `프롬프트.md`에 있는 표대로 칸을 채운다.
3. 자료 파일을 칸에 끌어다 놓는다. 파일 목록에 **"읽음 · ○○자"**가 보여야 들어간 것이다.
4. **에이전트 실행**을 누른다. 처음에 허용을 묻는 창이 뜨면 **허용**을 누른다.
5. "노드 진행"에 지금 어느 단계인지 표시되고, 그 아래에 결과가 나온다.
6. `프롬프트.md` 맨 아래 "결과에서 볼 것"으로 결과를 점검한다.

| 폴더 | 사이트 에이전트 | 올릴 자료 |
|---|---|---|
| `실습1_보고서작성/` | 보고서 작성 | `가상데이터_교육과정운영실적.xlsx` |
| `실습2_기획안작성/` | 기획안 작성 | `가상데이터_수강생VOC.xlsx` |
| `실습4_RFP분석/` | RFP 서류 분석 | `공고문_가상.md` + `우리기관_정보.md` |
| `실습5_참여자문의응대/` | 참여자 문의 응대 (심화) | `모집요강_안내자료.md` + 문의 한 건 |
| `실습6_참여자데이터관리/` | 고객 데이터 관리 (심화) | `가상데이터_참여자명단.xlsx` |
| `실습7_일정관리/` | 일정 관리 | 캘린더 불러오기 또는 `가상일정_붙여넣기용.md` |
| `실습8_나만의에이전트/` | 나만의 에이전트 | 빈칸 양식을 채워 입력 |

실습 번호는 강의안의 번호와 같다. 실습 3은 이번 과정에서 다루지 않는다.
실습 2는 실습 4의 결과를 이어받을 수 있다(결과 아래 "이 결과로 기획안 만들기" 단추).

## 4번 — 결과를 파일로 받기

결과 아래 "결과를 파일로 받기"에서 형식을 고르고 **파일 받기**를 누른다. 형식을 바꿔 여러 번 받을 수 있다.

| 형식 | 참고 |
|---|---|
| 한글 (hwpx) | 압축(zip)으로 저장된다. 풀면 hwpx 파일이 나온다 |
| 워드 (docx) | 표가 워드 표로 들어간다 |
| PDF | 보기 · 인쇄용. 글자를 고칠 수 없다 |
| 한글 옛 형식 (hwp) | hwpx로 저장된다. 한글에서 열어 [다른 이름으로 저장 → hwp] |
| 글 파일 (md) | 메모장에서 열린다 |

보고서 작성은 한 장 보고서 / 3장 이내 보고서 / 분석 결과 전체 가운데 무엇을 받을지도 고른다.

## 5번 — 교육 뒤에도 쓰는 것 (실습 8)

실습 8의 산출물은 기획서 한 장, 내 업무에 맞춘 MD 파일(`<name>_SKILL.md`), 직접 활용 계획이다.
교육 뒤 1주 안에 가상 자료로 한 번, 2주 안에 개인정보를 지운 실제 자료 사본으로 한 번 써 본다.
고친 점은 MD 파일의 "고쳐 쓴 기록"에 적고, 계획은 `직접활용_계획표.md`에 적는다.

## 안 될 때

화면에 붉은 상자가 나오면 그 안의 안내대로 한다. 증상별 대처는 `나만의스튜디오_만들기/시작하기.md`의 "안 될 때" 표에 있다.
사이트에서 실행이 끝내 되지 않으면 각 `프롬프트.md`의 "방법 B"(지시문을 Claude 채팅에 붙여넣기)로 같은 결과를 얻을 수 있다.

## 지킬 것

- 실습 중에는 가상 자료만 쓴다. 실제 업무 자료는 이름·연락처를 지운 사본만 쓴다.
- 결과물의 수치는 대조표로 원자료와 맞춰 본다. 마지막 확인은 사람이 한다.
- AI가 만든 답변·안내문은 담당자가 확인한 뒤에 보낸다.
