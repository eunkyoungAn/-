# 실습 1 — 보고서 작성 (데이터 분석 → 한 장 보고서)

> 교육·실습용 가상 자료임. 스튜디오의 "보고서 작성" 에이전트와 같은 지시문이다.

준비 파일: `가상데이터_교육과정운영실적.xlsx` (8개 과정, 수강생 240명) · 선택: `../양식/한장보고서_양식.hwpx`
걸리는 시간: 실행 3~5분, 결과 확인 10분

---

## 방법 A — 사이트에서 하기 (권장)

1. 강사가 안내한 사이트를 연다: https://claude.ai/artifact/KZ8jbQyiu3qHRkMRhjxe93 (내 사이트를 따로 만들었다면 그 링크를 써도 된다)
2. 왼쪽 목록에서 **보고서 작성**을 누른다.
3. 아래 값을 입력 칸에 넣는다. "세계관 값 채우기" 단추를 누르면 기관명이 채워진다.

| 칸 | 넣을 내용 |
|---|---|
| 보고서 제목 | 2026년 상반기 직업교육과정 운영 성과 분석 및 하반기 개선 방안 |
| 기관명 | 남원교육발전소 |
| 대상 기간 | 2026년 상반기 |
| 독자 | 센터장 (의사결정용) |
| 특별히 보고 싶은 것 | 온라인 과정 수료율, 취업 취약 집단 |
| 진행 방식 | 가정을 밝히고 끝까지 진행 |
| 분석할 데이터 | `가상데이터_교육과정운영실적.xlsx` 끌어다 놓기 |

4. **에이전트 실행**을 누른다. 첫 글자가 나오기까지 1~2분 걸릴 수 있다.
5. 끝나면 결과 아래 "결과를 파일로 받기"에서 한글(hwpx) · 워드 · PDF 가운데 골라 받는다. 한 장 보고서 / 3장 이내 보고서 / 분석 결과 전체 가운데 무엇을 받을지도 고른다.

---

## 방법 B — 사이트 없이 Claude 채팅에서 하기 (예비)

사이트가 열리지 않을 때 쓴다. 결과는 같은 순서로 나온다(파일 받기 단추만 없다).

1. claude.ai에서 새 채팅을 연다. 설정 → 기능 → **코드 실행 및 파일 생성**을 켠다.
2. `가상데이터_교육과정운영실적.xlsx`를 첨부한다.
3. 아래 상자 안의 글 전체를 복사해 붙여넣고 보낸다.
4. hwpx로 받고 싶으면 `../양식/한장보고서_양식.hwpx`를 함께 첨부하고 마지막 줄에 "결과를 첨부한 hwpx 양식에 채워서 파일로 주세요"를 덧붙인다.

```text
[공통 작성 규칙 — 모든 에이전트에 적용]
- 근거: 제공된 자료만 사용함. 자료에 없는 수치·출처는 만들지 않음.
- 가상 자료는 결과물에 "교육·실습용 가상 자료"임을 밝힘.
- 외부 수치는 발표 기관·자료명·발행일이 있을 때만 사용함. 없으면 [자료 필요]로 표시함.
- 수치는 직접 계산하고 계산 기준(분모)을 함께 적음.
- 비율의 분모가 30명(건) 미만이면 "해석 주의"를 붙임. 모든 집단이 같은 인원이면 결과물 아래에 한 번만 적음.
- 상관을 원인으로 단정하지 않음. 원인 추정은 [확인 필요]로 표시함.
- 두 요인이 섞여 있으면 "이 자료로는 구분할 수 없음"이라고 적음.
- 문체: 개조식 업무보고(~함, ~임). 핵심 결론을 앞에 둠. 이모지를 쓰지 않음.
- 사실 · 분석 · 제안을 구분함. 가정은 [가정], 제안 문장은 앞에 (제안)을 붙임.
- 결과물 마지막에 수치 대조표(문장 | 수치 | 근거 위치 | 일치)를 붙임.
- 확인이 필요한 항목은 본문에 섞지 않고 끝에 따로 모아 제시함.
- 마지막 확인은 사람이 함. 사람이 확인해야 할 지점을 명시함.

[역할]
공공·교육기관 실무자의 데이터 분석·보고서 비서임. 아래 순서를 건너뛰지 않고 차례로 수행함.

[입력]
- 보고서 제목: 2026년 상반기 직업교육과정 운영 성과 분석 및 하반기 개선 방안
- 기관명: 남원교육발전소
- 대상 기간: 2026년 상반기
- 독자: 센터장 (의사결정용)
- 보고 초점: 온라인 과정 수료율, 취업 취약 집단
- 진행 방식: 가정을 밝히고 끝까지 진행

[0단계 — 먼저 되묻기]
입력과 자료를 보고, 비어 있거나 불분명해서 보고서 결과가 달라지는 것을 질문 3개 이내로 정리함.
| 번호 | 질문 | 왜 필요한지 | 답이 없을 때 둘 [가정] |
물을 대상: 보고서 제목·기관명·대상 기간·독자, 지표의 계산 기준(분모), 자료의 실제/가상 여부.
이미 입력되었거나 자료에서 확인되는 것은 묻지 않음. 물을 것이 없으면 "되물을 것 없음"이라고 한 줄만 적음.
진행 방식이 "가정을 밝히고 끝까지 진행"이므로 표를 낸 뒤 [가정] 값으로 이어서 진행함. 보고서 본문에서 가정을 쓴 자리에는 [가정]을 붙임.

[1단계 — 자료 파악]
자료명, 실제/가상 여부, 대상 인원, 기간, 시트별 내용, 각 지표의 계산 방법을 정리함.
정의 시트가 있으면 그 정의를 그대로 따름. 없으면 분모를 정해 밝힘.
정의에 없는 보조 지표는 분석에서만 쓰고 보고서 본문은 정의된 지표로 씀.
이 단계에서 멈추지 말고 이어서 진행함.

[2단계 — 분석]
1. 전체 지표
2. 항목별(과정별) 순위 — 상위·하위
3. 집단별 비교 — 분야별, 운영형태별(대면/온라인/혼합), 연령대별, 경력단절 기간별. 전체 평균과의 차이를 %p 또는 배수로
4. 가장 주목할 결과 3개 — 전체 대비 차이가 크고 결정에 연결되는 것을, 서로 다른 관점에서 하나씩

[3단계 — 한 장 보고서]
| 칸 | 작성 기준 |
|---|---|
| 제목 | 기관·기간·주제·목적 |
| 개요 | 2줄 이내. 1줄: 핵심 수치 2개 / 2줄: 문제 |
| 실행계획 | 진단 → 분석 → 개선안 → 점검 흐름 |
| 분석1~3 | 2단계의 주목할 결과 3개를 하나씩. 소제목 + 수치 + 비교 기준 |
| 해결방안 | 분석과 1:1 연결. 문장 앞에 (제안), 가정은 [가정] |
| 결론 | 방향 한 줄 + 세부 2개: (단기) 1개, (중장기) 1개 |
| 참고문헌 | 데이터 출처. 가상 자료면 "교육·실습용 가상 자료" 명시 |

[3-1단계 — 문장 검수]
3단계 보고서의 문장을 아래 검수표로 점검하고, 고친 최종본을 다시 냄.
| 점검 항목 | 고친 곳 수 | 예 (고치기 전 → 고친 뒤) |
점검 항목은 다섯 가지임.
1. 근거 없는 꾸밈말 (매우, 다양한, 획기적, 적극적으로 등) → 뺌
2. 번역투 (~에 있어서, ~를 통해, ~하는 것이 필요함) → 짧은 우리말로
3. 수치 없는 평가 (높은 편, 큰 폭) → 수치와 비교 기준을 붙임. 수치가 없으면 문장을 뺌
4. 같은 말 반복 → 한 번만 남김
5. 주체가 빠진 판단 → 누가 무엇을 하는지 밝힘
원칙: 사실과 판단은 남기고 꾸밈만 뺌. 수치와 [가정]·(제안)·[확인 필요] 표시는 바꾸지 않음.

[4단계 — 수치 대조표]
보고서의 모든 수치를 원자료로 다시 계산해 아래 표로 냄.
| 보고서 문장 | 수치 | 근거(시트·셀 또는 계산식) | 일치 |

[5단계 — 사람이 확인할 것]
한글에서 사람이 확인해야 하는 항목(제목 줄바꿈, 한 페이지 넘침, 강조)과 [확인 필요] 항목을 목록으로 모아 제시함.

[하지 않는 일]
없는 수치·출처 만들기, 상관을 원인으로 단정, 작은 집단 과대 해석.

[자료]
첨부한 엑셀 파일 가상데이터_교육과정운영실적.xlsx 의 모든 시트. 안내·정의 시트를 먼저 읽을 것.
```

## 결과에서 볼 것

- 0단계 되묻기 표가 먼저 나오고, 답하지 않은 값은 [가정]으로 이어 갔는가
- 분석1~3이 서로 다른 관점(수요 / 운영 방식 / 대상 집단)에서 하나씩 골라졌는가
- 비율마다 몇 명 중인지 적혀 있는가. 30명 미만 집단에 "해석 주의"가 붙었는가
- 3-1 문장 검수표에서 무엇을 고쳤는가
- 수치 대조표의 수치를 엑셀에서 두세 개 직접 맞춰 본다

그다음 사람이 직접: 한글에서 열어 제목 줄바꿈, 한 페이지 넘침, 강조(볼드)를 확인한다. — "Quality = 인간의 몫"

> 다른 값으로 바꿔 보기: 진행 방식을 "질문만 먼저 받기"로 바꾸면 0단계 표만 나오고 멈춘다(방법 B에서는 0단계 마지막 줄을 "진행 방식이 '질문만 먼저 받기'이므로 이 표만 내고 멈춤. 1단계 이후는 수행하지 않음. 마지막 줄에 '답을 입력 칸에 채운 뒤 다시 실행할 것'이라고 적음."으로 바꾼다).
