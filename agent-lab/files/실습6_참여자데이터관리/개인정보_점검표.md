# 개인정보 점검표 — 실습 6 (자료를 올리기 전에 사람이 먼저 채운다)

AI에 자료를 올리기 **전에** 채운다. 한 칸이라도 비어 있으면 올리지 않는다.

## 1. 식별 정보 확인

| 항목 | 들어 있음 | 열 이름 | 처리 |
|---|---|---|---|
| 이름·성명 | ☐ | | ☐ 삭제 ☐ ID 치환 |
| 연락처·전화번호 | ☐ | | ☐ 삭제 ☐ ID 치환 |
| 주민등록번호·생년월일 | ☐ | | ☐ 삭제 |
| 주소 | ☐ | | ☐ 삭제 |
| 이메일 | ☐ | | ☐ 삭제 ☐ ID 치환 |
| 보호자·가족 정보 | ☐ | | ☐ 삭제 |
| 그 밖에 개인을 알아볼 수 있는 정보 | ☐ | | |

## 2. 처리 절차

| 순서 | 할 일 | 완료 |
|---|---|---|
| 1 | 원본 파일을 복사해 사본을 만든다 | ☐ |
| 2 | 사본에서 식별 정보 열을 삭제한다 | ☐ |
| 3 | `참여ID` 같은 비식별 키가 남아 있는지 확인한다 | ☐ |
| 4 | 자유 기재 칸(의견·비고)에 이름이 적혀 있지 않은지 확인한다 | ☐ |
| 5 | 원본은 식별자 대조표로 담당자가 별도 보관한다 | ☐ |
| 6 | 사본만 AI에 올린다 | ☐ |

> 스튜디오에서는 파일을 올리면 이름·연락처 열을 찾아 경고하고 "해당 열 지우고 보내기" 단추를 준다. 단추를 눌러도 원본 파일은 바뀌지 않는다.

## 3. 산출물 점검 (분석 후)

| 점검 항목 | 확인 |
|---|---|
| 결과물에 실명이 없다 | ☐ |
| 결과물에 연락처가 없다 | ☐ |
| 대상이 ID나 조건으로만 표시되어 있다 | ☐ |
| 명단 추출은 사람이 원본에서 했다 | ☐ |
