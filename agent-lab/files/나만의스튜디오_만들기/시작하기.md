# 나만의 업무 에이전트 스튜디오 만들기 — 시작하기

실습은 강사가 안내한 사이트 링크로 한다. 이 문서는 교육 뒤 내 사이트를 따로 갖고 싶을 때 쓴다(선택).

Claude를 처음 쓰는 사람도 그대로 따라 하면 내 사이트가 만들어진다. 걸리는 시간은 3~5분이다.
노트북(크롬 또는 엣지)에서 claude.ai에 로그인한 상태로 진행한다.

## 준비물

이 폴더의 파일 두 개: `CLAUDE.md`, `index.html`

## 순서

1. (선택) `CLAUDE.md`를 메모장으로 열어 **0. 내 업무 정보**의 빈칸을 채우고 저장한다. 비워 둬도 된다.
2. claude.ai에서 **새 채팅**을 연다.
3. `CLAUDE.md`와 `index.html` **두 파일을 함께 첨부**한다.
4. 아래 문장을 그대로 붙여넣고 보낸다.

```text
첨부한 CLAUDE.md의 순서대로 index.html을 아티팩트 사이트로 게시해 줘. 질문 없이 끝까지 진행해 줘.
```

5. Claude가 사이트 링크를 알려 주면 연다.
6. 왼쪽에서 에이전트를 고르고 → 값을 넣고 → 자료 파일을 끌어다 놓고 → **에이전트 실행**을 누른다.
   - 처음 실행할 때 허용을 묻는 창이 뜨면 **허용**을 누른다.
   - 첫 글자가 나오기까지 1~2분 걸릴 수 있다. 실행 중에는 "노드 진행"에 지금 어느 단계인지 표시된다.
7. 결과 아래 **결과를 파일로 받기**에서 형식을 고르고 **파일 받기**를 누른다.

| 형식 | 받는 파일 | 참고 |
|---|---|---|
| 한글 (hwpx) | `…_hwpx.zip` | 압축을 풀면 hwpx 파일이 나온다. 한글 2014 이상에서 열린다 |
| 워드 (docx) | `….docx` | 표가 워드 표로 들어간다 |
| PDF | `….pdf` | 보기 · 인쇄용. 글자를 고칠 수 없다 |
| 한글 옛 형식 (hwp) | `…_hwpx.zip` | hwp는 사이트에서 직접 만들 수 없다. hwpx를 한글에서 열어 [파일 → 다른 이름으로 저장 → 한글 문서(*.hwp)] |
| 글 파일 (md) | `….md` | 메모장에서 열린다 |

보고서 작성 에이전트는 **한 장 보고서 / 3장 이내 보고서 / 분석 결과 전체** 가운데 무엇을 받을지도 고른다.

## 실습 자료 넣기

각 실습 폴더의 `프롬프트.md`에 있는 "방법 A" 표대로 칸을 채우고 자료를 올린다. 내 사이트도 강사 사이트와 같은 칸을 쓴다.

## 넣을 수 있는 자료 파일

| 파일 | 읽힘 | 참고 |
|---|---|---|
| 엑셀 (xlsx, xls), CSV | 예 | 이름·연락처 열이 있으면 경고가 뜨고 지울 수 있다 |
| 한글 (hwpx), 워드 (docx) | 예 | 본문 글과 표를 읽는다 |
| PDF | 예 | 글자가 들어 있는 PDF만. 스캔한 그림 PDF는 읽지 못한다 |
| 글 파일 (txt, md) | 예 | |
| 한글 옛 형식 (hwp) | 아니오 | 한글에서 [다른 이름으로 저장 → hwpx]로 바꿔 올린다 |
| 그림, 압축 파일 | 아니오 | 압축은 풀어서 안의 파일을 올린다 |

파일을 칸에 **끌어다 놓거나**, 칸을 눌러 파일을 고른다. 올린 뒤 파일 목록에 **"읽음 · ○○자"**가 보여야 들어간 것이다. 붉은 글씨가 나오면 그 안내대로 한다.
파일이 안 올라가면 내용을 복사해 **본문 붙여넣기** 칸에 넣어도 결과는 같다.

## 안 될 때

| 화면에 나온 것 | 왜 그런가 | 할 일 |
|---|---|---|
| 붉은 상자 "이 화면에서는 에이전트를 실행할 수 없음" | 로그인하지 않은 화면에서 링크를 열었거나, 사이트에 실행 기능이 선언되지 않았다 | 크롬이나 엣지에서 claude.ai에 로그인한 뒤, 같은 브라우저에서 링크를 다시 연다. 내가 만든 사이트라면 만든 채팅에 "방금 만든 아티팩트에 sample, downloads 기능을 선언해 줘."라고 보내고 새로 고친다 |
| 붉은 상자 "실행하지 않았음 — 아래 항목이 비어 있음" | 별표(*) 칸이나 자료가 비어 있다 | 적힌 항목을 채운다. 자료는 파일 목록에 "읽음"이 보여야 한다 |
| 파일 이름 아래 붉은 글씨 "읽지 못함" | 읽을 수 없는 형식이거나, 기관 네트워크가 읽기 도구를 막았다 | 붉은 안내대로 한다. 급하면 내용을 복사해 "본문 붙여넣기" 칸에 넣는다 |
| "Claude에게 요청함 (○초 지남)"에서 멈춰 있다 | 허용을 묻는 창이 떠 있거나, 응답을 기다리는 중이다 | 화면에 뜬 창에서 **허용**을 누른다. 3분이 넘으면 중지하고 다시 실행한다 |
| "요청이 많아 잠시 제한됨" | 짧은 시간에 여러 번 실행했다 | 1~2분 뒤 다시 실행한다 |
| 파일 받기를 눌렀는데 저장 창이 안 뜬다 | 저장 창이 이미 떠 있거나 사이트에 저장 기능이 없다 | 한 번 더 누른다. 그래도 안 되면 "결과 복사"로 한글에 붙여넣는다 |
| Claude가 코드를 길게 쓰기 시작한다 (사이트 만들 때) | 파일을 게시하지 않고 새로 만들려는 것이다 | 멈춤을 누르고 "코드를 다시 쓰지 말고, 첨부한 index.html 파일을 그대로 게시해 줘."라고 보낸다 |
| Claude가 "게시할 수 없다"고 한다 | 이 채팅에 게시 도구가 없다 | 강사 사이트로 실습한다: https://claude.ai/artifact/KZ8jbQyiu3qHRkMRhjxe93 |

## 지킬 것

- 실습 중에는 가상 자료만 쓴다. 실제 자료는 이름·연락처를 지운 사본만 쓴다.
- 결과의 수치는 대조표로 원자료와 맞춰 본다. 마지막 확인은 사람이 한다.
