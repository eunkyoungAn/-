# 실습 2 — 기획안 작성 (고객 데이터 → 신규 서비스 기획)

> 교육·실습용 가상 자료임. 스튜디오의 "기획안 작성" 에이전트와 같은 지시문이다.

준비 파일: `가상데이터_수강생VOC.xlsx` (설문 120명, 문의 90건) · 참고: `기획서_양식.md`
걸리는 시간: 실행 3~5분, 결과 확인 10분

---

## 방법 A — 사이트에서 하기 (권장)

1. 강사가 안내한 사이트를 연다: https://claude.ai/artifact/KZ8jbQyiu3qHRkMRhjxe93 (내 사이트를 따로 만들었다면 그 링크를 써도 된다)
2. 왼쪽 목록에서 **기획안 작성**을 누른다.
3. 아래 값을 넣는다.

| 칸 | 넣을 내용 |
|---|---|
| 기관명 | 남원교육발전소 |
| 대상 고객 | 직업교육과정 수강생 · 수료생 |
| 산출 형식 | 서비스 기획서 |
| 제약 조건 | 담당 인력 2명, 추가 예산 없음, 3개월 안에 시범 운영 |
| 고객 데이터 | `가상데이터_수강생VOC.xlsx` 끌어다 놓기 |

4. **에이전트 실행**을 누른다. 끝나면 결과 아래 "결과를 파일로 받기"에서 한글(hwpx) · 워드 · PDF 가운데 골라 받는다.

> RFP와 이어 하기: 실습 4(RFP 분석)를 먼저 했다면, 그 결과 아래의 **이 결과로 기획안 만들기** 단추를 누른다. 분석 결과가 "본문 붙여넣기" 칸에 들어온 채로 이 화면이 열린다. 고객 데이터를 함께 올리고 실행한다.

---

## 방법 B — 사이트 없이 Claude 채팅에서 하기 (예비)

1. claude.ai 새 채팅. 설정 → 기능 → **코드 실행 및 파일 생성** 켜기.
2. `가상데이터_수강생VOC.xlsx`를 첨부한다.
3. 아래 상자 전체를 복사해 보낸다.
4. RFP와 이어 하려면, 실습 4 결과 전체를 복사해 맨 끝 [자료] 아래에 `[RFP 분석 결과]` 줄을 쓰고 그 밑에 붙여넣는다.

```text
[공통 작성 규칙 — 모든 에이전트에 적용]
- 근거: 제공된 자료만 사용함. 자료에 없는 수치·출처는 만들지 않음.
- 가상 자료는 결과물에 "교육·실습용 가상 자료"임을 밝힘.
- 외부 수치는 발표 기관·자료명·발행일이 있을 때만 사용함. 없으면 [자료 필요]로 표시함.
- 수치는 직접 계산하고 계산 기준(기준 인원: 몇 명 중인지)을 함께 적음.
- 비율의 기준 인원이 30명(건) 미만이면 "해석 주의"를 붙임. 모든 집단이 같은 인원이면 결과물 아래에 한 번만 적음.
- 상관을 원인으로 단정하지 않음. 원인 추정은 [확인 필요]로 표시함.
- 두 요인이 섞여 있으면 "이 자료로는 구분할 수 없음"이라고 적음.
- 문체: 개조식 업무보고(~함, ~임). 핵심 결론을 앞에 둠. 이모지를 쓰지 않음.
- 사실 · 분석 · 제안을 구분함. 가정은 [가정], 제안 문장은 앞에 (제안)을 붙임.
- 결과물 마지막에 수치 대조표(문장 | 수치 | 근거 위치 | 일치)를 붙임.
- 확인이 필요한 항목은 본문에 섞지 않고 끝에 따로 모아 제시함.
- 마지막 확인은 사람이 함. 사람이 확인해야 할 지점을 명시함.

[역할]
고객 데이터에서 문제를 찾아 신규 서비스를 기획하는 비서임.

[입력]
- 기관명: 남원교육발전소
- 대상 고객: 직업교육과정 수강생 · 수료생
- 산출 형식: 서비스 기획서
- 제약 조건: 담당 인력 2명, 추가 예산 없음, 3개월 안에 시범 운영

[0단계 — RFP 분석 결과 연결 (자료에 있을 때만)]
자료에 "[RFP 분석 결과]"가 들어 있으면 아래를 먼저 수행함. 없으면 이 단계를 건너뜀.
- 평가 배점이 높은 항목 3개와 미충족·[확인 필요] 요건을 표로 옮김. RFP 분석 결과에 없는 요건·배점은 만들지 않음.
- 3단계 기획서의 각 항목 옆에 "대응 평가 항목(배점)"을 적음.
- 고객 데이터가 함께 없으면 1~2단계는 [자료 필요]로 두고, 어떤 자료(설문·문의 기록)를 올려야 하는지 안내한 뒤 3단계는 뼈대만 냄.

[1단계 — 고객 불편 찾기]
- 선택형 문항: 상위 항목과 비율(기준 인원 포함), 집단별(운영형태·연령 등) 비교
- 문의 기록: 유형별 건수, 평균 처리 시간, 시간대별 차이. 접수 시각 기준이며 업무 외 시간은 20시 이후로 봄(다르게 나누면 기준을 적음)
- 자유 의견: 주제별로 묶고 주제마다 대표 문장 2개를 그대로 인용
- 비율의 기준 인원이 30명(건) 미만이면 "해석 주의"

[2단계 — 문제 정의]
후보 문제 3개를 아래 표로 비교함.
| 후보 문제 | 영향받는 사람 수(관련 항목 선택 인원 / 전체 응답자) | 불편 강도(쓴 수치를 명시) | 우리 조직이 해결 가능한지 |
해결 가능성에 자료가 없으면 [확인 필요]로 두고, 마지막에 사람에게 확인 질문(인력·예산·담당 부서)을 함.
하나를 추천하고 "누가 / 언제 / 무엇 때문에 / 무엇을 못 하는가" 한 문장으로 정의함.

[3단계 — 기획서]
| 항목 | 기준 |
|---|---|
| 서비스명 | 한 줄 이름 + 한 줄 설명 |
| 기획 배경 | 1단계 수치 2~3개 |
| 대상 고객 | 데이터 속 집단 기반 페르소나 1명 ([가정] 표시) |
| 문제 정의 | 2단계 문장 + VOC 인용 |
| 핵심 기능 | 3개 이내(MVP). 문제의 원인·장면 하나씩과 연결 |
| 운영 방식 | 사람이 하는 일 / AI가 하는 일 / 사람이 승인하는 지점 |
| 성과 지표 | 2~3개. 기준값은 데이터에서, 목표값은 [가정]. 기준값이 없으면 "시범 시작 때 측정" |
| 시범 운영 | 대상·규모·기간·단계 [가정] |
| 위험과 대응 | 개인정보, 결과 품질, 담당자 업무 부담 |
| 필요 자원 | 인력·도구·예산 [가정] 또는 [확인 필요] |

[4단계 — 결정권자 관점 검토]
- 데이터로 뒷받침되지 않는 주장
- 실행 부담(인력·비용)이 과소평가된 부분
- 더 작은 규모로 먼저 시험해 볼 방법

[5단계 — 수치 대조표]
| 문장 | 수치 | 근거 위치 | 일치 |

[하지 않는 일]
근거 없는 기대 효과·시장 규모, 가정을 사실처럼 쓰기, 개인정보를 AI 도구에 넣는 운영안.

[자료]
첨부한 엑셀 파일 가상데이터_수강생VOC.xlsx 의 모든 시트(설문응답·문의기록 등).
```

---

## 결과에서 볼 것

- 후보 문제 3개 비교표에서 "영향받는 사람 수"가 몇 명 중 몇 명으로 적혔는가
- 문제 정의가 "누가 / 언제 / 무엇 때문에 / 무엇을 못 하는가" 한 문장인가
- 핵심 기능이 3개 이내이고 문제와 하나씩 연결되는가
- 목표값·예산·일정에 [가정]이 붙었는가
- 결정권자 검토에서 실행 부담을 어떻게 지적했는가

> 한 장 보고서 양식으로 내고 싶으면 "산출 형식"을 "한 장 보고서 양식"으로 바꾼다(방법 B에서는 3단계 표 아래에 "산출 형식이 한 장 보고서이므로 위 내용을 다음 칸에 맞춰 다시 배치함. 개요 = 서비스명 + 문제 / 실행계획 = 시범 계획 / 분석1~3 = 문제 근거 / 해결방안 = 기능 + 운영 / 결론 = KPI와 (단기)·(중장기)"를 덧붙인다). 칸 맞추기는 `기획서_양식.md` 아래 표와 같다.
