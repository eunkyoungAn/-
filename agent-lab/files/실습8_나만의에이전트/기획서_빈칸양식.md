# 나만의 에이전트 기획서 — 빈칸 양식 (실습 8)

실명·연락처·내부 문서 원문은 적지 않는다. 업무의 순서와 자료 종류만 적는다.
채운 내용을 스튜디오 **나만의 에이전트** 입력 칸에 그대로 넣는다.

| 번호 | 칸 | 내가 적을 내용 | 예시 |
|---|---|---|---|
| 1 | 자동화할 업무 | | 월간 교육 운영 실적 보고서 작성 |
| 2 | 누가 쓰나 | | 나 혼자 / 우리 팀 / 기관 전체 |
| 3 | 입력 자료 | | 출석부 엑셀, 만족도 설문 결과, 지난달 보고서 |
| 4 | 지금 하는 순서 | | 인원을 센다 → 수료율을 계산한다 → 지난달과 비교한다 → 양식에 옮긴다 → 팀장 결재 |
| 5 | AI에게 맡길 일 | | 읽기, 분류, 계산, 초안, 대조 |
| 6 | 담당자가 판단할 일 | | 금액, 일정, 자격, 대외 발송 |
| 7 | 어디에 저장하나 | | 내 컴퓨터 / Claude 프로젝트 / 기관 공유 폴더 |
| 8 | 사람 확인 지점 | | 결과가 바깥으로 나가기 바로 앞 |

## 진행 순서 (50분)

| 시간 | 할 일 |
|---|---|
| 20분 | 위 빈칸 여덟 개를 채운다 |
| 15분 | 스튜디오에서 실행하고 맞춤형 MD 파일(SKILL.md)을 받는다. 단추를 누르면 내 컴퓨터에 저장됨 |
| 15분 | `직접활용_계획표.md`로 교육 뒤 세 번 써 볼 계획을 세우고, 짝과 바꿔 사람 확인 지점을 점검한다 |

스튜디오 칸과 이 양식 번호를 맞추는 표, 스튜디오 없이 하는 방법은 `프롬프트.md`에 있다.

## 산출물

- 기획서 한 장 (노드 흐름 포함)
- 맞춤형 MD 파일 `<name>_SKILL.md` — 내 업무에 맞춘 스킬 파일
- 직접 활용 계획 (`직접활용_계획표.md`)
- 안전 사용 체크리스트 점검 결과
