# 데이터 분석 → 한 장 보고서

업무 에이전트 스튜디오의 "보고서 작성" 에이전트와 같은 순서다. 단계를 건너뛰지 않는다.

## 받을 값
보고서 제목, 기관명, 대상 기간, 독자(기본: 센터장 의사결정용), 보고 초점(선택), 진행 방식(가정을 밝히고 끝까지 진행 / 질문만 먼저 받기. 기본은 앞의 것).

## 0. 먼저 되묻기
- 비어 있거나 불분명해서 결과가 달라지는 것을 질문 3개 이내로 정리한다.
  | 번호 | 질문 | 왜 필요한지 | 답이 없을 때 둘 [가정] |
- 물을 대상: 제목·기관명·기간·독자, 지표의 분모, 자료의 실제/가상 여부. 이미 입력됐거나 자료에서 확인되는 것은 묻지 않는다. 없으면 "되물을 것 없음" 한 줄.
- "질문만 먼저 받기"면 이 표만 내고 멈춘다. 아니면 [가정] 값으로 이어 가고, 본문에서 가정을 쓴 자리에 [가정]을 붙인다.

## 1. 자료 파악 (멈추지 말고 이어서 진행)
- 자료명, 실제/가상 여부, 대상 인원, 기간, 시트별 내용, 지표 정의
- 정의 시트가 있으면 그대로 따른다. 없으면 분모를 정해서 밝힌다.
- 정의에 없는 보조 지표는 분석에서만 쓰고, 보고서 본문은 정의된 지표로 쓴다.

## 2. 분석
1. 전체 지표
2. 항목별(과정별) 순위 (상위·하위)
3. 집단별 비교: 분야별, 운영형태별, 연령대별, 경력단절 기간별. 전체 평균과의 차이를 %p 또는 배수로
4. 주목할 결과 3개: 차이가 크고 정원·예산·운영 방식 같은 결정에 연결되는 것을 **서로 다른 관점**(수요 / 운영 방식 / 대상 집단)에서 하나씩
- 모든 수치는 직접 계산하고 분모를 적는다. 분모 30명 미만은 "해석 주의"(모든 집단이 같은 인원이면 아래에 한 번만).
- 두 요인이 섞여 있으면 "이 자료로는 구분할 수 없음". 원인은 추측하지 않고 [확인 필요]로 끝에 모은다.

## 3. 한 장 보고서
| 칸 | 작성 기준 |
|---|---|
| 제목 | 기관·기간·주제·목적 |
| 개요 | 2줄 이내. 1줄: 핵심 수치 2개 / 2줄: 문제 |
| 실행계획 | 진단 → 분석 → 개선안 → 점검 흐름 |
| 분석1~3 | 주목할 결과 3개를 하나씩. 소제목 + 수치 + 비교 기준 |
| 해결방안 | 분석과 1:1 연결. 문장 앞에 (제안), 가정은 [가정] |
| 결론 | 방향 한 줄 + 세부 2개: (단기) 1개, (중장기) 1개 |
| 참고문헌 | 데이터 출처. 가상 자료면 "교육·실습용 가상 자료" 명시 |
- 문체: 개조식(~함, ~임). 이모지 금지.
- hwpx 양식과 한 장 보고서 스킬이 있으면 그 스킬로 양식에 채운다. 없으면 칸별 텍스트로 내고 "hwpx 양식을 올리면 채워 드립니다"라고 안내한다.

## 3-1. 문장 검수
보고서 문장을 아래 다섯 항목으로 점검하고 고친 최종본을 다시 낸다.
| 점검 항목 | 고친 곳 수 | 예 (고치기 전 → 고친 뒤) |
1. 근거 없는 꾸밈말(매우, 다양한, 획기적, 적극적으로) → 뺌
2. 번역투(~에 있어서, ~를 통해, ~하는 것이 필요함) → 짧은 우리말로
3. 수치 없는 평가(높은 편, 큰 폭) → 수치와 비교 기준을 붙임. 없으면 문장을 뺌
4. 같은 말 반복 → 한 번만
5. 주체가 빠진 판단 → 누가 무엇을 하는지 밝힘
- 사실과 판단은 남기고 꾸밈만 뺀다. 수치와 [가정]·(제안)·[확인 필요] 표시는 바꾸지 않는다.

## 4. 수치 대조표 (항상 마지막에)
| 보고서 문장 | 수치 | 근거(시트·셀 또는 계산식) | 일치 |
- 원자료로 다시 계산해 소수 첫째 자리까지 같으면 일치. 틀린 것은 고친 뒤 다시 보여 준다.

## 5. 사람이 확인할 것
한글에서 제목 줄바꿈, 한 페이지 넘침, 강조(볼드)와 [확인 필요] 항목을 목록으로 모은다.

## 하지 않는 일
없는 수치·출처 만들기, 상관을 원인으로 단정, 작은 집단 과대 해석, 이름·연락처를 분석에 넣기.
