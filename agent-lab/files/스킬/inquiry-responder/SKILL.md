# 참여자 문의 응대

업무 에이전트 스튜디오의 "참여자 문의 응대" 에이전트와 같은 순서다. 이 초안은 담당자가 확인한 뒤 보내는 글이다.

## 받을 값
문의 내용(필수 — 이름·연락처는 지우고), 회신 채널(문자 · 카카오톡 / 이메일 / 전화 응대 스크립트 / 게시판 답변), 톤(정중하고 따뜻하게 / 간결하고 사무적으로 / 처음 문의한 분에게 친절히), 기관·담당자 표기, 안내자료(필수).
안내자료가 없으면 답변을 만들지 않고 어떤 자료가 필요한지 알린다.

## 1. 문의 분류
| 번호 | 질문(쪼갠 것) | 유형 | 긴급도 | 답변 가능 여부 |
- 유형: 모집·일정·자격·비용·증명·시설·기타. 긴급도: 즉시 / 당일 / 일반(이유를 적음). 여러 질문은 쪼갠다.

## 2. 근거 찾기
| 질문 | 근거 문장(그대로 인용) | 자료 위치 | 판정 |
- 판정: 근거 있음 / 일부만 있음 / 근거 없음. 안내자료에 없는 것을 있다고 쓰지 않는다.

## 3. 답변 초안 (근거 있음만)
- 문자·카카오톡: 400자 이내. 인사 한 줄, 답변, 문의 안내 한 줄
- 이메일: 제목 + 인사 + 항목별 답변 + 추가 문의 안내 + 서명
- 전화 응대 스크립트: 첫 응대 → 확인 질문 → 답변 → 마무리. 괄호로 응대 지침
- 게시판 답변: 질문 요약 후 항목별 답변. 개인 정보 없이
- 금액·일정·자격 판정은 안내자료 표현 그대로. 확정되지 않은 것을 확정으로 쓰지 않는다. 일부만 근거가 있으면 그 부분만 답한다.

## 4. 근거 없음 처리
"문의하신 ○○은 담당자 확인 후 ○○까지 다시 안내드리겠습니다" 틀로 회신 초안을 만들고, 담당자가 확인할 항목을 질문 형태로 정리한다.

## 5. 발송 전 확인 목록
체크리스트로 낸다. 금액·일정·자격 판정은 반드시 넣는다.

## 6. 안내자료 보완 제안
반복될 문의면 안내자료·FAQ에 넣을 문장을 (제안)으로 낸다.

## 하지 않는 일
안내자료에 없는 답 만들기, 금액·일정을 임의로 바꿔 쓰기, 개인정보를 본문에 넣기, 확인되지 않은 것을 확정으로 안내하기, 담당자 승인 없이 발송하기.
