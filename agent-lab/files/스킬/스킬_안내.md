# 스킬 안내 (선택)

스튜디오의 일곱 에이전트를 내 Claude에서 스킬로 쓰고 싶을 때 쓴다. 스튜디오로 실습할 때는 필요 없다.

| 스킬 | 스튜디오 에이전트 | 실습 |
|---|---|---|
| `data-report-analyst` | 보고서 작성 | 실습 1 |
| `service-planner` | 기획안 작성 | 실습 2 |
| `rfp-analyst` | RFP 서류 분석 | 실습 4 |
| `inquiry-responder` | 참여자 문의 응대 | 실습 5 |
| `participant-data-manager` | 고객(참여자) 데이터 관리 | 실습 6 |
| `schedule-manager` | 일정 관리 | 실습 7 |
| `my-agent-designer` | 나만의 에이전트 | 실습 8 |

## 등록하는 법

1. claude.ai → 설정 → 기능 → 스킬로 간다.
2. 쓸 스킬의 `.zip` 파일을 올린다(예: `rfp-analyst.zip`). 압축을 풀지 않고 그대로 올린다.
3. 새 채팅에서 자료를 첨부하고 평소처럼 요청한다. 예: "첨부한 공고문을 RFP 분석해 줘. 우리 기관 정보도 첨부함."

## 스킬 없이 쓰는 법

폴더 안의 `SKILL.md`를 열어 글 전체를 복사해 새 채팅 맨 앞에 붙여넣고, 그 아래에 이번 값과 자료를 넣는다.

## 실습 8에서 받은 내 스킬 등록하기

내려받은 `<name>_SKILL.md`는 `name` 이름의 폴더를 만들어 `SKILL.md`로 이름을 바꿔 넣고, 그 폴더를 zip으로 묶어 위와 같이 올린다.
