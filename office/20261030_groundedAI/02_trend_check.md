# 02_trend_check: Grounded AI 글 최신 동향 점검 (2026-11-02 기준)

방식: WebSearch 검색 요약만 확인. 공식 페이지 원문은 이 세션에서 열지 못함(네트워크 허용 목록 밖). 수치·정확도·비용 비교는 확인된 것이 없어 글에 넣지 않음.

## 글에서 뺀 것·미확인
- 2026-07-02 항목(최근 60일 내 파인튜닝 모델 추론이 없는 조직의 작업 생성 종료): 검색 결과마다 내용이 엇갈려 제외. 공식 페이지에서 확인 필요.
- 다른 회사(Google, Microsoft, AWS 등)의 파인튜닝 정책 변화: 확인하지 못함. 글에 "다른 회사도 같은지는 확인하지 못했다"고 표기.
- 환각률 등 통계(예: 2차 모음 사이트의 수치): 출처 신뢰도 낮아 제외.
- 연구 동향: RAG와 파인튜닝을 결합해 환각을 줄이는 논문들이 계속 나옴(예: https://arxiv.org/html/2505.10792v3). 글 본문에는 넣지 않음(수치 비교 회피).
- 기존 글의 "프롬프트 → RAG → 파인튜닝" 순서는 유효하지만, "긴 컨텍스트" 단계를 1번 항목 문구("통째로 붙여 넣기")로 흡수함.
