## 1장. 표지
- 라벨(좌상단): ● 면접 답변 공식
- 부제(작은 빨간 글씨): "그래서 결과가 뭐예요?"에 답하는 법
- 제목(큰 흰색 굵게 2줄): TRL 9칸 자로 / 프로젝트 한 문장
- 강조: TRL, 한 문장
- 레이아웃: 검정 바탕, 중앙에 휴대폰 목업 1개(화면: 1~9 칸 자, 1~3/4~6/7~9 구간 구분), 하단에 부제+제목

## 2장. ① TRL이 뭔가요?
- 제목: TRL은 기술의 / 입증 정도를 재는 9칸 자
- 본문: NASA에서 시작, Mankins(1995)가 9단계 정리. / 1~3 실험실 원리 확인, 4~6 유사 환경 검증, / 7~9 현장 실증·인증·운용
- 강조: 9칸 자, 입증
- 레이아웃: 휴대폰 A=9칸 자 세 구간 도식(구간별 명도 차이, 색은 코랄 레드 농도만), 휴대폰 B=구간 이름 3줄. 4~6 구간에 `mark`

## 3장. ② 분야별 척도
- 제목: 분야별 척도를 / 함께 말하세요
- 본문: 우주·국방 MRL, 에너지 CRI, / 바이오 바이오메디컬 TRL, SW·AI MLTRL, / 제조·품질은 MRL+TRL 6~8
- 강조: 분야별 척도, MRL, MLTRL
- 레이아웃: 휴대폰 A=산업 5칸 리스트, 휴대폰 B=빈칸 틀 예시 "□□ 부품을 TRL __ 수준에서 ___ 환경 시험으로 검증했고, 제조 쪽에서는 ___를 확인했습니다." 빈칸에 `mark`

## 4장. ③ 직무별 한 문장 공식
- 제목: TRL a→b 과정에서 / □□를 입증했습니다
- 본문: 공식: "TRL a→b 과정에서 □□를 입증했고, / 결과는 △△입니다." △△엔 수치·판정이나 / 다음 단계로 넘어간 상태 변화를
- 강조: □□, △△
- 레이아웃: 휴대폰 A=공식 문장 크게(□□·△△에 `mark`), 휴대폰 B=직무 6줄(품질 6→7 / 생산기술 6→8 / 사업개발 5→7 / PM a→b / 기술영업·FAE 7→8 / SW·AI PoC→운영)

## 5장. ④ 숫자보다 "무엇을 입증했나"
- 제목: 단계 숫자보다 / 입증한 내용이 핵심
- 본문: TRL 판정은 사람마다 다를 수 있다는 / 지적이 있어요(Olechowski 외 2020, Héder 2017). / "대략 ~단계" 뒤에 "○○를 입증했습니다"로
- 강조: 입증한 내용
- 레이아웃: 휴대폰 A=말풍선 "대략 TRL __ 단계였고", 휴대폰 B=말풍선 "___를 입증했습니다"(B 전체 `mark`). 두 화면 사이 화살표

## 6장. ⑤ TRL 면접 질문 5개
- 제목: 질문 5개, / STAR 순서로 답하세요
- 본문: 구조화 면접은 비구조화보다 직무성과 예측력이 / 높다고 보고됩니다(Levashina 외 2014). / 회사 단계는 "~로 보입니다"로 말하세요
- 강조: STAR, 구조화 면접
- 레이아웃: 휴대폰 A=질문 5개 목록(기억에 남는 프로젝트 / 입증한 것 / 실패 경험 / 현장에 더 필요한 것 / 우리 회사에서 활용), 휴대폰 B=1번 답변 빈칸 틀 "___ 기술이 대략 TRL __ 단계일 때, 제 역할은 ___였고 ___를 입증해 ___로 넘어갔습니다." 빈칸에 `mark`

## 7장. 마무리 CTA
- 강조 문구(빨간): 오늘 프로젝트 하나로 / 한 문장 공식을 채워 보세요
- 본문: 채운 문장을 댓글로 남기거나 코칭을 신청하면 / {코치명}이 함께 다듬어 드립니다
- 버튼: 저장하기 · 댓글 남기기 · 코칭 신청
- 프로필: 커리어캐쳐(CareerCatcher) / @career catcher
- 강조: 한 문장 공식, 댓글
- 레이아웃: 연한 분홍 바탕, 상단 강조 문구 → 본문 → 프로필 원형 로고 + 계정명 → 버튼 3개
