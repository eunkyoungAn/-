- 사진에 사람이 나올 경우 얼굴 비노출

## 1장 — 표지
- **제목**: 쇠퇴인가 퇴행인가 / 그건 내가 정합니다
- **본문(빨간 부제)**: "이 나이에 새로 배워도 될까요?" 경력 공백 앞에서
- **강조 문구**: 내가 정합니다
- **레이아웃 지시**: 검정 바탕. 좌상단 "● 커리어캐쳐 재취업 노트" 라벨. 중앙에 휴대폰 목업 1대(화면: 검색창에 "이 나이에 다시 배우기" 입력된 모습). 하단에 작은 빨간 부제 → 큰 흰색 굵은 제목 2줄

## 2장 — 번호 카드 1
- **제목**: 쇠퇴는 시간이 하고 / 퇴행은 내가 한다
- **본문**: 쇠퇴: 체력·속도가 자연히 약해지는 것. / 퇴행: 불안 속에 배우기를 멈추고 / 익숙한 과거로 물러나는 것.
- **강조 문구**: 퇴행은 내가 한다
- **레이아웃 지시**: 위쪽 휴대폰 2대 나란히. 왼쪽 화면 "쇠퇴 — 원인: 나이·환경 / 누구에게나 온다", 오른쪽 화면 "퇴행 — 원인: 배우기를 멈춤 / 선택할 수 있다". 오른쪽 "선택할 수 있다"에 `mark`

## 3장 — 번호 카드 2
- **제목**: 속도는 느려져도 / 경험은 사라지지 않아요
- **본문**: 새 문제를 빨리 푸는 능력은 서서히 줄지만 / 지식·어휘·경험에서 나오는 판단력은 / 중년 이후에도 유지되거나 자랄 수 있어요.
- **강조 문구**: 경험은 사라지지 않아요
- **레이아웃 지시**: 왼쪽 화면 "유동지능(처리 속도) ↘" 완만한 하강 그래프, 오른쪽 화면 "결정지능(경험·지식) →↗" 유지·상승 그래프. 오른쪽 그래프 선에 `mark`. 화면 하단 작은 출처 "유동·결정지능 이론(Horn & Cattell)". 수치·눈금은 넣지 않음(개념도)

## 4장 — 번호 카드 3
- **제목**: 뇌는 나이가 아니라 / 쓰는 만큼 바뀌어요
- **본문**: 성인이 저글링 같은 새 기술을 배우자 / 관련 뇌 영역에 변화가 나타났다는 / 신경가소성 연구가 있어요.
- **강조 문구**: 쓰는 만큼
- **레이아웃 지시**: 왼쪽 화면 저글링 공 3개 아이콘, 오른쪽 화면 뇌 아이콘 + 빛나는 영역 표시. 빛나는 영역에 `mark`. 출처 작게 "신경가소성 연구(Draganski 외)"

## 5장 — 번호 카드 4
- **제목**: 다시 배우는 성인은 / 셋 중 한 명 정도
- **본문**: 경력단절여성 약 110만 명(2025 상반기, 보도 기준) / 성인 평생학습 참여율 30%대(보도 기준). / 그 한 명이 되는 건 오늘의 선택이에요.
- **강조 문구**: 오늘의 선택
- **레이아웃 지시**: 왼쪽 화면 숫자 카드 "약 110만 명 / 경력단절여성", 오른쪽 화면 사람 아이콘 3개 중 1개만 빨간색 + "30%대". 빨간 아이콘에 `mark`. 각 화면 하단 출처 작게: "국가데이터처 지역별고용조사, 경기일보 보도 기준" / "교육부·한국교육개발원 실태조사, e-나라지표·헤럴드경제 보도 기준"

## 6장 — 번호 카드 5 (체크리스트)
- **제목**: 오늘 할 일 3가지 / 방향은 내가 정해요
- **본문**: ① 내 강점이 쓰이는 목표 1개 적기 / ② 이번 주 30분 학습 1개 일정에 넣기 / ③ 공백 기간에 한 일 3가지 적어 보기
- **강조 문구**: 공백은 이력서의 빈칸이지, 능력의 빈칸이 아닙니다
- **레이아웃 지시**: 왼쪽 화면 체크리스트 앱(3개 항목 체크박스), 오른쪽 화면 이력서 문서 + "돌봄·살림·봉사·독학 → 배운 점" 메모. 오른쪽 메모 줄에 `mark`. 강조 문구는 오른쪽 화면 상단 말풍선으로

## 7장 — 마무리 CTA
- **제목**: 퇴행 대신 / 다음 걸음을 함께 설계해요
- **본문**: 경력 공백·중장년 재취업이 막막하다면 / 지금의 고민을 댓글로 남겨 주세요.
- **강조 문구**: 다음 걸음
- **레이아웃 지시**: 연한 분홍 바탕. 상단 빨간 강조 문구 → 검정 제목 2줄 → 회색 본문. 하단에 원형 프로필(로고, 얼굴 사진 없음) + 계정명 **@career catcher** + 소개 "AI 자기소개서·AI면접·진로 코칭" + 빨간 버튼 "상담 신청하기" / 보조 버튼 "저장하고 다시 보기"
