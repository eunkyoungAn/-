## ② 서비스별 사실
### 01 기업·경험 찾기 (Experience Finder)
- 허브 문구: "질문에 답하며 숨은 경험을 꺼내고, 희망기업 공시(DART)를 분석해요." 부제 "경험이 막막할 때 시작".
- 형태: Google Apps Script 웹앱 + Google Sheets. 소스 저장소 eunkyoungAn/career-escape는 이 저장소에 없음(카드 문서로만 확인).
- 기능: 휴대폰으로 희망직무·경험 입력 → 경험카드 1개, 자소서 초안 1개, 면접질문 10개를 만들어 이메일로 발송. 희망기업이 공시 대상이면 OpenDART의 직원 현황·재무를 함께 분석.
- 입력: 이름, 이메일, 희망직무(필수), 희망기업·채용공고(선택), 경험 답변. 흐름: 목표 정하기 → 경험 찾아보기(질문 최대 5개) → 경험 정리하기 → 커리어 완성.
- DART: 공식 사실(DART)과 AI 해석을 나눠 표시. 첫 실행은 4~5분 걸릴 수 있고 같은 기업은 6시간 캐시. 비상장·소규모는 공시가 없어 채용공고 중심 분석.
- 한계: 경험이 빈약하면 초안이 평이해지고 표현이 과장될 수 있음. 링크를 아는 사람은 접속 가능. 현장 적용 결과는 [확인 필요].

### 02 AI 자기소개서 작성 (AI Cover Letter)
- 허브 문구: "정리한 기업·경험을 바탕으로 자기소개서 초안을 완성해요." 부제 "경험이 정리됐다면 여기부터".
- 형태: 정적 웹앱(React/TypeScript 소스를 빌드해 배포). 입력: 기업 리스트, 경험 노트. 출력: 기업 분석과 경험 기반 자소서 초안. 작업은 저장·불러오기 파일로 옮김.
- 데이터: 서버·DB 저장 없이 브라우저 localStorage, 브라우저에서 Gemini로 직접 전송. 메일 받기는 코드는 있으나 설정이 비어 비활성.
- 한계: 기업 분석은 AI가 만든 내용이라 최신 사실과 다를 수 있음. 기기 간 자동 동기화 없음. 없는 경험을 지어내거나 검토 없이 제출하는 것은 "쓰면 안 되는 경우"로 명시.
- 제작 이력(PROVENANCE.md): 원래 목적은 "자동화 시트를 웹페이지로 전환하고 사용자가 자신의 Gemini API 키로 실행"(L7). 관련 채팅 2026-09-09. GitHub Pages용으로 경로 수정, 화면·입력·프롬프트·생성 로직은 원본 유지. 정리일 2026-10-06.

### 03 AI 포트폴리오 작성 (Portfolio Builder)
- 허브 문구: "입력만 하면 직무 역량이 드러나는 포트폴리오를 만들어요." 부제 "결과물로 완성".
- 입력 양식: 퍼플커리어 노션 포트폴리오 양식 순서(Contact → About me → Skills → AI 역량 → Projects → Experiences → Education → Language·Other). 필수: 지원 직무, 프로젝트 1개 이상.
- 출력: 노션형 미리보기, [HTML 저장], [노션용 복사]. PDF는 브라우저 인쇄. 컨설턴트 피드백(보완점 3가지)은 화면에만 보임.
- AI: Gemini(무료, Flash-Lite 기본/Flash) 또는 Claude(유료). 키 없이 프롬프트를 복사해 ChatGPT·Claude 웹에 붙여넣는 방법도 있음. [예시로 채우기]의 이름·학교·숫자는 모두 가상.
- 한계: 이미지 업로드 없음, 결과가 HTML 파일 하나. 개인정보: 입력은 브라우저에만 임시 저장, 이메일·연락처는 AI에 보내지 않고 API 키는 저장하지 않음.

## ③ 흐름 안내 (사실)
