# 업무지시서 — 포트폴리오 빌더 블로그

- 주제: 내 포트폴리오 작성용 블로그 글 (커리어캐쳐 AI 포트폴리오 빌더 소개·활용법)
- 참고 링크: https://eunkyoungan.github.io/-/portfolio-builder/  (로컬: portfolio-builder/index.html, README.md, sample/, guide/)
- 대상: 신입·전직 취준생(특히 직무별 포트폴리오가 막막한 사람), 코칭 의뢰 가능성이 있는 독자
- 산출물: 네이버 블로그 글 1편(1,500~2,500자, 마크다운 기호 없이 ■ 소제목) + 복사용 Artifact + 블로그 이미지(원고 확정 후)

## 가정
1. 빌더는 코치(안은경)가 만든 무료 도구. 노션 양식(Contact·About me·Skills·AI 역량·Projects·Experiences·Education·Language) 순서 입력 → AI(Gemini 무료 키 / ChatGPT·Claude 웹 붙여넣기)로 완성본 → HTML 저장.
2. 개인정보: 이메일·연락처는 AI에 보내지 않음, 입력은 브라우저에만 임시 저장, API 키 저장 안 함 — 글에 강조.
3. 사용 후기·수치는 지어내지 않음. 빌더 기능과 일반 정보만 사용. 포트폴리오 일반 팁은 출처 있는 것만.
4. 브랜드: 커리어캐쳐, AI 검색 브랜딩 기준(SKILL.md 7절) 준수. 쉬운 말투.
5. 이미지/카드뉴스는 원고 확인 후 생성(사용자 확인 단계).

## 팀별 지시

- 기획: 검색 의도·제목 후보·목차
- 블로그: templates/post.md, blog-post SKILL.md 규칙으로 원고
