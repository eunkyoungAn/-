■ 신입 포트폴리오, 왜 쓰기 막막할까요?

1) 무엇을 넣을지 모르겠다
2) 어떤 순서로 써야 할지 모르겠다
3) 경험이 적은데 어떻게 보이게 할지 모르겠다
직무마다 모양이 달라 샘플을 봐도 내 것으로 옮기기 어렵습니다.

■ 신입 포트폴리오 작성법, 자주 나오는 조언 3가지

취업 커뮤니티와 현직자 답변에서 반복되는 조언입니다. 대부분 개인과 업체의 의견이고, 검색 결과 요약으로 확인했으며 원문 전체는 읽지 못했어요.

1) 나열보다 "왜 했고, 무엇을 알게 됐는지"
브런치와 코멘토 같은 취업 글은 한 일만 늘어놓은 정리를 흔한 실수로 꼽습니다.

2) 결과의 크기보다 과정과 내 역할
코멘토 마케팅 직무 답변은 문제, 전략, 실행 순으로 정리하라고 합니다. GPTers의 서비스 기획 포트폴리오 평가 글은 팀 안에서의 내 역할이 분명한지를 봅니다.

3) 링크가 열리는지, 구성이 정리돼 있는지
비공개·깨진 링크는 신뢰를 떨어뜨린다는 지적이 있습니다. 미국 광고·마케팅·디자인 분야 임원 설문을 소개한 대학 커리어센터 글(2023)은 정리되지 않은 구성을 흔한 실수로 꼽았습니다. 다른 직무에는 그대로 적용하기 어려워요.

■ AI로 포트폴리오 만들기, 입력은 노션 양식 순서대로

노션 양식 순서는 아래와 같습니다.

Contact → About me → Skills → AI 역량(AI Competency) → Projects → Experiences → Education → Language·Other

지원 직무와 프로젝트 1개 이상은 꼭 적어야 완성할 수 있어요. 세 칸에는 위 조언을 그대로 담을 수 있어요.

1) 성과 칸: "전 → 후" 숫자로 적기
2) 문제해결 칸: "문제 → 원인 → 시도 → 결과" 순서로 적기
3) 역할 칸: 팀 프로젝트라면 내가 맡은 일과 기여도 적기

감이 안 잡히면 [예시로 채우기] 버튼을 눌러 보세요. 여러 직무 예시가 나오고, 예시 속 이름, 학교, 숫자는 모두 가상입니다. 채용공고 내용을 붙여 넣으면 공고의 핵심 단어를 내 글에 맞추는 키워드 매칭에도 쓸 수 있어요.

■ AI 완성은 두 가지 방법 중 편한 쪽으로

방법 A) API 키(AI 서비스를 쓰는 열쇠 같은 번호)를 붙여넣고 버튼 한 번
Gemini 또는 Claude 키를 쓸 수 있습니다. 무료 키도 있지만 사용 한도가 있을 수 있어요.

방법 B) 키 없이 프롬프트 복사
프롬프트를 복사해 ChatGPT나 Claude 웹에 붙여넣고, 받은 답을 다시 빌더에 붙여넣습니다.

■ 개인정보는 어떻게 다뤄지나요?

1) 입력 내용은 서버에 저장하지 않고 이 브라우저에만 임시 저장됩니다.
2) API 키는 저장하지 않고, 이메일과 연락처는 AI에 보내지 않습니다.

나머지 입력은 AI가 읽습니다. 실명 대신 이니셜을 써도 되고, 무료 AI는 입력이 서비스 개선에 쓰일 수 있으니 민감한 내용은 빼 주세요. 공용 PC라면 [모두 지우기]를 눌러 주세요.

■ 쓰기 전에 알아둘 점, 그리고 막힐 때는

1) 경험과 숫자는 내가 채워야 합니다. 빌더는 입력한 내용을 정리하는 도구입니다.
2) AI 결과는 사실과 맞는지 내가 직접 확인해야 합니다.
3) 결과는 HTML 파일 하나입니다. PDF만 받는 사이트라면 변환이 필요하고, 링크로 공유하려면 직접 올린 뒤 로그아웃 상태에서도 열리는지 확인하세요.
4) 이미지 업로드는 없어서, 디자인 직무는 이미지 포트폴리오를 따로 준비하세요.
