# 모핑·도식 버전 디자인 명세서

> 대상: 「비즈니스 프로젝트 프레젠테이션」 모핑·도식 버전 12장 (`비즈니스_프로젝트_발표_모핑.pptx`)
> 작성일: 2026-10-15
> 기준 문서: 「원본 디자인 분석서」(디자인.md). 원본의 시각 언어를 유지하고, 흰 배경 전환과 모핑·도식을 추가했다.
> 목적: 이 문서만으로 같은 덱을 다시 만들 수 있도록 색상, 글꼴, 좌표, 모핑 짝, 품질 기준을 기록한다.

## 1. 자료 개요와 기준

### 1.1 화면과 단위

| 구분 | 값 | 비고 |
| --- | --- | --- |
| 슬라이드 크기 | 13.333 × 7.5인치 (16:9, PowerPoint ‘와이드스크린’) | 원본 20 × 11.25인치를 2/3로 축소한 비율과 같음 |
| 좌우 여백 | 좌 0.7인치, 우 0.7인치 (콘텐츠 x 0.7~12.633, 폭 11.933) | 원본의 약 5~6% 여백 유지 |
| 좌표 단위 | 인치 (x, y는 슬라이드 좌상단 기준) | 아래 모든 수치 동일 |
| 장 수 | 12장 | 원본 11장 + 경쟁사 포지셔닝 1장 |

### 1.2 원본 대비 변경 원칙

- **유지:** 큰 제목과 작은 설명의 위계, 얇은 회색 구분선, 원·캡슐·카드의 반복, 화면 가장자리의 파란 번짐, 제한적인 #5779FF 강조.
- **변경:** 배경을 #F6F6F6에서 **#FFFFFF**로 바꿨다. 흑백 사진은 도식으로 대체했다. 모든 장에 모핑 전환을 넣었다.
- **수정:** 성과 분석 번호 06 통일, 카드 밖 텍스트 넘침 제거, ‘?소셜 마케팅’ 오류 제거, 경쟁사 강조의 중립화, 반복 지표 이름 구분.
- **금지:** 제목 아래 색 강조선, 카드 한쪽만 칠한 색 띠, 크림·베이지 배경, 본문 14pt 미만, 근거 없는 수치를 실제 성과처럼 보이게 하는 표기.

### 1.3 예시 내용의 성격

회사명(LARANA COMPANY), 발표자(홍길동), 이메일, 친환경 포장재 전환 사례, 30·25·50·60% 수치는 모두 **예시**다. 10장에는 “※ 수치는 예시입니다. 실제 데이터와 출처로 교체하세요.”를 반드시 넣는다.

## 2. 전체 디자인의 특징

### 2.1 시각적 방향

흰 바탕 위에 짙은 회색 글자, 얇은 선, 연한 청보라 면을 배치한 절제된 비즈니스 스타일이다. 사진이 없어진 자리는 원·화살표·막대·맵으로 만든 도식이 채운다. 장마다 모핑으로 요소가 이어져, 정보량이 많은 본문도 한 흐름으로 읽힌다.

### 2.2 공통 프레임 (본문 장 3~11)

| 제목 | x 1.68, y 0.5, 8 × 0.78 | 32pt 굵게, #323232, 세로 가운데 | `!!title` |

### 2.3 파란색 번짐

- **제작:** 투명 PNG 한 장(900 × 900px)을 모든 장에 재사용한다. 가우시안 3개를 겹쳐 만든다. 중심은 #5779FF, 보조는 #8C7BFF(청보라)와 #9FB7FF, 최대 불투명도는 약 60%이고 가장자리는 0%다.

- **배치 원칙:** 화면 밖으로 잘려 들어오게 두고, 본문 글자 뒤에는 두지 않는다.

## 3. 색상과 글꼴

### 3.1 색상 체계

| 색상 | 역할 |
| --- | --- |
| `#FFFFFF` | 모든 슬라이드 배경, 카드·원 채움 |
| `#323232` | 제목, 핵심 텍스트, 번호 원 테두리 |
| `#545454` | 핵심 메시지, 설명 문단 |
| `#8A8A8A` | 회사명, 바닥글, 축 라벨, 주석 (원본 #AEAAAA는 흰 배경에서 대비가 낮아 어둡게 조정) |
| `#DCDFE6` | 구분선, 카드 테두리 |
| `#BFC3CC` | 표지·마무리 연락처 구분선, 비교표 머리 구분선 |
| `#5779FF` | 강조: 번호 라벨, 수치, 완료 표식, 목표 영역, 마지막 단계 |
| `#E7EAF9` | 연한 강조 면: 비교 기준 캡슐, 패널 제목 캡슐, 막대 바탕 |
| `#C9D2FB` | 중간 단계 면, 타임라인 선 |
| `#F4F6FE` | 가장 연한 면: 동심원 바깥, 목표 영역, 요약 상자 |

파란색은 “선택된 것, 완료된 것, 우리 회사의 목표”에만 쓴다. 비교 대상(A사·B사)에는 쓰지 않는다.

### 3.2 글꼴

- 모든 텍스트: **맑은 고딕** (한글 `ea` 글꼴도 맑은 고딕으로 지정, charset -127).
- 원본 글꼴(네모고딕, 210 옴니고딕, 29LT Bukra)은 설치·라이선스 여부가 불확실해 쓰지 않는다.

## 5. 모핑 설계

### 5.1 적용 방식

- 1장: 페이드(보통 속도).
- 2~12장: 모핑(개체 단위, 1.2초). XML에 `mc:AlternateContent`로 넣고, 지원하지 않는 버전을 위해 페이드를 대체 전환으로 둔다.
- 짝 맞추기: 연속된 두 장에서 **이름이 같고 `!!`로 시작하는 개체**끼리 이어진다. 개체 종류(도형↔도형, 그림↔그림)도 같아야 한다.

### 5.2 모핑 짝

| 개체 이름 | 흐름 | 보이는 효과 |
| --- | --- | --- |
| `!!blob` | 1→12 전체 | 번짐이 장마다 다른 가장자리로 흘러감 |
| `!!title`, `!!msg` | 1→12 전체 | 제목·메시지 자리가 부드럽게 바뀜 |
| `!!badge` | 2→3, 이후 3~11 | 목차의 01 원이 제목 옆으로 이동, 이후 번호만 바뀜 |
| `!!ring1~3` | 3→4 | 동심원(지름 3.9 / 2.7 / 1.5)이 가로로 겹친 세 원(지름 2.9)으로 펼쳐짐 |
| `!!compA`, `!!compB` | 6→7 | 비교표 머리의 A사·B사 캡슐이 포지셔닝 맵의 각 위치로 이동 |

`!!` 이름은 편집 중에도 바꾸지 않는다. 바꾸면 이동 대신 사라짐·나타남으로 바뀐다.

## 6. 슬라이드별 명세

### 01. 표지
- 회사명 우상단(공통 위치). 부제 “친환경 포장재 전환 프로젝트 결과 보고” x 0.7, y 1.45, 18pt #545454 (`!!msg`).
- 제목 1줄 “비즈니스 프로젝트” y 2.05, 54pt (`!!title`). 2줄 “프레젠테이션” y 3.1, 60pt.
- 연락처: 구분선 y 5.75와 6.6(#BFC3CC) 사이, y 5.95에 “발표 홍길동 · 전략기획팀”(x 0.7), “이메일 hello@larana.co.kr”(x 5.3). 라벨은 #8A8A8A, 값은 #323232, 15pt.

### 02. 목차
- “CONTENTS” x 0.7, y 0.95, 44pt (`!!title`), 그 아래 “목차” 16pt (`!!msg`).
- 2열 × 3행. 열 x 0.7 / 7.0, 행 y 2.75 / 4.05 / 5.35. 각 항목: 번호 원 0.74 + 제목 22pt + 회색 설명 13pt, 항목 아래 y+1.0에 폭 5.6 구분선.
- 항목: 01 프로젝트 개요(배경과 핵심 키워드), 02 시장 분석(시장을 움직이는 네 가지 요인), 03 경쟁사 분석(비교 기준과 포지셔닝), 04 전략 계획 수립(네 단계 실행 로드맵), 05 실행 결과(과제별 진행 현황), 06 성과 분석(핵심 지표와 향후 방향).
- 01의 원만 `!!badge`, 나머지는 일반 이름.

### 03. 01 프로젝트 개요 — 배경 (동심원)
- 메시지: 포장 규제 강화와 고객 인식 변화가 프로젝트의 출발점입니다
- 좌측 동심원, 중심 (3.3, 4.5): `!!ring1` 지름 3.9 #F4F6FE/#C9D2FB, `!!ring2` 2.7 #E7EAF9/#B5C2FB, `!!ring3` 1.5 #5779FF에 흰 글자 “프로젝트” 16pt. 띠 라벨 “시장 환경”, “고객 요구” 13pt 굵게.
- 우측 x 6.3~12.633: 소제목 “프로젝트 주요 배경” 24pt. 세 줄(라벨 #5779FF 15pt + 문장 16pt, 줄 간격 0.72, 줄마다 구분선): 규제 – 포장재 감축 기준이 단계적으로 강화되는 추세 / 고객 – 구매 전 친환경 포장 여부를 확인하는 고객 증가 / 비용 – 기존 포장재의 원가와 폐기 비용 부담 확대.
- 캡슐 2개 y 5.75(2.2 × 0.5): 규제 선제 대응, 고객 신뢰 확보.

### 04. 01 프로젝트 개요 — 세 키워드 (벤 다이어그램)
- 메시지: 세 가지 키워드가 겹치는 지점을 프로젝트 목표로 삼았습니다
- 원 3개 지름 2.9, 중심 y 3.95, x 4.3 / 6.667 / 9.033. 채움 #5779FF 투명도 86%, 테두리 #5779FF 1.25pt, 안에 키워드 21pt 굵게: 지속가능성, 비용 효율, 고객 경험.
- 원 아래 y 5.6, 14pt #545454 두 줄 가운데 정렬: 재생 원료 비중을 높이고 / 폐기물 발생을 줄인다 · 공정과 물류 단계의 / 불필요한 비용을 줄인다 · 개봉부터 분리배출까지 / 불편 없는 경험을 만든다.

### 05. 02 시장 분석 (아이콘 카드)
- 메시지: 시장 변화를 네 가지 요인으로 나누어 살펴봤습니다
- 카드 4개, 간격 0.35, 폭 2.72, y 3.3, 높이 2.9. 아이콘 원(지름 1.0)이 카드 윗변 중앙에 걸침.
- 카드 내부(좌우 여백 0.25): 번호 13pt #5779FF → 제목 19pt → 구분선 → 설명 14pt 두 줄.
- 정책·규제(감축 기준 강화로 / 대체 소재 수요 증가), 소비 트렌드(가치 소비 확산으로 / 포장도 구매 기준이 됨), 원자재 가격(원료 가격 변동으로 / 대체 소재 경쟁력 상승), 유통 채널(온라인 주문 증가로 / 배송 포장 물량 확대).
- 네 요인은 병렬이므로 화살표로 잇지 않는다.

### 06. 03 경쟁사 분석 — 비교표
- 메시지: 같은 기준으로 비교하면 두 경쟁사의 강점이 뚜렷하게 갈립니다
- 열: A사 x 0.7 폭 4.6 / 기준 x 5.667 폭 2.0 / B사 x 8.033 폭 4.6. 머리 y 2.5에 A사·B사 캡슐(1.7 × 0.48, 흰 채움 #323232 테두리, 16pt, `!!compA`/`!!compB`), 가운데 VS 원(0.66, #5779FF 테두리·글자).
- 머리 아래 구분선 y 3.22(#BFC3CC), 행 높이 0.76 × 4. 기준 캡슐 #E7EAF9 채움.
- 가격대: 중저가, 대량 구매 할인 | 고가, 맞춤 제작 중심 / 주력 소재: 재생 플라스틱 위주 | 종이·생분해 소재 위주 / 납기: 빠름 (재고 기반 출고) | 느림 (주문 후 생산) / 강점: 전국 물류망과 낮은 단가 | 디자인 완성도와 협업 경험.
- 양쪽의 시각적 무게를 같게 둔다(원본의 B사 단독 강조 제거).

### 07. 03 경쟁사 분석 — 포지셔닝 맵 (신규)
- 메시지: 가격과 친환경 차별화 사이의 빈 영역을 목표로 삼습니다
- 맵 영역 x 0.9~7.3, y 2.45~6.55, 축 교차점 (4.1, 4.5). 가로축 왼→오 화살표(가격 낮음 → 가격 높음), 세로축 위쪽 화살표(차별화 낮음 → 친환경 차별화 높음), 축 #8A8A8A 1pt, 라벨 12pt.
- 좌상 사분면 #F4F6FE 채움 + “목표 영역” 12pt #5779FF.
- 캡슐: A사 (1.35, 5.35), B사 (5.3, 2.95) — 6장과 같은 크기·서식. “LARANA 목표” (1.35, 3.05) #5779FF 채움 흰 글자. “LARANA 현재” (4.45, 4.95) 회색 점선 테두리. 현재 → 목표로 #5779FF 1.5pt 점선 화살표.
- 우측 x 7.95: 번호 01~03 + 16pt 문장 3개(간격 1.25, 사이 구분선): A사는 가격 경쟁력, B사는 차별화에 집중합니다 / 중저가이면서 친환경 소재를 쓰는 선택지는 비어 있습니다 / LARANA는 이 영역을 1차 목표 포지션으로 정했습니다.

### 08. 04 전략 계획 수립 (단계 화살표)
- 메시지: 네 단계를 순서대로 진행해 전환 위험을 줄였습니다
- 화살표 4개 y 2.75, 3.1 × 0.7, 간격 2.93. 1단계는 오각형, 2~4단계는 갈매기 모양. 채움이 점점 진해짐: #E7EAF9 → #C9D2FB → #9FB2FF → #5779FF. 글자 STEP 1~4 16pt 굵게(1~3 #323232, 4 흰색), 테두리 흰색 1.5pt.
- 각 화살표 아래 x+0.25, 폭 2.55: 제목 19pt(y 3.8) + 글머리 2개 14pt(y 4.35).
- 소재 검증(대체 소재 3종 비교 시험 / 내구성·단가 기준 확정), 공급망 정비(소재 공급사 2곳 계약 / 생산 라인 설비 조정), 시범 적용(주력 제품 1개 라인 적용 / 고객 반응 설문 실시), 전면 확대(전 제품군 순차 전환 / 분리배출 안내 개선).
- 요약 상자 y 5.6, 전체 폭, 높이 0.75, #F4F6FE 채움 #E7EAF9 테두리. 체크 원 + 16pt 굵게 “단계마다 검증 기준을 통과해야 다음 단계로 넘어가도록 설계했습니다”.
- 글머리는 단계당 2개 이하. 요약 상자와 최소 0.5인치 간격.

### 09. 05 실행 결과 (타임라인)
- 메시지: 계획한 다섯 가지 과제 중 네 가지를 완료했습니다
- 좌측: “4”(66pt #5779FF) + “ / 5”(30pt #8A8A8A), “과제 완료” 19pt, 설명 15pt “남은 1개 과제는 다음 분기 안에 마무리할 예정입니다”, 범례 y 5.6(● 완료 / ○ 진행 중).
- 우측 세로선 x 5.3(#C9D2FB 1.5pt), 항목 간격 0.8, 시작 y 2.55. 원 지름 0.4: 완료 = 채움 + 흰 체크, 진행 중 = 빈 원. 시기 14pt #5779FF, 내용 16pt.
- 1분기 대체 소재 3종 시험 후 1종 최종 선정 / 1분기 소재 공급사 2곳과 연간 공급 계약 체결 / 2분기 주력 제품 라인 포장 전환 적용 / 2분기 고객 설문 실시 및 결과 보고서 작성 / 3분기 전 제품군 확대 적용(+ 우측 “진행 중” 캡슐, 내용은 #545454).

### 10. 06 성과 분석 — 수치
- 메시지: 전환 이후 네 가지 지표가 모두 개선되었습니다
- 좌측: “핵심 성과” 24pt, 설명 15pt, 하단 y 5.85에 예시 수치 주석 11pt #8A8A8A.
- 우측 2 × 2 카드 x 4.75~12.633, 간격 0.3, 높이 1.85, 시작 y 2.45. 카드: 수치(46pt) + %(22pt) 좌측, 지표명 16pt 굵게 + 기준 12pt 회색 우측, 하단 y+1.35에 막대(높이 0.12, 길이 = 수치%).
- 30% 매출 성장률(전년 같은 기간 대비) / 25% 포장 원가 절감(전환 전 단가 대비) / 50% 폐기물 감소(월평균 배출량 기준) / 60% 고객 선호도(설문 만족 응답률).

### 11. 06 성과 분석 — 향후 계획과 발전 방향
- 메시지: 단기 실행 계획과 장기 지향점을 나누어 정리했습니다
- 패널 제목 캡슐(2.4 × 0.48, #E7EAF9): “향후 계획 · 6개월”(x 0.7), “발전 방향 · 3년”(x 7.0). 두 패널 사이 세로 구분선 x 6.67.
- 좌측 가로 타임라인 y 4.45, 화살표 끝. 점 간격 1.5: 1개월(전 제품 / 전환 완료, 채운 점), 2개월(분리배출 / 안내 개선), 4개월(협력사 / 2곳 추가), 6개월(성과 재측정 / 보고). 시점 라벨은 점 위 14pt #5779FF, 내용은 점 아래 14pt.
- 우측 계단 막대 3개, 폭 1.65, 간격 0.15, 바닥 y 6.4, 높이 0.85 / 1.55 / 2.25, 채움 #E7EAF9 / #C9D2FB / #5779FF. 막대 상단에 연차 14pt, 막대 위에 설명 14pt: 친환경 포장 / 표준 정립 · B2B 포장 / 솔루션 판매 · 순환형 포장 / 회수 체계.
- 향후 계획 = 구체적 실행, 발전 방향 = 장기 지향점으로 범위를 나눈다.
