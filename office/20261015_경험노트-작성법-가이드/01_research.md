# 01 리서치

## 1. 경험노트가 필요한 이유
- 자소서 문항은 기업마다 표현만 다르고 묻는 역량은 대체로 겹침(지원동기, 직무역량, 협업, 문제해결, 실패·극복, 도전).
- 서류 마감에 쫓겨 경험을 그때그때 떠올리면 수치·근거가 빠지고 사례가 중복됨.
- 면접은 자소서 기반 꼬리질문(왜, 어떻게, 결과, 다시 한다면)으로 깊이를 확인하므로 세부 기록이 있어야 일관되게 답할 수 있음.

## 2. 자소서 빈출 문항 유형
| 유형 | 확인 역량 |
|---|---|
| 지원동기·입사 후 포부 | 직무·회사 이해, 동기 |
| 직무 역량/전문성 | 지식·스킬 적용 |
| 문제해결·성과 | 분석력, 실행력 |
| 협업·갈등 해결 | 소통, 조율 |
| 실패·극복 | 회복탄력성, 성찰 |
| 도전·주도성 | 목표 설정, 책임감 |
| 윤리·원칙 | 신뢰성 |

## 3. 면접 꼬리질문 패턴
- 왜 그렇게 판단했나 / 다른 대안은 / 본인 역할은 정확히 / 결과를 어떻게 측정했나 / 갈등 상대는 어떻게 반응했나 / 다시 한다면.

## 4. 대표 기법
- STAR(Situation-Task-Action-Result), 결과 뒤에 배운 점(L)을 붙인 STAR-L.
- 경험 브레인스토밍: 시기별(학년·학기) 타임라인, 영역별(학업·대외활동·아르바이트·인턴·프로젝트·개인 생활).
- 역량 키워드 매핑: 한 경험에서 여러 역량을 태깅해 문항별 재활용.
- 경험-문항 매트릭스: 행=경험, 열=문항 유형으로 중복 사용 관리.
- 정량화: 기간, 인원, 횟수, 전후 비교(%)로 근거화. 정확한 수치가 없으면 추정 근거 명시.
