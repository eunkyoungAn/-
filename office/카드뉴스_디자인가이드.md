# 카드뉴스 디자인 가이드 (수정 기록)

AI가 매번 이 파일을 먼저 읽고 만든다. 수정 요청이 생기면 "무엇을, 왜" 고쳤는지 아래 기록에 추가한다. 같은 지적을 두 번 받지 않는 것이 목표.

## 기본 형식 (2026-10-15, 사용자 제공 레퍼런스 기준)
- 크기 1080×1350, 구성: 표지 → 번호 카드(4~5장) → 마무리 CTA
- 표지: 검정 바탕, 좌상단 "● 시리즈명" 라벨, 중앙에 기기 목업, 하단에 작은 빨간 부제 + 큰 흰색 굵은 제목 2줄
- 번호 카드: 위 55%는 연회색 바탕에 휴대폰 목업 2개(핵심 부분 빨간 테두리 강조), 아래 45%는 흰 바탕
  - 빨간 원 번호 → 검정 굵은 제목 2줄 → 회색 본문 3줄
- 마무리: 연한 분홍 바탕, 빨간 강조 문구, 프로필/행동 유도 버튼
- 포인트 색: 코랄 레드(#F0564A) 1가지만
- 모션: 요소는 위→아래 순서로 0.3초 간격 등장, 강조 테두리는 선이 그려지는 효과, 카드당 4~5초. PNG(마지막 프레임)와 MP4를 같은 HTML에서 뽑는다
