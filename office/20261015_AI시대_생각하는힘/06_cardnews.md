## 1장. 표지 (검정 바탕)
- 라벨(좌상단): ● AI 시대 생각 습관
- 부제(작은 빨간 글씨): AI가 답을 주는 시대, 생각은 덜 해도 될까?
- 헤드라인(흰색 굵게 2줄): 그래서 더 중요한 / 생각하는 힘
- 본문: 없음
- 시각 요소: 중앙에 노트북 목업, 화면에 AI 채팅창(보고서 초안 자동 작성 중). 커서 깜빡임
- 강조할 단어: 생각하는 힘

## 2장. 번호 카드 ① 인지 오프로딩
- 헤드라인: 자주 맡길수록 / 생각 점수는 낮았다
- 본문: 666명 조사(Gerlich, 2025). 생각을 AI에 맡길수록(인지 오프로딩) 비판적 사고 점수가 낮게 나타났어요. 단, 인과는 미입증.
- 시각 요소: 휴대폰 1 = AI에 "대신 정리해줘" 입력 화면 / 휴대폰 2 = 설문 결과 막대그래프(AI 사용 빈도↑, 점수↓), 그래프에 mark
- 강조할 단어: 인지 오프로딩, 낮게 나타났어요

## 3장. 번호 카드 ② MIT 실험
- 헤드라인: AI로 쓴 글, / 내 글로 잘 기억 못 했다
- 본문: 54명 뇌파 실험. 도구 없이 쓴 집단의 뇌 연결성이 가장 높았어요. 연구진은 '인지 부채'로 설명. (프리프린트·소규모)
- 시각 요소: 휴대폰 1 = LLM·검색엔진·도구 없음 3집단 비교 도식, '도구 없음'에 mark / 휴대폰 2 = "내가 쓴 문장 인용해 보기" 빈칸 화면
- 강조할 단어: 인지 부채, 도구 없이

## 4장. 번호 카드 ③ 역할 변화
- 헤드라인: 생각은 사라지지 않고 / 역할이 바뀐다
- 본문: 지식노동자 319명 사례 936건 분석. AI를 믿을수록 덜 생각하고, 내 능력을 믿을수록 더 생각했어요.
- 시각 요소: 휴대폰 1 = '직접 쓰기' 화면(흐리게) / 휴대폰 2 = 검증·통합·판단 3단 체크 화면, 3단에 mark
- 강조할 단어: 역할이 바뀐다, 더 생각했어요

## 5장. 번호 카드 ④ AI 환각
- 헤드라인: AI는 그럴듯하게 / 틀린다
- 본문: 가짜 판례 6건 제출로 벌금 5,000달러(2023). 딜로이트 호주는 가짜 인용으로 대금 일부 환불(2025).
- 시각 요소: 휴대폰 1 = 판례 목록 화면, 가짜 판례에 mark / 휴대폰 2 = 보고서 각주에 '출처 확인 필요' 빨간 표시
- 강조할 단어: 가짜 판례 6건, 가짜 인용

## 6장. 번호 카드 ⑤ 일터가 원하는 역량
- 헤드라인: 고용주가 꼽은 1위 / 분석적 사고
- 본문: WEF 2025, 고용주 1,000여 곳 조사. 10곳 중 7곳이 분석적 사고를 필수 역량으로 꼽았어요.
- 시각 요소: 휴대폰 1 = 역량 순위 리스트, 1위 '분석적 사고'에 mark / 휴대폰 2 = 10칸 아이콘 중 7칸 채움, 창의적 사고 57% 보조 표기
- 강조할 단어: 10곳 중 7곳, 분석적 사고

## 7장. 번호 카드 ⑥ 요약 체크리스트
- 헤드라인: 생각하는 힘 지키는 / AI 사용법 4가지
- 본문: 내 생각 먼저 적기 / 출처는 원문 확인 / "왜? 반대 근거는?" 묻기 / 최종 결정은 내가
- 시각 요소: 휴대폰 1 = 메모장에 내 초안 먼저 작성 / 휴대폰 2 = 체크리스트 4개, 체크박스 하나씩 순서대로 mark
- 강조할 단어: 내 생각 먼저, 최종 결정은 내가

## 8장. 마무리 CTA (연한 분홍 바탕)
- 헤드라인: AI는 생각을 / 확장하는 도구
- 본문: 오늘 AI 답 하나, 직접 검증해 보셨나요? 나만의 검증 습관을 댓글로 나눠 주세요.
- 시각 요소: 빨간 강조 문구 + 프로필 영역 + 버튼 2개(저장하기 / 댓글 남기기). 하단 작은 글씨로 출처: Gerlich 2025, Kosmyna 외 2025, Lee 외 CHI 2025, WEF 2025, Mata v. Avianca, 딜로이트 호주
- 강조할 단어: 직접 검증
- 계정 표기: @[계정명] (확정 필요)
