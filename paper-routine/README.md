# 논문 5편 루틴 (인력개발정책)

## 원칙
- 논문을 직접 많이 읽지 않아도 되는 구조: **AI 요약 + 3문항 체크**로 하루 15분 읽기
- 아이디어는 떠오를 때 **Slack `#paper-routine`에 한 줄**로 남기기 (분류는 AI가 함)
- 하루 할 일은 3개 이하: ① 읽기 15분 ② 쓰기 200자 ③ 아이디어 정리

## 5편 후보 (주제 탐색 단계에서 확정)
| # | 가제 | 데이터 후보 |
|---|---|---|
| P1 | 직업훈련의 취업·임금 효과 | KLIPS, KEEP, 고용보험 DB |
| P2 | 기업 교육훈련 투자 결정요인 | HCCP, 사업체 직업훈련 실태조사, WPS |
| P3 | 청년 노동시장 이행과 훈련 | 청년패널, GOMS, KEEP |
| P4 | 성인 평생학습 참여 격차 | 평생학습 개인실태조사, KLIPS, PIAAC |
| P5 | 국가 간 HRD 정책 비교 | OECD(PIAAC, ALMP 지출), ILOSTAT, Eurostat AES |

## 국외 자료 확인 결과 (2026-10 웹 확인)
- **PIAAC 2023 (OECD Survey of Adult Skills)**: 2024년 12월 공개, 31개국 16~65세, 한국 포함. 데이터 분석 매뉴얼 제공.
- **Eurostat AES 2022**: 18~69세 대상. 마이크로데이터는 EU 내 대학·연구기관 등 기관 단위만 접근 가능(개인 불가). 국가별 Scientific Use File 별도.
- **Eurostat CVTS**: 마이크로데이터 확인된 회차는 2005/2010/2015.
- **O\*NET**: 무료 공개 DB (확인 시점 30.3).
- ILOSTAT, OECD ALMP, UNESCO UIS는 별도 확인 필요.

## 단계 (주 단위, 5편 병행)
1. 1–2주: 주제 탐색, 선행연구 10편씩 AI 요약, 연구질문 확정
2. 3–4주: 데이터 신청·확보 (신청 소요 시간이 길어 먼저 시작)
3. 5–8주: 분석 설계·실행
4. 9–12주: 초고 → 피드백 → 투고 학술지 선정
(5편을 동시에 쓰지 않고 **주 단위로 1편에 집중하는 회전**: 월 P1, 화 P2, 수 P3, 목 P4, 금 P5+주간 리뷰)

## 매일 루틴 (평일 오전 9시 Slack)
1. 오늘의 논문(요일 회전) 한 줄 상태
2. 읽기: 논문 1편 AI 요약 + 3문항 (연구질문? 데이터? 내 논문에 쓸 문장은?)
3. 쓰기 마이크로태스크 1개 (200자)
4. 어제 이후 아이디어 정리 → 해당 논문 폴더로 분류
5. 금요일: 주간 리뷰 (진척, 막힌 점, 다음 주 계획)
