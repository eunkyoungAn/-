# 블로그 자동화 플로우 (현재)

- 슬랙 #blog-bot에 주제·메모·사진을 아무 때나 올리면, '블로그 슬랙 자동 확인' 루틴이
  매일 09:07~22:07(KST) 매시간 채널을 확인해 원고를 만든다. (최대 약 1시간 대기)
- 월요일 08:52 '① 주제 질문' 루틴은 주제 후보를 제안하는 알림 용도로 유지.
- 원고 = post.md + 서식 포함 post.html(Artifact 링크). "수정: ..." 답장 → 고쳐서 재게시.
- 마지막으로 확인한 슬랙 메시지 위치: state/slack_last_ts

# 블로그 자동화 플로우

```
[루틴① 질문]  매주 월 09:00 (KST)
  └ 슬랙 #blog-bot 에 "이번 주 주제?" + 주제 후보 3개 전송
        ↓ (사용자가 스레드에 답장: 주제 + 메모 + 사진)
[루틴② 수거]  매주 월 21:00 (KST) (또는 슬랙에서 "@작성" 후 수동 실행)
  ├ 스레드 읽기 → 정보 부족하면 추가 질문 1회 (사진 요청 포함) → 종료
  └ 충분하면 → 글 생성
        ↓
[글 생성]  /blog-post 스킬
  ├ posts/날짜-slug/post.md   ← 붙여넣기용 본문
  ├ posts/날짜-slug/meta.md   ← 제목 후보·태그·상태
  └ posts/날짜-slug/images/   ← 슬랙 사진 다운로드
        ↓
[전달]  커밋·푸시 → 슬랙 스레드에 본문 미리보기 + 파일 링크
        ↓
[발행]  사용자가 블로그 편집기에 붙여넣고 사진 삽입 → 슬랙에 "발행완료 <링크>"
        → 다음 루틴 실행 시 status: published 로 갱신
```

## 왜 루틴을 둘로 나누나
Claude 세션은 슬랙 답장이 오는 순간 자동으로 깨어나지 않는다.
그래서 "질문 보내기"와 "답장 읽고 작성하기"를 시간 차를 둔 두 루틴으로 나눈다.
급할 땐 claude.ai 앱에서 루틴②를 바로 실행(Run now)하면 된다.

## 슬랙 답장 형식 (자유롭게 써도 되지만 이러면 정확도↑)
```
주제: 초등 3학년 아이와 용돈 기록장 시작하기
핵심: 주 3천원, 아이가 직접 쓰고 기록. 2주 만에 군것질 줄어듦
대상: 초등 저학년 부모
사진: (첨부)
```

## 네이버 임시저장 방식
네이버 블로그는 글쓰기 API가 없어 자동 발행 대신 '임시저장 원고'까지 자동화한다.
1. 슬랙 스레드(또는 post.md)에서 ===== 사이 본문 복사
2. 네이버 글쓰기 → 제목·본문 붙여넣기 → [임시저장]
3. 📷 표시 위치에 사진 삽입, 태그 입력 → 발행
4. 슬랙 스레드에 "발행완료 <링크>" → 다음 루틴 때 status: published
