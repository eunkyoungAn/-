# 블로그 자동화 플로우

```
[루틴① 질문]  매주 월 09:00
  └ 슬랙 #blog-bot 에 "이번 주 주제?" + 주제 후보 3개 전송
        ↓ (사용자가 스레드에 답장: 주제 + 메모 + 사진)
[루틴② 수거]  매주 월 21:00 (또는 슬랙에서 "@작성" 후 수동 실행)
  ├ 스레드 읽기 → 정보 부족하면 추가 질문 1회 (사진 요청 포함) → 종료
  └ 충분하면 → 글 생성
        ↓
[글 생성]  /blog-post 스킬
  ├ posts/날짜-slug/post.md   ← 붙여넣기용 본문
  ├ posts/날짜-slug/meta.md   ← 제목 후보·태그·상태
  └ posts/날짜-slug/images/   ← 슬랙 사진 다운로드
        ↓
[전달]  커밋·푸시 → 슬랙 스레드에 본문 미리보기 + 파일 링크
        ↓
[발행]  사용자가 블로그 편집기에 붙여넣고 사진 삽입 → 슬랙에 "발행완료 <링크>"
        → 다음 루틴 실행 시 status: published 로 갱신
```

## 왜 루틴을 둘로 나누나
Claude 세션은 슬랙 답장이 오는 순간 자동으로 깨어나지 않는다.
그래서 "질문 보내기"와 "답장 읽고 작성하기"를 시간 차를 둔 두 루틴으로 나눈다.
급할 땐 claude.ai 앱에서 루틴②를 바로 실행(Run now)하면 된다.

## 슬랙 답장 형식 (자유롭게 써도 되지만 이러면 정확도↑)
```
주제: 초등 3학년 아이와 용돈 기록장 시작하기
핵심: 주 3천원, 아이가 직접 쓰고 기록. 2주 만에 군것질 줄어듦
대상: 초등 저학년 부모
사진: (첨부)
```

## 붙여넣기 주의
- 워드프레스·티스토리(마크다운 모드) → post.md 그대로 붙여넣기.
- 네이버 블로그 → 마크다운을 인식하지 않으므로 `post.md` 하단 "네이버용 텍스트" 블록을 사용.
- 사진 위치는 본문에 `[사진1: 설명]`으로 표시되어 있음.
