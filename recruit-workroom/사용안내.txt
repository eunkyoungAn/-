인재추천 워크룸

실행
Python 3.10 이상을 설치해 두세요.
Windows: 실행.cmd 더블클릭 / Mac·Linux: 실행.command 실행
처음 한 번 필요한 패키지를 자동 설치하고, 브라우저가 http://127.0.0.1:8765 로 열립니다.
실행 창을 닫으면 서버가 종료됩니다. 이 주소는 내 컴퓨터에서만 열립니다.

사용 순서
1. ‘이력서’ 화면에서 내용을 붙여넣거나 PDF/DOCX/TXT/PNG/JPG/WebP를 첨부하고 ‘다음’을 누릅니다.
2. ‘기업·공고’ 화면에서 기업명, 직무와 채용공고 본문을 입력합니다. URL은 출처로만 기록하며 자동 수집하지 않습니다.
3. ‘연락 목적’ 화면에서 기업 문의 / 후보자 제안 / 동의 후 기업 추천 / 결과 재문의 중 선택합니다. 상담 내용과 지원사업 기준은 필요한 경우 추가합니다.
4. AI 연결 설정 후 ‘분석하고 메일 작성’을 누릅니다.
5. ‘결과 확인’ 화면에서 ‘분석 결과’와 ‘메일 초안’을 각각 읽습니다. 메일은 직접 수정한 뒤 복사하거나 텍스트로 내려받습니다.
이전 단계로 이동해도 입력 내용은 유지됩니다. 새로고침하거나 창을 닫으면 입력 내용은 사라집니다.

가독성 개선 버전
입력과 결과를 한 화면씩 보여주고 본문 글씨를 17~18px로 키웠습니다.
사업 기준 등 선택 항목은 펼쳐볼 수 있으며, 좁은 창에서도 한 열로 표시합니다.
기존 화면이 열려 있다면 입력 중인 내용을 보관한 뒤 새로고침하면 새 화면이 반영됩니다.

AI 연결
연결 설정에 본인의 OpenAI API 키와 사용할 모델을 입력합니다. 또는 서버 환경변수 OPENAI_API_KEY, OPENAI_MODEL을 사용합니다.
API 키는 대화창에 보내지 마세요. 화면 입력 키는 브라우저 저장소나 파일에 저장하지 않습니다.
API 사용료는 연결한 계정에 적용됩니다. 기본 모델 gpt-4.1-mini는 변경할 수 있습니다.
자동 분석은 입력 자료와 첨부 이미지를 https://api.openai.com/v1/responses로 전송합니다.
Responses API의 store:false를 사용하지만, 이것은 외부 서비스의 모든 로그·보존 정책이 없다는 뜻은 아닙니다.
이 앱은 이력서, 분석 결과, API 키를 파일·DB·브라우저 저장소에 자동 보관하지 않습니다.

API 연결 전
‘이 대화에서 분석할 요청 복사’로 현재 입력을 정리하여 Codex 대화에 붙여넣을 수 있습니다.
이미지는 요청 텍스트에 포함되지 않으므로 대화에 따로 첨부해야 합니다.
‘가상 예시 불러오기’는 사용법을 보여주는 고정된 예시이며 실제 AI 분석 결과가 아닙니다.

파일
파일당 8MB, PDF 최대 30쪽, 이미지 최대 3장. 암호화 PDF는 해제 후 사용합니다.
텍스트 없는 스캔 PDF는 이미지로 첨부하거나 내용을 붙여넣습니다.
나이·성별·사진을 직무 적합성의 평가 기준으로 사용하지 않습니다.
메시지 자동 전송, 잡코리아 로그인·이력서 수집, 외부 URL 자동 방문 기능은 없습니다.
지원 의사·자료 전달 동의, 실제 채용 상태와 사업 자격은 담당자가 확인합니다.

종료
이 버전은 컴퓨터의 127.0.0.1에서 실행합니다. 온라인 게시 사이트가 아닙니다.
서버는 실행 프로세스를 종료하거나 컴퓨터를 재시작하면 종료됩니다.
