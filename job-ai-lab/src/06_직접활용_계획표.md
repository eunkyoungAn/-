# 직접 활용 계획표 (개별 실습)

교육 뒤 내가 만든 시트와 폼을 내 업무에서 세 번 써 본다. 날짜 대신 "교육 뒤 1주 안"처럼 적어도 된다.

내 시트 이름: ______________________

| 회차 | 언제 | 어떤 자료로 | 확인할 것 | 고칠 점 기록 |
|---|---|---|---|---|
| 1회 | 교육 뒤 1주 안 | 가상 자료(실습 자료나 직접 만든 가짜 자료) | 설계한 순서대로 결과가 나오는가, 사람 확인 지점이 지켜지는가 | |
| 2회 | 교육 뒤 2주 안 | 개인정보를 지운 실제 자료 사본 | 이름·연락처가 결과에 없는가, [확인 필요]가 어디에 남는가 | |
| 3회 | 2회 뒤 | 2회와 같은 종류의 자료 | 고친 시트와 코드로 다시 실행해 결과가 나아졌는가 | |

결과가 기대와 다르면 탭 구성이나 코드를 고치고, 시트의 "고쳐 쓴 기록" 탭에 날짜, 바꾼 것, 이유를 적는다.

## 실제 자료를 넣기 전에

- 안전 사용 체크리스트의 여덟 문장에 모두 "예"인지 다시 본다. 하나라도 "아니오"면 실제 자료를 넣지 않는다.
- 원본은 내가 보관하고, AI에는 식별 정보를 지운 사본만 넣는다.
- 기관의 보안·개인정보 규정이 정해져 있으면 그 규정이 먼저다.
