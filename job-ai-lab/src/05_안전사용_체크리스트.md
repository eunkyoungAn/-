# 안전 사용 체크리스트 (개별 실습)

실제 자료를 넣기 전에 여덟 가지를 예·아니오로 답한다. "아니오"가 하나라도 있으면 실제 자료를 넣지 않는다.

| 번호 | 점검 문장 | 예 | 아니오 |
|---|---|---|---|
| 1 | 개인정보 원문(이름·연락처)을 넣지 않는다 | ☐ | ☐ |
| 2 | 근거로 쓸 자료가 정해져 있다 | ☐ | ☐ |
| 3 | 사람 확인 지점이 하나 이상 있다 | ☐ | ☐ |
| 4 | 자료와 결과를 어디에 둘지 정했다 | ☐ | ☐ |
| 5 | 시트와 폼의 공유 범위가 꼭 필요한 사람으로 한정되어 있다 | ☐ | ☐ |
| 6 | 가상 자료로 먼저 시험했다 | ☐ | ☐ |
| 7 | 결과물에 [확인 필요]·[가정]이 표시된다 | ☐ | ☐ |
| 8 | 다른 사람이 이어받아 쓸 수 있다 | ☐ | ☐ |
