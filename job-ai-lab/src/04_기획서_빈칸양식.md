# 내 업무용 자료 기획서 — 빈칸 양식 (개별 실습)

실명·연락처·내부 문서 원문은 적지 않는다. 업무의 순서와 자료 종류만 적는다.
채운 내용을 지시문의 [입력] 여덟 줄에 옮겨 적는다.

| 번호 | 칸 | 내가 적을 내용 | 예시 |
|---|---|---|---|
| 1 | 자동화할 업무 | | 집단상담 프로그램 참여 신청 정리와 조 편성 |
| 2 | 누가 쓰나 | | 나 혼자 / 우리 팀 / 기관 전체 |
| 3 | 입력 자료 | | 참여 신청 구글 폼 응답, 프로그램 계획서, 지난 회차 조 편성표 |
| 4 | 지금 하는 순서 | | 신청 응답을 내려받는다 → 희망 직무별로 나눈다 → 조를 짠다 → 안내 문자를 쓴다 → 팀장 확인 후 발송 |
| 5 | AI에게 맡길 일 | | 읽기, 분류, 계산, 초안, 대조 |
| 6 | 담당자가 판단할 일 | | 금액, 일정, 자격, 대외 발송 |
| 7 | 어디에 저장하나 | | 내 구글 드라이브 / 기관 공유 드라이브 / 내 컴퓨터 |
| 8 | 사람 확인 지점 | | 결과가 바깥으로 나가기 바로 앞 |

## 진행 순서

1. 위 빈칸 여덟 개를 채운다
2. AI 채팅에 지시문을 넣어 실행하고 설계 결과를 저장한다
3. 직접 활용 계획표를 채우고, 짝과 바꿔 사람 확인 지점을 점검한다

## 산출물

- 기획서 한 장(단계 흐름 포함)
- 구글 시트·구글 폼 구성안과 Apps Script 초안
- 직접 활용 계획
- 안전 사용 체크리스트 점검 결과
