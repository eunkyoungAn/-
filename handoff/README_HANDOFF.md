- 확인 요청 사항: 파일 크기(v2.pptx = 208,634 bytes), SHA-256 `fd094248f710bf4ce094dad1dfdbfb92813620d478756149d681669dcd8a96ca` 비교(PowerShell `Get-FileHash`), PDF(`AI_Intro_v2.pdf`)는 열리는지.
