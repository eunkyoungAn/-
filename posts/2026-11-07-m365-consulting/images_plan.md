# 이미지 계획 (밈 스타일 5장, 1200x800)

공통
- 원본 밈 구도만 참고: (a) 흰 배경 + 상단 굵은 검정 제목 + 두 캐릭터 말풍선이 서로 딴소리, (b) 이동 중 헤드폰 쓴 모습 + 짧은 캡션. 원본 인물·고양이 사진은 쓰지 않음.
- 캐릭터: 코치 스티커(templates/character_coach/) + 캐치. 주의: 캐치 이미지 파일은 해당 폴더에 없음. 별도 파일이 있으면 사용하고, 없으면 코치 스티커 2종으로 두 캐릭터 구도를 대체하거나 캐치를 새로 그려야 함.
- 코치 스티커에는 문구가 포함돼 있어 큰 제목과 겹치지 않게 배치.
- 하단 우측에 작게 "가상의 예시 이미지 | 커리어캐쳐 CareerCatcher" 표기. 수치·실제 사례·특정인처럼 읽히는 문구 없음.
- 말풍선은 한글 굵은 고딕, 제목은 검정 굵게 1줄.

제작 메모
- 3번은 본문 예시 문장과 동일하게 괄호 칸을 비워 둔 일반 문장만 사용.
- 4번은 지하철 배경을 단순 일러스트로, 실제 노선·승객 없음.
- 5장 모두 "가상" 표기 유지, 수료생·참여자 말처럼 보이는 인용 부호는 쓰지 않음(말풍선만 사용).
