# 이미지 계획 (밈 5장, 1200x800) - 사용자 원본 밈 템플릿 방식

이전 계획(코치 스티커·캐치 구도)은 폐기했습니다. 사용자가 준 원본 두 장을 템플릿으로 문구만 바꿔 씁니다.

템플릿
- A = /tmp/claude-0/-home-user--/922154c2-f7c3-51b6-9809-e606cc8d84d3/images/2.png : 흰 배경, 상단 굵은 제목, 노랑 옷(왼쪽)·빨강 옷(오른쪽) 캐릭터, 말풍선 3개. 원본 제목 '나랑 내 친구 대화 수준:'. 말풍선은 왼쪽 위 / 오른쪽 / 왼쪽 아래 순서.
- B = 같은 폴더 3.webp : 헤드폰을 쓰고 지하철 손잡이를 잡은 고양이 사진. 제목 없음, 상단에 흰 띠를 붙여 제목을 넣고 사진 위에 캡션 1~2줄.

공통 규칙
- 사진 1, 2, 3, 5 = 템플릿 A / 사진 4 = 템플릿 B.
- 말풍선 문구는 한 줄 9자 안팎, 최대 2줄(오른쪽 말풍선은 짧게, 3줄까지).
- 모든 이미지에 "가상 대화" 표기(사진 4는 "가상 장면"). 하단에 "커리어캐쳐(CareerCatcher)" 작게 표기.
- 노랑/빨강 캐릭터는 이름 없는 가상 인물. 특정 참여자·실제 상담 재현·수치·성과로 읽히는 문구 없음.
- 엇갈리는 대화의 리듬: 왼쪽이 말하고, 오른쪽이 되묻고, 왼쪽이 같은 말을 답답해하며 반복.
