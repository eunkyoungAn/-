office-manager 에이전트에게 다음 주제를 맡겨 전 과정을 진행하세요: $ARGUMENTS

## 진행 순서 (반드시 지킬 것)
1. office-manager가 원고(05_final.md)를 완성하면, 바로 이미지·최종물을 만들지 말고 사용자에게 파일을 첨부해 보여 준다.
2. "원고에서 수정할 부분이 있는지 확인해 주세요"라고 요청한다.
3. AskUserQuestion으로 버튼을 제시한다: "이대로 생성하기" / "수정 후 생성하기"(수정사항은 '기타'에 입력).
4. 사용자가 생성 버튼을 고른 뒤에만 카드뉴스 이미지 등 최종 결과물을 생성한다.

## 카드뉴스 기본 형식
카드뉴스를 만들 때는 별도 지시가 없으면 `templates/카드뉴스_캐러셀_기본형/`(README 먼저 읽기)과 `office/카드뉴스_디자인가이드.md`를 기준으로 만든다.
