# 쿠팡 리뷰 작성

## 원칙 (꼭 지킨다)
- 사용자가 실제로 구매·사용한 상품만 다룬다.
- **사용자 메모에 없는 사용 경험은 지어내지 않는다.** (사용 기간, 효과, 상황 등)
  메모가 부족하면 지어내지 말고 질문한다. 가짜 리뷰는 표시광고법 위반·쿠팡 제재 대상.
- 상품 사실 정보(용량, 구성, 크기 등)는 상품 페이지·주문 정보에 있는 것만 쓴다.
- 등록은 사용자가 직접 한다. 쿠팡 자동 로그인·자동 등록은 하지 않는다(약관 위반).

## 1. 입력 수집
- 입력 형식(한 줄): `상품명 / 별점 / 좋은 점, 아쉬운 점`
  예) `무선청소기 / 4 / 가볍다, 흡입력 괜찮음, 먼지통 작음`
- 슬랙 `#blog-bot`(C0C6ACW2ML7)에서 받는다. 빠진 항목이 있으면 스레드에 아래 3개만 묻고 status: asked 로 종료.
  1) 별점은 몇 점인가요? (1~5)
  2) 좋았던 점 하나는요?
  3) 아쉬운 점이 있었나요? (없으면 "없음")
- 사진이 있으면 받아서 `images/01.jpg` 식으로 저장. 얼굴·주소·송장 노출 여부를 확인 질문한다.

## 2. 작성 (`templates/review.md` 양식)
- 말투: 담백한 존댓말 후기체("~네요", "~입니다"). 과장·광고 문구·이모지 금지.
- 분량: 본문 3~6문장, 150~350자.
- 구성: 첫인상/핵심 장점 → 사용 느낌 → 아쉬운 점 → 추천 대상 한 문장.
- 별점과 톤을 맞춘다: 5점 만족 위주, 3점 이하는 아쉬운 점을 앞에 솔직히.
- 아쉬운 점이 "없음"이면 억지로 만들지 않는다.
- 한 줄 요약(20자 내외) 1개를 함께 만든다.
- 쿠팡 리뷰는 서식이 없으므로 마크다운 기호 없이 평문으로 쓴다.

## 3. 저장
- 폴더: `reviews/YYYY-MM-DD-<상품-slug>/` 안에 `review.md`, `meta.md`, `images/`.
- meta.md:
```
status: drafted        # asked → answered → drafted → posted
product: <상품명>
rating: <별점>
order_date: <알면>
slack_thread: <링크>
user_memo: <사용자 원문 메모 그대로>
```

## 4. 전달
- 커밋·푸시 후 슬랙 스레드에 답장: 별점 + 한 줄 요약 + 본문(복사용 그대로).
- 안내 문구: "쿠팡 앱 → 마이쿠팡 → 리뷰 관리 → 해당 상품 [리뷰 작성] → 붙여넣기 → 등록"
- 사용자가 "등록했어"라고 하면 meta.md status를 posted 로 바꾼다.
