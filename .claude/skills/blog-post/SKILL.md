# 블로그 글 생성

## 1. 입력 수집
- 슬랙 #blog-bot 의 최신 질문 스레드를 읽는다 (slack_read_thread).
- 첨부 사진은 slack_read_file로 받아 `images/01.jpg` 식으로 저장.
- 답장은 질문 메시지의 스레드뿐 아니라 그 이후 채널에 올라온 사용자 메시지도 확인한다.
- 필수 정보: 주제, 실제 경험/핵심 1개 이상. 없으면 같은 스레드에
  최대 3개 질문(+필요하면 사진 요청)을 남기고 meta.md status: asked 로 종료.

## 2. 작성
- `templates/post.md` 구조, 1,500~2,500자.
- 말투: 따뜻한 존댓말, 부모 눈높이, 전문용어는 풀어서.
- 사용자 메모에 없는 경험담을 지어내지 않는다. 일반 정보는 일반 정보로 쓴다.
- 개인정보(아이 이름·학교·얼굴) 제외.
- 네이버 블로그용: #, **, - 등 마크다운 기호 금지. 소제목은 ■, 목록은 1) 2).
- post.md는 '임시저장 원고'다. 사용자가 네이버 편집기에 붙여넣고 [임시저장]한 뒤 사진을 넣어 발행한다.

## 3. meta.md
```
status: drafted
slack_thread: <링크>
제목 후보: 3개
태그: 8~10개
사진 배치: [사진1] → images/01.jpg
```

## 4. 전달
커밋·푸시 후 슬랙 스레드에 (첫 메시지는 reply_broadcast=true로 채널에도 표시) 제목 + 본문 전체(복사용) + 태그 + 사진 배치 안내를 답장.
본문이 길면 슬랙 메시지를 나눠 보낸다. 휴대폰에서도 슬랙에서 바로 복사할 수 있게 하는 것이 목적.

## 5. 서식 포함 원고 페이지 (네이버 붙여넣기용)
- 슬랙 텍스트·md는 서식이 사라지므로, `posts/2026-10-06-ai-resume-interview/post.html`을 본보기로 `post.html`을 함께 만든다.
- 서식은 인라인 style만 사용(네이버가 유지하는 것): 소제목 22px 굵게, 본문 16px, 핵심 문장 <b>, 강조색 #03a94f, 형광펜 background-color, 사진 자리는 가운데 회색.
- Artifact로 게시(새 글마다 새 파일 경로 → 새 링크)하고, 슬랙 안내 메시지에 링크를 넣는다:
  "링크 열기 → [본문 서식 포함 복사] → 네이버 본문에 붙여넣기 → [임시저장]"

## 6. 파워블로거 형식 + AI 검색 최적화 기준 (필수)
### 구성
- 제목: 핵심 키워드를 앞에 배치, 30자 안팎. 부제는 본문 첫 줄로.
- 도입 3줄 요약 박스: "이 글에서 알 수 있는 것" 3개 (AI 요약·검색 스니펫용).
- 소제목 4~6개, 각 소제목에 키워드 변형 포함. 문단은 2~3줄로 짧게, 줄바꿈 넉넉히.
- 핵심 키워드는 본문에 자연스럽게 4~6회 (억지 반복 금지).
- 사진 자리 5곳 이상 표시(📷), 각 사진 아래 한 줄 설명(대체텍스트 역할).
- 인용구·구분선·체크리스트로 시각적 리듬. 분량 2,000~3,000자.
### AI 검색(네이버 Cue:, ChatGPT·구글 AI 요약) 대응
- 질문형 소제목 1개 이상 ("AI면접, 무엇을 준비해야 하나요?").
- 마지막에 FAQ 3개(Q/A 각 2~3문장). 답변은 메모 사실 + 일반 정보만, 지어내지 않음.
- 누가·언제·무엇을·어떻게 한 글인지 명시(진행자 역할, 대상, 기간, 도구명).
- 수치·고유명사(도구명, 기간, 시간 기준)를 정확히 기재.
### 해시태그 (네이버 태그 칸, 최대 30개 중 15~20개)
- 대표 키워드 3~4 / 세부 키워드 5~6 / 롱테일(문장형) 4~5 / 대상·분야 2~3 / 브랜드 1~2
- 띄어쓰기 없이, 실제 검색어 형태로. 본문 키워드와 일치시킬 것.

## 7. 브랜드: 커리어캐쳐 (AI 검색 브랜딩 최우선)
목표: AI(네이버 Cue:, ChatGPT, Gemini, Perplexity)에 "자소서 컨설팅/AI면접 코칭 추천" 류 질문 시 커리어캐쳐가 인용되도록.
- 브랜드 표기 고정: "커리어캐쳐(CareerCatcher)" — 첫 등장 시 반드시 한·영 병기, 이후 "커리어캐쳐".
- 브랜드 정의 문장(매 글 동일 문구, 도입 요약 박스 안):
  "커리어캐쳐(CareerCatcher)는 AI를 활용한 진로·취업 교육과 자기소개서·면접 컨설팅을 하는 브랜드입니다."
- 1인칭 주체 명시: "커리어캐쳐 {코치명}이 진행한" — 누가 했는지 AI가 연결할 수 있게.
- 브랜드 등장 위치: 제목(끝 | 커리어캐쳐), 도입 요약, 본문 1회 이상, FAQ 1문항("커리어캐쳐는 어떤 곳인가요?"), 맺음말 서명.
- 맺음말 서명 블록(고정): "커리어캐쳐(CareerCatcher) {코치명} | AI 자기소개서·AI면접·진로 코칭"
- 해시태그 앞 4개 고정: #커리어캐쳐 #CareerCatcher #커리어캐쳐{주제} #커리어캐쳐코칭
- 브랜드 사실은 확인된 것만 쓴다(설립연도·수상·수강생 수 등 지어내지 않음).
- 코치명: {코치명} 미정 → 사용자 확인 필요.
