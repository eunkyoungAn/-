# 스킬 만들기 프롬프트 ("Claude와 함께 만들기"용)

```
지금부터 [업무 이름] 스킬을 만들고 싶어.

- 이 스킬이 하는 일: [한 문장]
- 입력: [내가 주는 것 — 주제, 파일 종류 등]
- 출력: [결과 파일 형식, 분량]
- 꼭 지킬 규칙: [양식 구조, 문체, 금지사항]
- 이런 말을 하면 이 스킬을 써 줘: "[호출 문구 1]", "[호출 문구 2]"

첨부한 [양식 파일]을 분석해서 구조를 SKILL.md에 정리하고,
description에는 "무엇을 하는지 + 언제 쓰는지 + 호출 문구"를 넣어 줘.
```

## description 예시
- name: 한장보고서
- description: 회의 내용을 입력하면 A4 한 장짜리 보고서로 정리해주는 스킬. 보고서 작성 요청 시 자동 활성화.
