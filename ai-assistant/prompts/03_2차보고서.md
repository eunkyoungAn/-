# [2차] 분석결과 보고서 프롬프트

```
1차 분석 결과를 바탕으로 「[보고서 제목]」를 작성하세요.

보고서는 다음과 같이 구성하세요.
- 핵심 요약
- 조사 목적과 개요
- 전체 분석
- 집단별 특징
- 주요 시사점
- [업무명] 권고사항
- 실행 과제
- 분석의 한계

핵심 결론을 보고서 앞부분에 제시하고, 수치와 분석 근거를 연결하세요.
사실·분석·권고를 명확히 구분하고, 객관적이며 간결한 업무보고 문체를 사용하세요.
분량: [A4 1장 / 2장]
자료에 없는 내용은 [자료 필요] 또는 [확인 필요]로 표시하세요.
```
