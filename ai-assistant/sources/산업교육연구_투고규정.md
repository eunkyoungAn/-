## 1. 투고 및 발간 규정 (요점)

| 항목 | 내용 |
|---|---|
| 투고 자격 | 산업교육 분야에 관심 있는 사람 누구나 |
| 제출처 | 학회 편집위원회 |
| 조건 | 다른 간행물에 발표되지 않은 논문 |
| 책임·판권 | 내용 책임은 집필자, 판권은 별도 명시 없으면 학회 귀속 |
| 심사료 | 10만원 |
| 게재료 | 15만원, 20매 초과 시 초과 1장당 2만원 (학회지 1부 + 별쇄본 10부 제공) |
| 분량 | A4 20매 내외 |
| 접수일 | 편집위원회에 원고가 도착한 날 |
| 발간 | 연 2회(2월 28일, 8월 31일), 원고는 수시 접수 |
| 게재 가능 유형 | 문헌고찰, 이론도출, 이론검증(실증), 사례 연구, 현장 실천 연구, 프로그램 개발 연구, 기타 |

심사 절차
1. 투고요령에 맞지 않는 원고는 보완 요청 대상
2. 접수 즉시 접수일 서면 통지, 분야별 편집위원이 심사위원 3인 선정
3. 3인 비밀심사(양방향 익명). 게재가·게재불가로 갈리면 제3 심사위원이 최종 판단
4. 심사위원은 의뢰일로부터 15일 이내 심사
5. 수정 요청 시 저자는 30일 이내 수정본 + **수정요지** 제출. 사유 통보 없이 미제출 시 철회 간주
6. 수정본은 1차 심사자가 재심사 → 통과 논문만 게재 확정
7. 게재예정증명은 게재 확정 후 발급

게재 결정 기준(10개): 연구의 필요성, 학술지 적합성, 선행연구·문헌고찰의 철저성, 창의성, 내용 전개의 논리성, 연구방법의 적절성, 결론의 적절성·합리성, 이론적·학문적 기여, 사회적·실천적 기여, 편집기술상 요건

## 2. 논문 작성 및 편집 규정

### 원고 작성
- 아래한글 또는 MS-Word(2010 이상 권장)
- 1면: 국문 제목, 성명(제1저자·교신저자와 공동저자 구분), 소속(각주), 연락주소, 전화, e-mail, 원고 매수
- 2면: 국문 요약(A4 1/2매 이내) + 핵심 되는 말(Key word)
- 마지막: 영문 초록(Abstract) + 영문 제목, 영문 성명, Key words
  - 원문 모순: '라'항은 국문 요약 1/2매, '마'항은 "영문초록 및 국문 요약 1매 이내". 국문 요약은 1/2매로 맞추는 것이 안전 [추론]
- 학술용어는 가능한 한 국문, 필요 시 괄호 안에 영문 병기
- 페이지 번호 넣지 않음

### 원고 체제 (양적 연구)
국문 요약 → Ⅰ. 서론 → Ⅱ. 이론적 배경 → Ⅲ. 연구방법 → Ⅳ. 연구 결과 → Ⅴ. 결론 및 제언 → 참고문헌 → Abstract
질적 연구·연구보고서 재구성 논문은 저자 재량(편집위원회 최종 결정)

### 서식표

- 번호 체계: Ⅰ → 1 → 1) → (1)
- 표는 `<표 Ⅱ-1>`, 그림은 `[그림 Ⅱ-1]` 식으로 번호. 표 제목은 위, 그림 제목은 아래. 주석·출처는 각각 아래
- 표 선: 위·아래 굵은 실선, 좌우 세로선 없음, 구분선은 이중선
- 각주는 최소화, 해당 면 하단

### 참고문헌·인용
- 본문 인용: (김종인, 2002), 쪽 인용은 (Marsick, 1991: 150)
- 3~5인: 첫 인용부터 (정석희 외, 2003) / (Garavan et al., 2002) 형태 예시
- 7인 이상: 본문은 첫 저자 + 외/et al., 참고문헌은 6번째 저자까지 쓰고 외/et al.
- 번역서: 본문 (Goldstein & Ford, 2004/2002), 참고문헌은 원저자. (번역연도). 번역서명 (역자 역.). 출판사. (원저 연도 출판)
- 배열: 국문(가나다순) → 외국문헌(알파벳순), 본문 끝에 장을 달리해 기재
- 도서: 저자. (연도). 제목. (출판지:) 출판사.
- 학술지: 저자. (연도). 논문제목. 학술지명, 권(호), 쪽.
- 학위논문: 주현미. (2007). 제목. 석사학위논문, 서울대학교.
- 그 밖은 APA 참조

주의 [추론]
- 학회 예시는 APA 6판 계열(7인 이상 처리, 출판지 표기, 학위논문 표기)이다. 평소 기준인 APA 7판과 다르므로 **이 학술지에 투고할 때는 학회 규정을 우선**하고, 규정에 없는 항목만 APA 7판으로 채운다.
- 원문 예시에 오탈자가 있으니 그대로 베끼지 않는다: Foil → Fiol, Schon/Schol → Schön, Slogan Management Review → Sloan Management Review, Gunningle → Gunnigle, Addision-Wesley → Addison-Wesley, 저널 예시의 "9(1) 75-88" 쉼표 누락, Wolchik 예시 끝의 쉼표.

## 3. 연구윤리규정 (투고자에게 해당하는 부분 중심)

연구자
- 제1조 표절 금지: 출판·미출판·전자저작물 모두 출처 명시, 문자 아닌 결과물도 고지
- 제2조 저자 표시: 실제 기여한 사람만 저자, 순서는 지위가 아니라 기여도. 학생 학위논문을 학술지에 낼 때 학생은 일반적으로 저자
- 제3조 중복 게재 금지: 게재 예정·심사 중 원고 포함. 다른 언어로 낸 결과도 재출판 전 확인
- 제4조 인용: 상식이 아니면 출처 명시. 심사·개인 접촉으로 얻은 자료는 제공자 동의 후 인용. 선행연구와 본인 주장을 독자가 구분할 수 있게
- 제5조 수정: 심사 의견 최대한 반영, 동의하지 않으면 근거·이유를 상세히 써서 편집위원회에 통지

편집위원(제7~13조): 공정 관리, 전문 심사위원 의뢰(친분·적대 관계 회피, 평가 차이 크면 제3 전문가), 게재 결정 전 비공개, 중복출판 거부·통지, 부정행위 조사, 심사자·저자 익명 유지, 오류 발견 시 수정·철회

심사위원(제14~18조): 기간 내 성실 심사, 적임 아니면 즉시 통보, 근거 없는 탈락·관점 차이로 인한 탈락 금지, 정중한 표현, 비밀 유지(출판 전 무단 인용 금지), 이해관계 공개

시행(제19~28조): 신규회원 서약, 위반 보고(제보자 신원 보호), 윤리위원회 5인 이상, 조사 비협조도 위반, 소명 기회 보장, 징계는 경고·자격 정지·박탈, 2009-03-01 시행

## 투고 전 점검표 (이 자료로 만든 것)
- [ ] 다른 곳에 발표·심사 중이 아닌 원고인가
- [ ] 1면 저자 정보·각주 소속·원고 매수 기재
- [ ] 국문 요약 1/2매 이내 + 핵심 되는 말
- [ ] 체제 순서(요약~Abstract) 준수, 페이지 번호 없음
- [ ] 번호 체계 Ⅰ-1-1)-(1), 서식표대로 글꼴·크기
- [ ] 표·그림 번호, 제목 위치, 표 선 처리, 출처 표기
- [ ] 본문 인용과 참고문헌 목록 1:1 대응, 국문→영문 순 정렬
- [ ] 분량 A4 20매 내외(초과 시 장당 2만원)
- [ ] 저자 순서가 기여도 기준인가
- [ ] 수정 요청 시 30일 이내, 수정요지(답변서) 함께 제출
