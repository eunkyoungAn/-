# [퇴근N남부] claude활용 오피스 작성 실무 — 교안 요약

- 기관: 서울시 남부여성발전센터 / 강사: 커리어캐쳐 안은경
- 1회차 2026.6.17(수), 2회차 2026.6.24(수)

## 1회차 — 생성형AI 현황과 Claude, 좋은 보고서의 조건
1. **현재 상태 점검**: 검색·초안용 → 정리·요약용 → 전 과정 활용·맥락 설계·결과 검증
2. **활용 현황**(나우앤서베이, 2025.5): 직장인 71.3% AI 사용, 61.2% 조직에서 사용 권장. 1위 ChatGPT(87.0%), Claude 9.8%. 주 용도 정보검색·요약 75.3%, 문서 작성 44.9%
3. **LLM 원리**: 질문 → 지식 소스 검색 → 맥락 보강 → 모델 생성 (RAG). 모든 지식을 가진 게 아님
4. **AI 비교**: ChatGPT(범용·창의), Claude(인간적 글쓰기·장문), Gemini(구글 연동·멀티모달), Perplexity(출처·실시간 검색)
5. **핵심 메시지**: "우리는 오케스트레이터로서 사용해야 한다" — 강점 파악 → 일 배분 → 결과 통합
6. **요금제·크레딧 절약**: 15~20개 메시지마다 새 대화, 질문 묶기, 재전송 대신 편집, 반복 설명은 Project 지침에, 출력 길이 명시, 간단한 작업은 Haiku
7. **스킬 vs 프로젝트**: 스킬=절차(필요할 때 로드, SOP), 프로젝트=배경지식(항상 로드, 인수인계 파일)
8. **좋은 보고서 3요소**: 구조화된 논리 · 객관적 데이터 · 시각화
9. **객관적 데이터 수집 도구**: NotebookLM(소스 기반 보고서·인포그래픽, Docs 내보내기), Perplexity(웹·학술·딥리서치), Liner(웹+논문 출처 검색)

## 2회차 — Claude Project·Skills로 보고서 작성
1. **Project = 작업용 방(맥락)**, **Skills = 작업 매뉴얼(실력)** → 함께 써서 "자료를 이해하고 정해진 방식으로 실행"
2. **Project 실습**: 새 프로젝트 → 지침 입력(XML 보고서 지침) → 참고 파일 추가 → 실습자료(여행 선호지역 xlsx, 가상자료 120명) → 1차 분석 → 2차 보고서
   - 무료 요금제끼리면 ChatGPT Project로 대체
3. **Skills 실습**: 설정 → 기능(코드 실행·파일 생성 켜기) → 사용자 지정 → 스킬 만들기(함께 만들기/지침 작성/업로드) → 한 장 보고서 hwpx 스킬
4. **description이 핵심**: Claude가 대화를 보고 스스로 스킬을 불러오는 기준
5. **Quality = 인간의 몫**: 정확성·신뢰성·최신성·맥락 적합성·일관성·완결성 + 제목 줄바꿈, 페이지 수·여백, 볼드 디테일
6. **다양한 스킬**: 공개 스킬 모음(k-skill 등) — 예) biz-health-check 사업자 실사 리포트
7. **FAQ**: 스킬 많으면 토큰 소모 → 1~2개 위주 / 스킬 조합 가능 / 2026.2 무료 개방
