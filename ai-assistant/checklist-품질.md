# 품질 체크리스트 — "Quality = 인간의 몫"

## A. 품질 6요소 (내용)
- [ ] **정확성** Accuracy — 수치·이름·날짜가 원자료와 일치하는가
- [ ] **신뢰성** Reliability — 출처가 공신력 있고, 2곳 이상 교차 확인했는가
- [ ] **최신성** Timeliness — 최근 2~3년 자료인가, 조회일을 적었는가
- [ ] **맥락 적합성** Relevance — 보고 받는 사람·목적에 맞는 내용인가
- [ ] **일관성** Consistency — 용어·숫자 단위·문체가 처음부터 끝까지 같은가
- [ ] **완결성** Completeness — 요청 항목이 빠짐없이 들어갔는가, `[자료 필요]`가 남아 있지 않은가

## B. 사람의 마무리 (형식)
- [ ] 제목 줄바꿈 — 읽기 좋게 직접 엔터로 조절
- [ ] 페이지 수·여백 — 분량이 정해진 경우 반드시 확인
- [ ] 디테일 — 빽빽하면 문단 나누기, 핵심은 볼드

## C. 커리어캐쳐 공통
- [ ] 개인정보(실명·학교·얼굴) 없음
- [ ] 브랜드 문체(`careercatcher-skill-os`) 적용
- [ ] 타인 저작물(그래프·캡처) 출처 표기
