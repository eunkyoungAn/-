# 커리어캐쳐 업무 비서 (안은경 강사용)

강의용 비서를 내 업무에 맞게 바꾼 버전. 정리하는 자료는 네 가지(기관 담당자 단톡, 수강생 단톡, 회의·통화 메모, 협업 강사 대화)이고, 주간 보고는 **기관·과정별로** 묶는다.

## A. claude.ai에서 만들기 (약 15분)
| 순서 | 할 일 | 화면 경로 |
|---|---|---|
| 1 | 코드 실행 및 파일 생성 켜기 | 설정 → 기능 |
| 2 | `careercatcher-work-assistant.zip` 업로드 | 설정 → 사용자 지정 → 스킬 → + → 스킬 업로드 |
| 3 | 프로젝트 "커리어캐쳐 업무 비서" 만들기 | 왼쪽 바 → 프로젝트 → 새 프로젝트 |
| 4 | `지침.md`의 글을 지침 칸에 붙여넣고 `[ ]`(내 표시 이름, 운영 중인 기관·과정) 채우기 | 프로젝트 → 지침 |
| 5 | 빈 `업무목록.md` 올리기 | 프로젝트 → 파일 → + |

**처음 써 보기 (가상 자료로 연습)**
1. 프로젝트 안 새 채팅에 `../samples/내비서/` 세 파일을 올리고 "세 파일 할 일 뽑아줘"라고 합니다.
2. 후보 표를 보고 "1·2번 승인, 3번은 기한 ○일로 승인" 식으로 답합니다.
3. 업무 목록 표를 `업무목록.md`에 붙여 넣어 저장합니다.
4. "주간 보고 만들어줘"라고 하면 기관·과정별 보고가 나옵니다.

**평소에 쓰는 말 예시**
- "A센터 단톡 오늘 치 정리해줘" (파일 첨부)
- "통화 메모: B대학 담당자, 캠프 일정 12/3로 변경, 견적서 다음 주까지" → 메모도 그대로 붙여 넣으면 됨
- "3번 완료, 드라이브에 운영일지 올림"
- "이번 주 할 일 Top 3만"
- "주간 보고 만들어줘"

## B. Claude Code 확장판 (내 컴퓨터)
근거 검증·승인 기록·중복 방지를 프로그램으로 강제하는 버전. 기관·과정 칸을 지원한다.
```bash
python3 workdesk/tools/workdesk.py ingest A센터_단톡.txt --by 안은경 --project "A센터 AI 실무과정"
```
- 그다음은 세션에서 `[업무정리] A센터 단톡 | 업무후보`로 "업무 후보 뽑아줘" → 승인 → "주간 보고"
- 주간 보고는 기관·과정이 있으면 자동으로 기관·과정별로 묶인다.
- 자세한 사용법: `../README.md`

## 지킬 것
- 실제 단톡방은 기관 정책과 대화 참여자 동의를 먼저 확인하고, 필요한 구간만 내보낸다.
- 수강생 이름·연락처는 비서가 업무 목록·보고에 쓰지 않도록 규칙을 넣어 두었다. 결과를 공유하기 전 한 번 더 확인한다.
- 실제 대화 원문은 이 저장소에 올리지 않는다(`samples/`는 모두 가상).
