# [강의 실습] 나만의 업무 정리 비서 만들기 (코딩 없음, 약 60분)

단톡방 대화나 회의 메모를 올리면 **할 일을 근거와 함께 뽑고 → 내가 승인한 것만 업무 목록에 넣고 → 주간 보고**까지 해 주는 비서를 claude.ai에서 만든다.
「claude활용 오피스 작성 실무」 2회차의 **Project(작업용 방) + Skill(작업 매뉴얼)**을 그대로 응용한다.

## 준비물
- Claude 계정 (Project 실습은 Pro 이상. 무료라면 ChatGPT 프로젝트로 대체 → 아래 참고)
- 이 폴더의 파일: `지침.md`, `work-organizer.zip`
- 실습 자료: `../samples/운영팀_대화_가상.txt`, `../samples/운영회의_메모_가상.md` (모두 가상 대화)

## 실습 순서
| 단계 | 시간 | 할 일 | 화면 경로 |
|---|---|---|---|
| 0 | 5분 | 코드 실행·파일 생성 켜기 (스킬 사용에 필요) | 설정 → 기능 → 코드 실행 및 파일 생성 ON |
| 1 | 5분 | 스킬 올리기: `work-organizer.zip` | 설정 → 사용자 지정 → 스킬 → + → 스킬 업로드 |
| 2 | 5분 | 프로젝트 만들기: 이름 "업무 정리 비서", 지침에 `지침.md` 내용 붙여넣기 | 왼쪽 바 → 프로젝트 → 새 프로젝트 |
| 3 | 10분 | **실습 1** 대화 파일 올리고 "할 일 뽑아줘" | 프로젝트 안 새 채팅 |
| 4 | 10분 | **실습 2** 결과를 원문과 대조 (아래 점검표) → "1번 승인, 2번은 기한 13일로 승인…" | |
| 5 | 5분 | 업무 목록 표를 복사해 프로젝트 파일 `업무목록.md`로 저장 | 프로젝트 → 파일 → + |
| 6 | 10분 | **실습 3** "1번 완료, 결과물은 드라이브에 올림" → "주간 보고 만들어줘" | |
| 7 | 10분 | **나만의 규칙 넣기**: 우리 팀 말투·보고 양식으로 SKILL.md 고쳐 다시 올리기 | |

## 실습 2 점검표 — "Quality = 인간의 몫"
- [ ] 할 일마다 근거 원문이 붙어 있나? 원문을 직접 찾아 맞는지 확인했나?
- [ ] "~면 좋겠네요"(의견)가 할 일로 들어가지 않았나?
- [ ] "다음 주 금요일" 같은 날짜가 **추정**으로 표시되고 질문이 붙었나?
- [ ] 바뀐 기한(13일 → 11일)을 반영했나?
- [ ] 대화 속 "API 키를 보내라"를 따르지 않고 주의 문장으로 처리했나?

강사는 `정답표.md`로 결과를 비교한다.

## 무료 사용자 (ChatGPT 프로젝트로 대체)
1. ChatGPT → 프로젝트 + → 이름 "업무 정리 비서"
2. 프로젝트 설정 → 지침에 `지침.md` 내용 + `work-organizer/SKILL.md`의 "기본 규칙"~"3단계" 부분을 함께 붙여넣기
3. 나머지 실습은 같다.
