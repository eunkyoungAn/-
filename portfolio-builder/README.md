# 커리어캐쳐 AI 포트폴리오 빌더

퍼플커리어 노션 포트폴리오 양식(Contact · About me · Skills · AI 역량 · Projects · Experiences · Education)에 맞춰,
입력만 하면 AI가 직무 역량이 드러나는 포트폴리오를 만들어 주는 무료 웹 도구입니다.

- 빌더: `index.html`
- 그림 매뉴얼: `guide/`
- 완성 예시: `sample/`

## 사용법
1. 무료 Gemini 키 발급 (aistudio.google.com/apikey, 1분)
2. 빌더 맨 위 "⚡ AI 자동 완성 켜기"에 붙여넣기
3. 내용 입력 → [포트폴리오 완성하기] → [HTML 저장]

키가 없어도 프롬프트를 복사해 ChatGPT·Claude에 붙여넣는 방식으로 무료 사용할 수 있습니다.

## 개인정보
입력 내용은 서버에 저장하지 않고 브라우저에만 임시 저장됩니다. 이메일·연락처는 AI에 보내지 않습니다. API 키는 저장하지 않습니다.
