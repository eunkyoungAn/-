# 코치 캐릭터 스티커 (안은경 코치, 사용자 제공 2026-10-21)

`sticker_sheet.png`(3×9칸 시트)에서 배경을 지워 오린 파일입니다. 블로그 이미지·카드뉴스에 사진 대신 쓸 수 있습니다.

| 파일 | 표정·문구 | 쓰는 곳 예시 |
|---|---|---|
| hello.png | 안녕하세요! | 제목 카드, 시작 |
| thanks.png | 감사합니다! | 마무리, 감사 |
| fight.png | 화이팅! | 연습·도전 |
| think.png | ??? | 질문·고민 |
| best.png | 최고! | 칭찬·핵심 |
| sorry.png | 죄송합니다ㅠ | 사과·실수 |
| congrats.png | 축하합니다! | 합격·성과 |
| ok.png | 오케이! | 정리·확인 |
| cry.png | 흑흑 | 탈락·어려움 |

사용법: 투명 PNG이므로 `<img style="position:absolute;right:10px;bottom:0;height:480px">`처럼 배치합니다. 문구가 포함된 스티커이므로 같은 이미지에 큰 제목과 겹치지 않게 둡니다.
