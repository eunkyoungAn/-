# 커리어캐쳐 앱 스타일 — 복사해서 쓰는 디자인 양식

AI비서 에이전트 작업(강의 교안 PPT, AI비서 페이지)에서 쓴 디자인을 다른 작업에 그대로 가져다 쓰기 위한 양식이다.
흰 바탕 · 큰 굵은 제목 · 둥근 카드 · 포인트 색 하나. 앱 서비스 화면 느낌이지만 특정 회사의 로고·고유 색은 쓰지 않는다.

## 쓰는 방법 3가지
| 만들 것 | 쓰는 파일 | 방법 |
|---|---|---|
| 웹 페이지 | `index.html` (스타일 가이드) | 브라우저로 열고 **전체 CSS 복사** → 내 페이지 `<style>`에 붙여넣기 → 필요한 조각의 **HTML 복사** |
| 새 페이지를 처음부터 | `page-template.html` | 파일을 복사해서 제목·내용만 바꾸기 (CSS 포함) |
| PPT | `ppt/` | `kit.js` 부품으로 만들기. 예시 `example.js` |
| AI에게 맡길 때 | `프롬프트.md` | 웹용·PPT용 문구를 복사해 claude.ai·ChatGPT에 붙여넣기 |

## 파일
| 파일 | 내용 |
|---|---|
| `tokens.css` | 색·글꼴·크기 변수와 조각 스타일 (원본, 134줄) |
| `index.html` | 스타일 가이드: 색, 규칙 10가지, 조각 11개 미리보기 + 복사 버튼, 밝게/어둡게·웜 톤 전환 |
| `page-template.html` | CSS가 들어 있는 빈 시작 페이지 |
| `ppt/kit.js`, `ppt/example.js` | PPT 부품과 최소 예시 |
| `프롬프트.md` | AI에게 이 스타일을 요청하는 문구 |
| `_build/build.py` | `tokens.css`를 고친 뒤 실행하면 `index.html`, `page-template.html`이 다시 만들어짐 |

## 톤 두 가지
- **기본(파랑)**: 강의 교안과 같은 톤.
- **웜 그린**: AI비서 조직도·지시판 페이지와 같은 톤. 페이지의 `<html>`에 `data-tone="warm"`을 넣으면 된다.
