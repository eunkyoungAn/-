# 카드뉴스 캐러셀 기본형 (마음에 든 버전, 2026-10-15 저장)

첫 사용: 「경험노트 작성법」 카드뉴스 v2. 완성본 미리보기는 `sample/`에 있다.
새 카드뉴스를 만들 때는 이 형식을 기본으로 쓴다.

## 형식
- 1080×1350, 7장: 표지(검정) → 번호 카드 1~5 → 마무리 CTA(연한 분홍)
- 번호 카드: 위쪽(연회색)에 휴대폰 화면 2개 + 빨간 테두리 강조 / 아래쪽(흰색)에 빨간 원 번호 + 굵은 제목 2줄 + 회색 본문 3줄
- 포인트 색 코랄 레드 #F0564A 하나, 글꼴 Pretendard
- 모션: 요소가 위에서 아래 순서로 등장하고, 강조 테두리는 선이 그려지는 효과. 카드당 5초

## 만드는 법
1. `template.html`을 새 작업 폴더에 `cards.html`로 복사하고, 카드별 문구와 휴대폰 화면 내용만 바꾼다.
   - 강조할 요소에 `mark` 클래스를 붙이면 빨간 테두리가 생긴다.
   - 등장 순서는 `class="a"`와 `style="--d:0.3s"`로 조절한다.
2. PNG만 뽑기: `NODE_PATH=$(npm root -g) node templates/카드뉴스_캐러셀_기본형/render.js <작업폴더 절대경로>`
   PNG와 MP4 함께 뽑기: 같은 명령 끝에 ` video`를 붙인다.
   - 작업 폴더 안에 `png/`와 `mp4/` 폴더를 먼저 만들어 둔다.
