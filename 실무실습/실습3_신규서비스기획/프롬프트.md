# 실습 3 프롬프트 — 고객 데이터로 새 서비스 기획

준비: `가상데이터_수강생VOC.xlsx`, `기획서_양식.md` (한 장 보고서로 낼 경우 `../양식/한장보고서_양식.hwpx`)

## 1차 — 고객 불편 찾기 (15분)
```
첨부한 설문응답·문의기록 시트를 분석하세요.

1. "추가로 원하는 지원" 상위 3개와 비율
2. 운영형태(대면/온라인/혼합)별 "가장 어려웠던 점" 비교
3. 문의 유형별 건수와 평균 답변 시간, 야간(20시 이후) 문의의 비율과 평균 답변 시간
4. 자유 의견을 주제별로 묶고, 주제마다 대표 문장 2개 인용

규칙: 비율은 분모를 함께 적고, 응답 30명 미만 집단은 "해석 주의". 원인은 추측하지 말고 [확인 필요].
```

## 2차 — 문제 정의 (10분)
```
1차 결과에서 해결할 문제 하나를 고르고 이유를 데이터로 설명하세요.
그 문제를 "누가 / 언제 / 무엇 때문에 / 무엇을 못 하는가" 한 문장으로 정의하세요.
후보 문제 3개를 표로 비교한 뒤 하나를 추천하세요. (영향받는 사람 수, 불편 강도, 센터가 해결 가능한지)
```

## 3차 — 서비스 기획서 (20분)
```
선택한 문제를 해결할 새 서비스를 기획서 양식대로 작성하세요.
- 핵심 기능은 3개 이내, 문제와 1:1로 연결
- 사람이 하는 일과 AI가 하는 일, 사람이 승인하는 지점을 나눠 쓰기
- 성과 지표의 기준값은 데이터에서 가져오고, 목표값·예산·일정은 [가정]으로 표시
- 개인정보(수강생 이름·연락처)와 위험 대응 포함
```

## 4차 — 검토 (10분)
```
방금 기획서를 센터장 입장에서 비판적으로 검토하세요.
- 데이터로 뒷받침되지 않는 주장
- 실행 부담(인력·비용)이 과소평가된 부분
- 더 작은 규모로 먼저 시험해 볼 방법
```
