# 신규 서비스 기획서 양식

> 모든 수치에는 근거(데이터 시트·계산식 또는 출처)를 붙인다. 근거 없는 기대 효과는 쓰지 않고, 가정은 `[가정]`으로 표시한다.

| 항목 | 작성 내용 | 근거 |
|---|---|---|
| 1. 서비스명 | 한 줄 이름 + 한 줄 설명 | |
| 2. 기획 배경 | 고객 데이터에서 찾은 문제 2~3개 (수치 포함) | 시트·계산식 |
| 3. 대상 고객 | 누구의 어떤 상황인가 (페르소나 1명) | 데이터 속 집단 |
| 4. 문제 정의 | "○○는 ○○할 때 ○○ 때문에 ○○하지 못한다" 한 문장 | VOC 인용 1~2개 |
| 5. 해결 아이디어 | 핵심 기능 3개 이내 (MVP) | 문제와 1:1 연결 |
| 6. 운영 방식 | 사람이 하는 일 / AI가 하는 일 / 승인 지점 | |
| 7. 성과 지표 | KPI 2~3개, 현재 기준값과 목표값 | 기준값은 데이터에서 |
| 8. 시범 운영 계획 | 대상·기간·규모, 단계별 일정 | `[가정]` 표시 |
| 9. 위험과 대응 | 개인정보, 품질, 업무 부담 | |
| 10. 필요 자원 | 인력·도구·예산 | `[가정]` 또는 `[확인 필요]` |

## 한 장 보고서 양식으로 낼 때 칸 맞추기
| 한 장 보고서 칸 | 기획서 항목 |
|---|---|
| 개요 | 1 + 4 (서비스명과 문제 정의) |
| 실행계획 | 8 |
| 분석1~3 | 2의 문제 3개 |
| 해결방안 | 5 + 6 |
| 결론 / 세부1·2 | 7, 단기·중장기 |
| 참고문헌 | 데이터 출처 (가상 자료 명시) |
