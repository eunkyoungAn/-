# 실습 3 강사용 정답 (가상 자료 기준)

`가상데이터_수강생VOC.xlsx`를 Python으로 따로 계산해 확인한 값이다(2026-11-08). 설문 120명(대면 42, 온라인 48, 혼합 30), 문의 90건.

## 데이터에 심어 둔 발견 3가지
| 발견 | 수치 |
|---|---|
| 1. 수료 후 커리어 지원 수요 | "추가로 원하는 지원" 1위 **이력서·포트폴리오 피드백 30.0%(36명)**. 문의 중 취업·진로 상담은 14건뿐이지만 평균 답변 **59.5시간**으로 가장 김 |
| 2. 온라인 과정 질문 공백 | "질문할 곳이 없음" 온라인 **29.2%** vs 대면 11.9%·혼합 13.3%. 온라인은 "수업 외 질문 창구" 요청도 33.3%로 1위. 만족도 온라인 3.96 / 혼합 4.43 / 대면 4.74 |
| 3. 야간 학습 공백 | 야간(20시 이후) 문의 28건(31%), 평균 답변 **30.5시간** vs 주간 16.6시간. 과제·실습 질문 36건 중 18건(50%)이 야간 |

- 보조: "수업 녹화본·복습 자료" 20.8%(25명), 대면 과정은 "실습 후 복습할 자료 부족"이 23.8%로 어려운 점 1위(특별히 없음 제외)
- 함정: 50대 이상은 11명뿐 → 54.5%가 피드백을 원해도 "해석 주의"
- 야간 기준을 18시로 잡아도 같은 결론: 18시 이후 접수 33건 평균 27.7시간, 그중 과제·실습 질문 19건은 평균 26.3시간(주간 6.9시간)
- 시험 결과(2026-11-08): 스킬과 데이터만 준 새 Claude가 같은 1순위 문제(수료 후 이력서·포트폴리오)를 골랐고, 개인정보는 AI에 넣지 않는 운영안을 냈다

## 정답이 하나는 아니다 — 좋은 기획의 예
| 기획안 | 근거로 쓰는 발견 | 핵심 기능 예시 |
|---|---|---|
| 수료생 커리어 코칭 데스크 | 1 | 교육 경험 → 이력서 문장 초안(AI) → 강사 피드백(사람) / 실습 결과물 포트폴리오 템플릿 / 월 1회 그룹 코칭 |
| 24시간 실습 질문 도우미 | 2, 3 | 과정 자료 기반 1차 답변(AI) / 해결 안 되면 강사에게 넘기기 / 자주 묻는 질문을 복습 자료로 정리 |
| 복습 키트 | 보조 | 회차별 3분 요약 영상·단계별 캡처 / 실습 체크리스트 |

### 예시: 수료생 커리어 코칭 데스크 (요약)
- 문제 정의: 수료생은 수료 직후 이력서·포트폴리오를 준비할 때 교육 경험을 어떻게 쓸지 몰라 지원을 미룬다 (원하는 지원 1위 30.0%, 진로 문의 답변 59.5시간)
- 기능: ① 교육 경험을 이력서 문장으로 바꾸는 초안 생성(AI, 사람 검토 후 전달) ② 실습 결과물 포트폴리오 템플릿 ③ 월 1회 강사 그룹 피드백
- 운영: AI는 초안만, 최종 피드백과 기업 추천은 강사가 한다. 수강생 이름·연락처는 AI 도구에 넣지 않는다.
- KPI: 진로 문의 평균 답변 59.5시간 → 24시간 이내 `[가정]`, 수료 후 3개월 취업·창업률(실습 1 기준 44.6%) 개선 추이 관찰
- 시범: 하반기 1개 과정 30명, 8주 `[가정]`

## 채점 포인트
- 문제를 데이터 수치로 고르고, 기능이 문제와 1:1로 연결되는가
- 사람·AI 역할과 승인 지점이 나뉘는가
- 목표값·예산을 사실처럼 쓰지 않고 [가정]으로 표시했는가
- 작은 집단(50대 이상 11명)을 과대 해석하지 않았는가
