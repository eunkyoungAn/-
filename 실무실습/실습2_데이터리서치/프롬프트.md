# 실습 2 프롬프트 — 데이터 리서치 (실제 자료 찾기)

실습 1·3은 가상 데이터를 분석하지만, 보고서와 기획서에는 **바깥의 실제 근거**가 필요하다. 이 실습에서 그 근거를 찾고 검증한다.
준비: `출처기록표.xlsx`, `교차검증_체크리스트.md`
도구: Claude 웹 검색(또는 리서치 기능), Perplexity, Liner, NotebookLM — 1회차 교안의 자료 수집 도구

## 조사 주제 (하나 선택)
- A. 직장인·구직자의 생성형 AI 활용 현황 (실습 1 보고서 배경)
- B. 경력단절·중장년 여성의 재취업 현황과 지원 정책 (실습 1 분석3 보강)
- C. 온라인 교육의 수료율·학습 지원 방식 (실습 1 분석2, 실습 3 보강)

## 1단계 — 질문 쪼개기 (5분)
```
"[주제]"를 조사하려고 합니다. 보고서 근거로 쓸 수 있도록 확인 가능한 사실 질문 4개로 나눠 주세요.
각 질문마다 어떤 기관이 공식 자료를 낼 가능성이 높은지도 함께 적어 주세요.
```

## 2단계 — 자료 찾기 (15분)
```
아래 질문에 답할 자료를 웹에서 찾아 주세요: [질문]
- 2024~2026년 자료 우선
- 수치마다 발표 기관, 자료명, 발행일, 원문 링크
- 정부·공공기관·학술 자료를 먼저, 언론·민간 조사는 그다음
- 찾지 못한 것은 "찾지 못함"이라고 쓰고 추측하지 마세요
```

## 3단계 — 원문 확인과 기록 (15분)
사람이 직접 링크를 열어 원문(보도자료·보고서)에서 수치를 찾는다. 찾은 것만 `출처기록표.xlsx`에 기록한다.
- 원문을 직접 확인했으면 `원문 직접 확인 = Y`
- AI 답변이나 블로그 요약만 봤으면 `N` → 보고서에 쓰지 않음

## 4단계 — 보고서에 넣기 (10분)
```
출처기록표에서 '사용'으로 표시한 자료만 써서, 실습 1 보고서의 개요와 참고문헌을 보강해 주세요.
표에 없는 수치는 넣지 마세요. 참고문헌 형식: 기관, 「자료명」, 발행일.
```
