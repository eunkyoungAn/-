# 교차검증 체크리스트 — 수치 하나를 보고서에 쓰기 전에

| 확인 | 질문 |
|---|---|
| [ ] 원문 | 발표 기관의 원문(보도자료·보고서·통계표)을 직접 열어 봤는가? 기사·요약·AI 답변만 본 것은 아닌가 |
| [ ] 대상 | 누구를 조사했는가 (직장인 / 구직자 / 전체 국민, 표본 수) |
| [ ] 기간 | 언제 조사했고 언제 발표했는가. 2년보다 오래되지 않았는가 |
| [ ] 정의 | 같은 단어를 같은 뜻으로 쓰는가 (예: "AI 사용" = 주 1회 이상? 한 번이라도?) |
| [ ] 교차 | 다른 기관 자료와 크게 다르지 않은가. 다르면 차이의 이유(대상·정의)를 적었는가 |
| [ ] 옮겨 적기 | 숫자·단위·소수점을 원문 그대로 옮겼는가 |
| [ ] 표시 | 출처(기관, 자료명, 발행일)를 보고서에 적었는가 |

**AI 리서치 결과에서 자주 나오는 문제**
- 존재하지 않는 보고서 이름이나 링크
- 맞는 기관인데 연도가 다른 수치
- 여러 조사의 수치를 섞어 하나처럼 말함
- 원문에 없는 해석("~때문이다")을 사실처럼 붙임
