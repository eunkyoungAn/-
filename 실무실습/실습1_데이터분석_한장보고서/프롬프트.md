# 실습 1 프롬프트 — 데이터 분석 → 한 장 보고서

준비: `가상데이터_교육과정운영실적.xlsx`, `../양식/한장보고서_양식.hwpx`
권장 환경: claude.ai 프로젝트 "실무 보고서" (지침: `../지침.md`), 설정 → 기능 → 코드 실행 및 파일 생성 ON

## 1차 — 자료 파악 (5분)
```
첨부한 엑셀의 안내 시트를 읽고 정리하세요.
- 자료명, 자료 성격(실제/가상), 대상 인원, 기간
- 시트별 내용과 각 지표의 계산 방법
수치 해석은 아직 하지 마세요.
```

## 2차 — 분석 (15분)
```
과정별실적 시트와 수강생 원자료를 분석하세요.

1. 과정별 경쟁률·수료율·만족도·취업·창업률 순위
2. 분야별, 운영형태(대면/온라인/혼합)별 수료율·만족도·취업·창업률
3. 연령대별, 경력단절 기간별 수료자 취업·창업률
4. 가장 주목할 결과 3개 (전체 평균과 비교한 차이를 %p로)

규칙
- 모든 수치는 엑셀에서 직접 계산하고, 계산에 쓴 기준(분모)을 함께 적으세요.
- 집단 인원이 50명 미만이면 "해석 주의"를 붙이세요.
- 자료에 없는 원인은 추측하지 말고 [확인 필요]로 표시하세요.
```

## 3차 — 한 장 보고서 (15분)
```
2차 분석 결과로 한 장 보고서를 작성하세요.

- 제목: 2026년 상반기 직업교육과정 운영 성과 분석 및 하반기 개선 방안
- 독자: 센터장 (의사결정용)
- 구성: 개요(2줄 이내) / 실행계획 / 분석1~3 / 해결방안 / 결론 + 세부 2개 / 참고문헌
- 분석1~3은 2차의 주목할 결과 3개를 하나씩 사용
- 해결방안과 결론은 분석 수치와 연결하고, 제안은 제안으로 표시
- 참고문헌에는 "교육·실습용 가상 자료"임을 밝히세요.
첨부한 hwpx 양식에 채워서 파일로 주세요.
```
> 한 장 보고서 스킬(one-page-report-hwpx)을 등록했다면 "한 장 보고서 작성해줘"만으로도 양식이 채워진다.

## 4차 — 검수 (10분)
```
방금 보고서의 모든 수치를 엑셀과 다시 대조해 표로 보여 주세요.
| 보고서 문장 | 수치 | 엑셀 위치(시트·셀 또는 계산식) | 일치 여부 |
```
그다음 사람이 직접: 제목 줄바꿈, 한 페이지 넘침, 강조(볼드) 확인 — "Quality = 인간의 몫"
