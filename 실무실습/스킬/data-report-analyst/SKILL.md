# 데이터 분석 → 한 장 보고서

## 1. 자료 파악 (먼저 보여 주고 시작)
- 자료명, 실제/가상 여부, 대상·인원, 기간, 시트별 내용, 지표 정의
- 정의 시트가 있으면 그 정의를 그대로 따른다. 없으면 분모를 정해서 밝힌다.

## 2. 분석
1. 전체 지표
2. 항목별 순위 (상위·하위)
3. 집단별 비교: 전체 평균과의 차이를 %p 또는 배수로
4. 주목할 결과 3개
- 모든 수치는 직접 계산하고 계산 기준(분모)을 적는다.
- 집단이 50명 미만이면 "해석 주의".
- 원인은 추측하지 않는다. 필요하면 [확인 필요]로 질문한다.

## 3. 한 장 보고서 초안
| 칸 | 작성 기준 |
|---|---|
| 제목 | 기관·기간·주제·목적 |
| 개요 | 2줄 이내. 핵심 수치 2개 + 문제 한 줄 |
| 실행계획 | 진단 → 분석 → 개선안 → 점검 흐름 |
| 분석1~3 | 주목할 결과 3개를 하나씩. 소제목 + 수치 + 비교 기준 |
| 해결방안 | 분석과 1:1 연결된 제안. "제안"으로 표시 |
| 결론 | 방향 한 줄 + (단기) 1개 + (중장기) 1개 |
| 참고문헌 | 데이터 출처. 가상 자료면 "교육·실습용 가상 자료" 명시 |
- 문체: 개조식(~함, ~임). 이모지 금지.
- hwpx 양식이 있고 한 장 보고서 스킬이 있으면 그 스킬로 양식에 채운다.

## 4. 수치 대조표 (항상 마지막에)
| 보고서 문장 | 수치 | 근거(시트·셀 또는 계산식) | 일치 |
틀린 것이 있으면 고친 뒤 다시 보여 준다.

## 하지 않는 일
없는 수치·출처 만들기, 상관을 원인으로 단정, 작은 집단 과대 해석.
