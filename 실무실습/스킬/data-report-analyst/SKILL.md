# 데이터 분석 → 한 장 보고서

## 1. 자료 파악 (요약해 보여 주고 멈추지 말고 이어서 진행)
- 자료명, 실제/가상 여부, 대상·인원, 기간, 시트별 내용, 지표 정의
- 정의 시트가 있으면 그 정의를 그대로 따른다. 없으면 분모를 정해서 밝힌다.
- 정의에 없는 보조 지표(예: 수강 인원 기준 취업률)는 분석에서만 쓰고, 보고서 본문은 정의된 지표로 쓴다.

## 2. 분석
1. 전체 지표
2. 항목별 순위 (상위·하위)
3. 집단별 비교: 전체 평균과의 차이를 %p 또는 배수로
4. 주목할 결과 3개: 전체 대비 차이가 크고, 정원·예산·운영 방식 같은 결정에 연결되는 것을 **서로 다른 관점**(예: 수요 / 운영 방식 / 대상 집단)에서 하나씩 고른다
- 모든 수치는 직접 계산하고 계산 기준(분모)을 적는다.
- 비율의 분모가 30명 미만이면 "해석 주의". 모든 과정이 같은 인원이라면 보고서 아래에 한 번만 적는다.
- 두 요인이 섞여 있으면(예: 온라인 과정이 특정 분야에 몰림) "이 자료로는 구분할 수 없음"이라고 쓴다.
- 원인은 추측하지 않는다. [확인 필요] 사항은 본문이 아니라 보고서 아래 별도 목록으로 모은다.

## 3. 한 장 보고서 초안
| 칸 | 작성 기준 |
|---|---|
| 제목 | 기관·기간·주제·목적 |
| 개요 | 2줄 이내. 1줄: 핵심 수치 2개, 2줄: 문제 |
| 실행계획 | 진단 → 분석 → 개선안 → 점검 흐름 |
| 분석1~3 | 주목할 결과 3개를 하나씩. 소제목 + 수치 + 비교 기준 |
| 해결방안 | 분석과 1:1 연결. 문장 앞에 `(제안)`, 가정이 들어가면 `[가정]` |
| 결론 | 방향 한 줄 + 세부 2개: `(단기)` 1개, `(중장기)` 1개 |
| 참고문헌 | 데이터 출처. 가상 자료면 "교육·실습용 가상 자료" 명시 |
- 문체: 개조식(~함, ~임). 이모지 금지.
- hwpx 양식이 있고 한 장 보고서 스킬이 있으면 그 스킬로 양식에 채운다. 양식이 없으면 칸별 텍스트로 내고 "hwpx 양식을 올리면 채워 드립니다"라고 안내한다.

## 4. 수치 대조표 (항상 마지막에)
| 보고서 문장 | 수치 | 근거(시트·셀 또는 계산식) | 일치 |
- 원자료로 다시 계산한 값과 비교하고, 소수 첫째 자리까지 같으면 일치로 본다. 틀린 것이 있으면 고친 뒤 다시 보여 준다.

## 하지 않는 일
없는 수치·출처 만들기, 상관을 원인으로 단정, 작은 집단 과대 해석.
