# 실무 실습 — 데이터 분석·리서치·보고서·서비스 기획

AI 업무 비서 강의를 **실제 실무**로 넓히는 실습 묶음이다. 모든 실습 데이터는 가상이고, 결과물은 실제 기관 양식(한 장 보고서 hwpx)으로 낸다.

## 적용 가능 여부 (2026-11-08 확인)

| 하려는 일 | 가능? | 쓰는 기능 | 주의 |
|---|---|---|---|
| 한 장 보고서 (첨부 hwpx 양식) | **가능** | 한 장 보고서 스킬 `one-page-report-hwpx`. 첨부 양식이 스킬의 19칸 배치와 똑같은 것을 확인했고, 예시 결과물도 만들었다 | 한 페이지 넘침·줄바꿈은 한글에서 사람이 확인 |
| 엑셀 데이터 분석 | **가능** | claude.ai 코드 실행(설정 → 기능) + `data-report-analyst` 스킬 | 수치는 엑셀과 대조표로 검증 |
| 데이터 리서치 (외부 근거) | **가능, 조건 있음** | 웹 검색·리서치 기능, Perplexity·Liner·NotebookLM | AI가 없는 보고서·틀린 연도를 말할 수 있어 **원문 직접 확인**이 필수 |
| 신규 서비스 기획 | **가능** | `service-planner` 스킬 + 고객 데이터(VOC) | 목표값·예산·일정은 [가정]. 시장 규모 같은 외부 수치는 리서치 단계 출처가 있을 때만 |
| 다른 기관 양식 채우기 | **가능** | `hwpx-autofill-conversion`, 운영일지는 `operation-log-hwpx` | 양식마다 칸 구조 확인 |

## 실습 구성 (각 45~55분)

| 실습 | 입력 | 산출물 | 핵심 역량 |
|---|---|---|---|
| [실습 1 데이터 분석 → 한 장 보고서](실습1_데이터분석_한장보고서/) | 가상 교육과정 운영 실적 (8개 과정, 240명) | 한 장 보고서 hwpx | 지표 계산, 집단 비교, 수치 대조 |
| [실습 2 데이터 리서치](실습2_데이터리서치/) | 실제 웹 자료 | 출처기록표, 보강된 보고서 | 원문 확인, 교차검증 |
| [실습 3 신규 서비스 기획](실습3_신규서비스기획/) | 가상 수강생 설문 120명 + 문의 90건 | 서비스 기획서 (또는 한 장 보고서) | 고객 불편 발견, 문제 정의, KPI |

세 실습은 이어진다. 실습 1에서 찾은 문제(온라인 과정 성과, 취업 취약 집단) → 실습 2에서 외부 근거 보강 → 실습 3에서 해결 서비스 기획.

## 폴더 안내
| 파일 | 용도 |
|---|---|
| `양식/한장보고서_양식.hwpx` | 공용 한 장 보고서 양식 (제공 원본) |
| `지침.md` | 프로젝트 "실무 보고서·기획" 지침 |
| `스킬/data-report-analyst.zip` | 데이터 → 한 장 보고서 스킬 (업로드용) |
| `스킬/service-planner.zip` | 고객 데이터 → 서비스 기획 스킬 (업로드용) |
| `실습N_*/프롬프트.md` | 단계별 프롬프트 (스킬 없이도 실습 가능) |
| `실습N_*/강사용_정답.md` | 데이터에 심어 둔 정답과 흔한 오류 (수강생 배포 금지) |
| `실습1_*/예시결과_한장보고서.hwpx` | 가상 데이터로 실제 채운 예시 |

## 준비 (수강생)
1. 설정 → 기능 → **코드 실행 및 파일 생성** ON
2. 설정 → 사용자 지정 → 스킬 → + → 스킬 업로드: `data-report-analyst.zip`, `service-planner.zip` (한 장 보고서 스킬이 있으면 함께)
3. 프로젝트 "실무 보고서·기획" 만들기 → `지침.md` 붙여넣기 → 양식 hwpx를 프로젝트 파일로 올리기
4. 무료 사용자: ChatGPT 프로젝트에 지침 + 스킬 내용을 붙여 넣고 `프롬프트.md` 순서대로 진행

## 원칙
- 가상 데이터는 결과물에 "교육·실습용 가상 자료"라고 밝힌다.
- 외부 수치는 원문을 직접 확인한 것만 쓴다.
- 모든 결과물 끝에 수치 대조표를 붙이고, 마지막 확인은 사람이 한다 (Quality = 인간의 몫).

## 데이터 다시 만들기
가상 데이터는 고정된 난수로 만들어 매번 같은 값이 나온다. 생성 스크립트는 `_build/`에 있다.
