Gemini가 만든 코드로 메일 한 번에 보내기

구글 시트에 받는 사람 목록을 적고, Gemini에게 Apps Script 코드를 받아 붙여 넣으면 한 사람씩 이름을 넣은 메일이 Gmail로 나갑니다. 코딩을 몰라도 됩니다. 나에게 테스트 메일을 먼저 보내 확인한 뒤 전체 발송을 결정합니다.

    시작 전 1Google 계정 로그인

    크롬에서 개인 Google 계정으로 로그인합니다. 시트, Gemini, Gmail을 같은 계정으로 씁니다.

    시작 전 2보낼 메일 준비

    3회차 실습 1에서 만든 회의 안내 메일을 열어 둡니다. 없으면 예시 문장을 그대로 씁니다.

    시작 전 3예시 주소만 사용

    연습에는 내 주소와 동의를 받은 주소만 씁니다. 실제 고객·수강생 명단은 넣지 않습니다.

    MATERIALS

    요청문과 참고 코드

    2단계에서 쓰는 요청문과, Gemini 코드가 맞지 않을 때 쓰는 참고 코드입니다.

    SAFETY

    실제 업무에 쓸 때

    AI가 작성하고, 사람이 확인합니다.

    받는 사람에게 메일을 보내도 되는지(수신 동의) 먼저 확인합니다. 주민등록번호, 계좌번호, 고객 명단, 회사 내부자료는 Gemini 요청문에 넣지 않습니다. 개인 Gmail 계정은 Apps Script로 하루 100명까지 보낼 수 있으므로 인원이 많으면 나눠 보냅니다. 회사 계정은 회사 규정과 담당자 안내를 먼저 따릅니다.
