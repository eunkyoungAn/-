2. 양식 조건
  • 제목: 회색 박스 안, 굵은 헤드라인 글씨, 가운데 정렬
  • □ 개요: ○ 1개, 1~2줄 이내로 문서 전체 요약
  • □ 본문: ○ 5개, [라벨] + 개조식 1~2줄
  • □ 결론: ○ 방향 제시 1개 + - 세부 내용 정확히 2개
  • □ 참고문헌: 논문명 / 기사 / 사이트
  • 개조식(명사형 종결), 이모지 금지, 반드시 한 페이지
