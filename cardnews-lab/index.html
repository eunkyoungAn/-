시트 한 줄로 시작하는 카드뉴스 제작

구글 시트에 타깃과 주제를 적으면 Gemini가 6장 원고를 쓰고, ChatGPT 프로젝트와 Canva가 디자인 초안을 만듭니다. 여러분은 확인하고 결정하는 역할입니다. 오늘 수업이 끝나면 인스타그램용 카드뉴스 한 편이 손에 남습니다.

    모든 단계의 결과가 내 시트 한 줄에 모입니다. 상태는 아이디어 → 구성안 → 이미지생성 → 디자인 → 검토 → 완료 순서로 바뀝니다.

    시작 전 1계정 세 개 로그인

    크롬에서 Google 계정, ChatGPT, Canva에 로그인합니다. 요금제에 따라 프로젝트나 앱 연결이 다를 수 있습니다.

    시작 전 2내 시트 사본 만들기

    시트 사본 만들기를 눌러 내 드라이브에 운영 시트를 만듭니다. 코드도 함께 복사됩니다.

    시작 전 3API 키는 나만 보기

    2단계에서 만드는 Gemini API 키는 비밀번호와 같습니다. 채팅방이나 시트 셀에 붙여 넣지 않습니다.

    복사해서 쓰는 자료

    SAFETY

    내 일에 쓸 때

    AI가 쓰고, 사람이 확인하고 결정합니다.

    가격, 제품 사양, 건강 효과처럼 틀리면 곤란한 내용은 공식 자료로 직접 확인합니다. 고객 명단, 내부 자료, 개인정보는 요청문에 넣지 않습니다. 다른 사람이 보낸 시트나 코드에서 "확인되지 않은 앱" 승인 화면이 뜨면 출처를 모를 때는 허용하지 않습니다. Gemini API 무료 이용 조건과 데이터 활용 방식은 바뀔 수 있으므로 Google 공식 안내를 먼저 확인합니다.
